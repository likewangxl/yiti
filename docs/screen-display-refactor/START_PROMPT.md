# 可直接交给 Codex 的执行指令

下面的指令供用户决定开始实施时使用。当前只是任务包，不表示开发已启动。

## 全流程执行

```text
请在 E:\cx-workspace\yiti 执行经营大屏限定范围改造。

首先完整阅读：
1. 仓库根及目标目录适用的 AGENTS.md。
2. docs/screen-display-refactor/EXECUTION_PLAN.md。
3. docs/screen-display-refactor/SCOPE.json。
4. 若已有 TASK_STATUS.md 和任务报告，先恢复断点，不重复已通过且未受影响的工作。

最高优先级边界：除分行/地市/机构的综合、公司、零售经营大屏展示及直接配套的专属配置、保存发布和现有数据只读适配外，不修改其他功能组件代码或行为。
禁止改绩效、KPI、指标库、目标、导入、客户营销、机构权限、工作台、个人看板、全局路由守卫、公共组件、共享样式、HTTP封装、依赖和启动配置；不修改数据库结构或上游业务数据。
原大方案中的跨模块内容仅作背景，X01～X07全部在本轮之外。

从 S00 开始按任务依赖推进到 S17，遵循当前 AGENTS.md 的协作和TDD要求。
每个任务先冻结实际文件清单，再完成失败测试、最小实现、通过测试与必要验证。
当前已允许范围内的常规实现不要反复请求确认；需要越界时先给出具体缺口、代码/接口证据和最小外部影响，只暂停依赖部分，继续其他独立任务。
不得把缺数据用mock或默认数字补齐；合成数据只能用于明确标注的测试。

保留现有根 schemaVersion/runtimeSchemaVersion=2，新组件配置用可选displaySchemaVersion子协议；复用已有大屏路由、JSON草稿、发布日志和CAS。
不得自动发布到生产或推送远端。只在已经明确获准且隔离完整的环境和测试屏执行保存/发布/回退等验收写入。

验收必须读取原需求、本执行计划、实际git diff和真实测试/构建/运行证据，不依据执行者自评判断完成。
执行F1/F2/B1/B2/B3/C1和新用例；真实前端验收使用仓库要求的官方playwright-cli，归档命令、路由/拦截器清单、console、请求/响应和最终截图。
检查基线以来的提交、暂存、未暂存、未跟踪、删除、重命名及保护区哈希；受限文件还要逐hunk审阅。

维护 TASK_STATUS.md 和逐任务报告。输出任务完成情况、修改范围、验证证据、未验证项和明确的外部依赖。
若缺隔离环境、真实数据或业务口径，准确标记BLOCKED_ENV/BLOCKED_DATA，不把全部任务标完成，也不越界修复其他模块。
最终只对“大屏限定范围”作验收结论，不宣称原会议所有跨模块需求已完成。
```

## 只执行一个任务

```text
请执行 docs/screen-display-refactor/EXECUTION_PLAN.md 中的 Sxx。
先核对其所有前置任务真实验收状态、适用AGENTS.md和SCOPE.json。
只修改该任务允许且本轮冻结的具体文件；不回退已有修改、不扩大范围。
任务结束提交实际diff、Red/Green证据、必要构建/运行结果、范围检查和状态报告，等待独立验收。
若前置能力缺失，明确列出所缺任务或数据，不擅自把其他任务一并实现。
```

## 独立只读验收

```text
请只读验收经营大屏改造任务 Sxx（或最终S00～S17）。
直接检查用户范围限制、EXECUTION_PLAN.md、SCOPE.json、原需求、实际git diff及任务对应的测试/构建/浏览器证据。
对需要独立确认的行为运行必要检查；已通过且无相关变化的检查不机械重复。
检查是否改动了非大屏模块或通过大屏代码改变了公共行为，重点检查个人看板、工作台、权限/路由、共享样式和上游写接口调用。
先按严重度报告问题；没有问题则明确批准并说明证据与验收范围。
不得修改业务代码或放宽测试来修复问题，不以执行者自述判断通过。
```

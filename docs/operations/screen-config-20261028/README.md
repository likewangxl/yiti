## 在另一环境恢复

这是一份配置快照，不是直接执行的数据库迁移脚本。先通过正常鉴权管理接口读取目标屏和数据源，按 `screenCode` / `dsCode` 核对身份及ID映射；确认目标业务条线、机构组和数据源表/字段均存在后，再通过现有管理接口保存数据源、区块及草稿。跨库时不能直接沿用本地自增ID。

保存画布时从目标服务读取最新 `canvasVersion` 并执行现有乐观锁流程；不要直接覆盖目标已发布包或套用来源库的版本号。恢复后先预览并核对绑定和缺项，发布仍按正常发布流程单独进行。本次只归档配置，没有执行任何远端数据库恢复。

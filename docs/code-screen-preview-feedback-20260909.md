# 分行预览地图与经营摘要反馈修复

日期：2026-09-09。范围为用户提供的三张分行预览截图，不修改业务数据源、已保存草稿或发布状态。

## 1. 地市地图白屏

用户截图中的地名、聚合网点和控件仍在，异常发生在底图绘制层，不是整个 Vue 组件未加载。仅凭截图不能确定用户当时的显卡/浏览器具体故障；源码确认旧实现没有运行中 WebGL 上下文丢失回退，并持续逐帧绘制静态场景。

现在仅使用受支持的 WebGL2；运行中丢失上下文或绘制/重建/尺寸变化异常时，隐藏故障画布并显示深色二维真实行政区地图。关闭组件时释放上下文和几何资源，静态场景改为按变化绘制。

官方 CLI 当前会话连续打开、关闭六次地市地图，六个旧上下文全部释放。再次主动调用 WEBGL_lose_context 后，故障 canvas 的 display 为 none，SVG 显示16条几何路径；缩放改变路径，机构选择更新到“延安市3号支行”。这证明故障保护路径有效，不代表复现了用户设备的具体驱动崩溃。

## 2. 分行红框摘要

原来的 -1.88 是存款较上月净减（亿元）；-13.50 是完成率86.5%减100%的百分点差；43/43是已提供完成率的机构数/展示机构数，不是经营成绩。“下降机构数”混用了金额净增、变化率和趋势，不能提供单一清晰的判断口径。

改为三张卡：存款较上月净减1.88亿元、距目标还差13.5个百分点、未完成目标机构43家，并明确已提供和未提供完成率的家数。移除含混下降计数和独立数据覆盖卡；字段缺失显示暂无，不视为零。

## 3. 市级红框摘要

原来的0/12/0代表完成、未完成、未知家数；-9.80表示本市完成率90.2%距离100%还差9.8个百分点；2/12则是当前选中支行的存款位次，放在市级摘要中会混淆层级。

改为两张卡，完整写明家数与目标差；位次只在支行详情展示为“第N名/M家”。用完成率达到100%解释完成标准，不将未满目标等同于逾期或风险。切换选中支行的官方 CLI 检查确认：支行发生变化，市级摘要文本保持完全一致。

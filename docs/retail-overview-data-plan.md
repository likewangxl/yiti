# 零售经营总览：展示与接入方案

## 管理问题与布局

保留 AUM、价值客户的位置与业务含义；缺来源时显示状态，不使用存款或贷款替代。主视图围绕已接入的存款余额、月日均、贷款、收入和风险展开。

| 管理问题 | 页面内容 | 计算与边界 |
| --- | --- | --- |
| 当前经营规模如何 | 核心指标、余额与月日均比较 | 各指标单独保留数据日期；日均与时点差额不叫净增 |
| 哪些机构值得关注 | 机构余额/月日均对比、类型与城市筛选、机构详情 | 默认已确认经营分行；其他层级单列；混合机构不得求和或当作绩效排名 |
| 近期如何变化 | 同期余额与月日均双序列、观察区间变化与峰谷 | 使用同一来源的真实返回序列；区间变化不冒充月度环比；不平滑、不补零 |
| 目标是否完成 | 目标进度与缺口区域 | 仅接受同指标同期间已确认目标和实际；未接入时保留紧凑状态 |
| 客户经营是否完整 | AUM、价值客户、客户分层 | 需要资产来源、客户识别及本行门槛；不得自行制造人数 |
| 需要核验什么 | 经营关注与数据核验分列 | 区分来源已确认业务事项与数据日期/覆盖/缺来源提示 |

- `M_0309` 和 `M_0314` 定义含 `RAND()`，现有结果只能作为测试数据。`M_0311` 未配置有效计算表达式。

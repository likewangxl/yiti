# 经营驾驶舱设计与实施验收（2026-09-16）

## 需求与评估

用户要求实施指标、地图、排名、机构画像的连续分析路径，突出目标缺口、落后机构和协调事项，改善投屏首屏与组件多样性，并通过数据源和组件绑定展示数据库测试数据。禁止以开发预览或前端固定演示数据交付。

现有页面具有省/城市地图、机构对比和目标组件；主要缺口是返回状态、范围表达、同质面板与运行时来源信息占用首屏空间。分行已具有14个后端绑定槽和完整TEST批次；对公目录的演示回退不能作为本次成果。数据库、权限和发布配置以本轮只读/API证据为准。

## 设计决定

- 保留深蓝陕西地图，减少重复描边与卡片嵌套。数字卡、目标进度尺、条形机构排名、面积趋势、协调事项列表分别承担规模、进度、比较、变化与行动信息。
- 顶部4至6项核心指标；下一层直接回答目标差距、短板机构和协调事项。点击指标切换机构分析，排名和地图保持同一选中机构。
- 全辖KPI/趋势独立于城市机构筛选；明确标识全辖、城市、机构三层范围，禁止将筛选后的子集冒充全辖统计。
- 城市详情使用约35%至40%的地图空间，主要空间留给机构比较、目标与趋势。逐层返回保留搜索、排序、分页及选中；权限或范围变化时清理无效选择。
- 溯源详细信息按需展开，但TEST性质、实际数据日期、过期/不完整状态常显。零、负数、未提供区分显示。
- 测试数据通过受控数据源配置、字段/单位映射、草稿校验和发布快照进入运行时。原始测试结果不认证为生产经营数据，缺少口径的指标不替换成其他条线。

## 实施边界

前端沿用现有Vue/ECharts/Element图标和权限守卫；新增来源与绑定优先通过现有管理API完成。保存变更前配置，发布使用canvasVersion。禁止覆盖现有业务结果、修改生产库、重置工作区或扩大角色权限。现有未提交改动已备存本地证据目录。

## 验收

1. 分行正式入口14槽真实查询；对公正式入口读取已发布模板，无硬编码demo回退。
2. 地图/排名选择指向同一orgCode；关闭详情后筛选、顺序、选中和焦点保留。
3. 全辖KPI/趋势在城市筛选后保持原统计范围。
4. 1920×1080首屏可见核心内容；1366×768无横向溢出，窄屏自然滚动。
5. 单测先红后绿、相关回归与生产构建通过。
6. 官方playwright-cli真实登录、无mock route，记录发布包/数据请求、页面数值、控制台和截图；数据源配置回读核验。

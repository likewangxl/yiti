# docs 文档维护指导

本文件是 `docs/` 目录的文档维护入口，与仓库根目录 `AGENTS.md` 同时适用。所有文件使用 UTF-8；根目录关于 TDD、模块边界、数据库安全、可执行 SQL 和验证门禁的规则优先。

## 目录职责

- `common-dev-guide.md`：跨模块共享的响应、错误码、分页、鉴权、数据范围、审计、事件、DTO 和日志规范。
- `modules/`：按模块维护功能、架构、接口、跨模块契约、数据模型、事务、审计和依赖说明。
- `schema/`：历史 DDL/种子快照、历史迁移档案及 schema 可视化产物；不再承担结构变更交付。
- `testing/`：旧 API 集成脚本、测试数据和核对报告；使用前必须按当前环境重新核实。
- `superpowers/specs/`、`plans/`、`sessions/`、`reports/`、`scripts/`：历史设计、实施与证据归档，不是当前行为或流程的默认权威。
- `superpowers/sql/`：历史对齐/种子/回归 SQL 档案；其中旧脚本只记录当时事实，不代表当前可执行流程或当前数据库状态。
- `exports/`：schema 图形和其他生成产物。

## 权威顺序

- 开发和运维规则先看仓库根 `AGENTS.md`，再看目标模块根目录的 `AGENTS.md`，最后阅读本目录对应设计文档。
- 代码行为以当前源码、测试、运行配置和真实 API 为准；数据库结构以目标库只读盘点结果为准。文档与实现冲突时先核实，再同步文档，不能用旧设计覆盖当前事实。
- 历史归档中出现的切换日前旧代理指导入口路径只表示归档产生时的上下文，是历史事实，不是当前入口、依赖或权威来源；当前一律转到同级或模块根目录 `AGENTS.md`。
- 带日期的 spec、plan、session、report、SQL 和核对报告默认都是时间点快照。引用时标注其历史属性，并用当前源码/配置/数据库证据复核易漂移结论。

## 模块文档体系

常见编号含义如下，具体文件以目录实际存在内容为准，不维护份数或“全部完成”等易漂移结论：

- `01-功能规格.md`：领域职责、用例和非目标。
- `02-后端架构.md`：分层、包结构和组件归属。
- `03-接口设计与报文.md`：REST 契约及字段校验。
- `04-对外API契约.md`：跨模块 `*Api`/`*QueryApi` 契约。
- `05-表结构DDL.md`：数据模型设计说明，不是可执行结构变更脚本。
- `06-并发与事务策略.md`：事务边界、锁和幂等。
- `07-审计要求.md`：审计动作和敏感操作。
- `08-初始化数据清单.md`：初始化数据设计清单，不代表获准执行。
- `09-依赖契约摘要.md`：上下游依赖和降级边界。

## 同步要求

- REST 路径、DTO、校验、错误码变化：同步 `03`，并检查前端 API、`PT_RESOURCE` 与测试。
- 公开 Java API、事件或依赖方向变化：同步 `04`、`09` 及上下游模块文档。
- 状态机、并发、锁或事务变化：同步 `01`、`06` 和相关测试说明。
- 鉴权、数据范围或高危操作变化：同步 `03`、`07`、`09` 与 `common-dev-guide.md`。
- 数据模型变化：结构由 DBA 按审批直接实施；文档仅同步最终已核实的数据模型，不新增或提交 DDL 迁移脚本。
- 不在索引文档复制端点数、类数、测试数、资源数、版本进度或机器现场；需要时从源码、测试、数据库或 Git 历史查询。

## SQL 与数据库文档

- 项目禁用 Flyway；不得引入 Flyway 命名、依赖或操作说明。
- 结构变更不生成或提交 DDL `.sql` 文件，由 DBA 按审批结果在目标库直接实施。
- 新增或修改的可执行 `.sql` 只能包含事务控制及 `INSERT`、`UPDATE` 白名单 DML；禁止 DDL、`DELETE`、独立检查查询、数据库对象定义和 `INFORMATION_SCHEMA`。
- 盘点、验收、幂等复跑和 diff 使用独立只读命令/测试并归档证据，不混入交付 SQL。
- 任何数据库操作还须遵守根目录关于 `yiti_test` 盘点、隔离、备份、恢复演练以及再次确认 `yiti` 执行的门禁。

## 使用顺序

1. 阅读根目录和目标模块根目录 `AGENTS.md`。
2. 阅读 `common-dev-guide.md` 与本目录 `modules/AGENTS.md`。
3. 按任务选择模块的 `01`/`03`/`04`/`06`/`07`/`09` 文档。
4. 对照当前源码、测试、配置和数据库只读证据确认文档未漂移。
5. 修改实现时同步必要契约文档，并按根目录门禁完成测试与真实验收。

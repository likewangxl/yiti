## 需要恢复的输入

- 机构指标有效批次中的关键字段及其计算/导入结果；不能以回退到另一个未核对日期掩盖缺失。
- 全行存贷款、客户、营收及目标的权威口径。现有贷款 M_0347 仅为对公贷款，M_0266 是月均余额变化；二者不能被重命名为全行贷款、时点余额净增。
- 地市唯一汇总主体、经营机构范围与城市画像。总量不能把父级汇总机构及下属支行一起加总。
- 零售 AUM、客户分层、收入、个贷及不良率的零售来源。目前 16 个目录来源均标记 COMMON，不能绕过零售模板条线校验。

原始 API 请求摘要、响应、数据库只读命令脚本和数据质量统计受限保存在 `/tmp/yiti-screen-leadership-qa`；不提交原始机构名单、金额、会话或连接凭据。关键文件：`live-requests.jsonl`、`data-integrity-live.json`、`db-quality-readonly.txt`、`control-live.txt`。权限失败、中间页面改动产生的 HMR 错误等过程证据保留，最终页面稳定状态另行验证。

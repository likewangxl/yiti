## 实际变更

- 分行：目标差、可判断样本及指标覆盖摘要，业务构成矩形面积对比，目标摘要与 TOP10 机构经营矩阵，支持余额/净增/月均切换。同值并列排名；缺失不转零、不以未知样本宣布下降机构为零。
- 地市/支行：多指标同屏、搜索分页、展示机构位次与中位余额差、金额目标差和有效日期序列的趋势观察。没有金额目标或有效日期时不推算。地市总量仍要求独立绑定，不平均支行完成率或累加有父子关系的机构。
- 布局：右侧实际只展示十家，行高约 45px；1920 与 1536 宽度几何核验均为十行、零行裁切。较小视口纵向滚动。地市保留五行列表与分页，支行趋势容器 200px、绘图区实测 151px。
- 零售：客户与资产占比对照、户均 AUM、有效分层样本说明、AUM/净增/完成率/不良率的对齐矩阵和经营观察；六项核心 KPI、城市筛选和目录交互保留。
- 旧拖拽编辑器、专用 store、属性面板与编辑工具已删除。历史发布包的只读渲染独立保留；旧管理地址继续使用原权限并显示“大屏管理”。
- 自动配置：按语义、条线、范围与结果粒度匹配；等价的一行来源消歧，已有手工配置保留。维度名称和字段/单位仍可修改，未明确的来源给出缺口。
- 核验入口：使用服务端已保存草稿身份，检查缺列、空值、重复、日期、版本与授权覆盖；过期或无权限结果清空，真实零值中性展示。它不证明业务口径正确，也不自动发布。

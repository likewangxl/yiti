```java
private List<KpiCardItem> buildStats(String orgCode, LocalDate dataDate) {
    List<String> metricCodes = DashboardPresidentMetrics.CORE_METRICS;

    // 当日值（与原 summaryMetrics 复用）
    Map<String, BigDecimal> currMap = safeGetOrgMetrics(orgCode, dataDate, metricCodes);
    // 月初值（环比基准；缓存在 Redis）
    Map<String, BigDecimal> prevMap = safeGetOrgMetrics(orgCode, dataDate.withDayOfMonth(1), metricCodes);

    return DashboardPresidentMetrics.KPI_CARD_METRICS.stream()
        .map(meta -> {
            BigDecimal curr = currMap.get(meta.getMetricCode());
            BigDecimal prev = prevMap.get(meta.getMetricCode());
            TrendFormatter.Result r = TrendFormatter.format(curr, prev);
            return new KpiCardItem(meta.getMetricCode(), meta.getLabel(),
                                    curr, meta.getUnit(), r.text(), r.type());
        })
        .collect(Collectors.toList());
}
```

#### GREEN：TrendFormatter 实现

```java
public final class TrendFormatter {
    public static Result format(BigDecimal curr, BigDecimal prev) {
        if (curr == null || prev == null || prev.signum() == 0) {
            return new Result("--", "flat");
        }
        BigDecimal pct = curr.subtract(prev)
            .divide(prev, 4, RoundingMode.HALF_UP)
            .multiply(BigDecimal.valueOf(100))
            .setScale(1, RoundingMode.HALF_UP);
        if (pct.signum() > 0) {
            return new Result("↑ 较月初 +" + pct + "%", "up");
        } else if (pct.signum() < 0) {
            return new Result("↓ 较月初 " + pct + "%", "down");
        } else {
            return new Result("较月初 0.0%", "flat");
        }
    }
    public record Result(String text, String type) {}
}
```

- [ ] **Step 2.1**: dispatch executor subagent

  **Subagent prompt**:
  > 修 4 个文件中的 30 处小写表名 → 大写：
  >
  > - `bootstrap/src/test/resources/it/perf-fake-data.sql`：emp_index_result, perf_target_value, perf_kpi_item, perf_kpi_scheme, perf_metric_def, sys_control, portal_shortcut（约 15 处 DELETE/INSERT）
  > - `bootstrap/src/test/resources/customer-marketing-data.sql`：cust_master, cust_lead, cust_claim, cust_tag, cust_tag_rel, lead_import_batch, touch_log, touch_task（约 9 处 DELETE/INSERT）
  > - `bootstrap/src/test/resources/business-application-data.sql`：loan_apply, support_request（约 4 处 DELETE/INSERT）
  > - `bootstrap/src/test/resources/flowable-real-env-data.sql`：wf_node_candidate_conf（约 2 处 INSERT）
  >
  > **方法**：
  > 1. 用 sed 或 Edit 工具按 `\b<table_name>\b` 词边界替换
  > 2. **保护**：列名（非表名）不动；字符串字面量（'xxx' 内的小写名）不动
  > 3. 改完后跑 `grep -n "create table [a-z]\|insert into [a-z]\|FROM [a-z_]\|UPDATE [a-z]\|DELETE FROM [a-z]\|update [a-z]\|delete from [a-z]" <file>` 确认 0 残留
  > 4. **不跑** mvn verify（main agent 在 P4 跑）
  > 5. 完成后 git add + commit message: "fix(v1.9): bootstrap test data SQL 表名大写化（4 文件 30 处）"
  > 6. 不要 push
  >
  > **报告格式**：每文件改动行数 + 残留扫描命令输出

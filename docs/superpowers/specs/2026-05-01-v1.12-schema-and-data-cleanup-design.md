## § 2. 设计方案（4 项 fix）

### 2.1 # 2 MetricScheduledE2EIT cleanup

**症状**：MetricScheduledE2EIT 反复跑时 INSERT 'E2E_M_V1_7' 报 PERF_METRIC_DEF.uk_metric_code Duplicate。

**根因**：IT @Sql 加载未含 PERF_METRIC_DEF 的 DELETE WHERE metric_code='E2E_M_V1_7'。

**修复**：
- 选项 A（最小）：IT @Sql 加 BEFORE_TEST_METHOD `DELETE FROM PERF_METRIC_DEF WHERE metric_code='E2E_M_V1_7'`
- 选项 B（彻底）：IT @AfterEach 显式清理（不依赖 @Sql）
- **选定 A**（更简单 + 与项目其他 IT cleanup pattern 一致）

### 2.2 # 5 onepl_test_bootstrap schema column drift

**症状**：customer-marketing-schema.sql 用 `CREATE TABLE IF NOT EXISTS` 不更新现有表的列；onepl_test_bootstrap 旧表缺 V1.6+ 新加列（如 TOUCH_TASK.sla_warning）。

**根因**：测试库长期累积 + schema.sql 无 ALTER 兜底。

**修复**：
- **选项 A（一次性）**：写 cleanup SQL `docs/superpowers/sql/2026-05-01-v1.12-schema-column-drift-fix.sql` —— ALTER 加缺列 + 注释说明
- **选项 B（永久）**：customer-marketing-schema.sql 改 DROP TABLE + CREATE TABLE
- **选定 A + 注释**：A 一次性修复现役实例 + schema.sql 加注释提醒未来 IT 用 V1.10 onepl_test_bootstrap 之上重启 schema 时小心

**audit 范围**：检查 8 张 customer 表（cust_tag/cust_tag_rel/cust_lead/cust_master/cust_claim/touch_task/touch_log/lead_import_batch）vs customer-marketing-schema.sql 列定义，找出 drift。

### 2.3 # 6 DROP 8 customer 小写历史表

**症状**：mysql lower_case_table_names=0 case-sensitive，业务用大写 `CUST_MASTER` 等，但小写 `cust_master` 等历史表共存（V1.10 治理前手工建的）。

**风险评估**：
- 7 张小写表 = 0 行 → 安全 DROP
- **`cust_master` 小写表 = 1 行**（未知数据来源）→ **需用户审批处置**
  - 选项 a：dump 备份后 DROP
  - 选项 b：保留小写表（不影响业务，只是冗余）
  - 选项 c：先看 cust_master 1 行内容，决定是否迁移到大写表

**修复**：
- 写 cleanup SQL 含：先 dump 8 表到 `docs/superpowers/sql/backup/2026-05-01-v1.12-customer-lowercase-tables-backup.sql` → DROP 8 表
- **关键审批点**：cust_master 1 行处置策略（用户决定）

### 2.4 # 7 BusinessApplicationCenterIT 数据残留

**症状**：每次跑 IT 后 LOAN_APPLY/SUPPORT_REQUEST 累积，反复跑 → 多个 IN_APPROVAL 状态行 → 断言 `runningLoanCount=1` 实际 2 fail。

**根因**：bootstrap test resources 下 `business-application-data.sql` 不存在（仅 schema.sql），无 DELETE cleanup 段。

**修复**：
- 新建 `bootstrap/src/test/resources/business-application-data.sql` 含 DELETE 段（pattern 同 customer-marketing-data.sql）
- BusinessApplicationCenterIT @Sql 加引用此 data.sql
- 验证反复跑 3 次都通过

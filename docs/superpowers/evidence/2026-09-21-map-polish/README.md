# 地市引导标注美化与目标水位图

## 结果

- 地市标签左右各5行等距排列，用稳定地市配色连接标签、曲线及地理锚点。
- 三次贝塞尔曲线加水平收尾；有数据实线、缺失数据低亮度虚线；hover/focus强调对应曲线，减少动态效果设置关闭流动动效。
- 地市详情含当前授权范围的机构/定位数量、7项已有经营指标、机构名单和日期。城市汇总优先；单机构回退显式标明范围，多机构不擅自合计，0与缺失区分，万元不误作亿元。
- 完成率只使用一个水位图，删除重复进度条。区间为 <60 珊瑚色、60–<80 暖金色、80–<100 蓝青色、≥100 绿色，属于视觉进度分段，不作为业务风险判断。
- 水位限制在0–100，真实百分比保留；0不绘制水体、100及超额为满水位。使用组件实例唯一SVG ID，避免多实例/热更新渐变串色。

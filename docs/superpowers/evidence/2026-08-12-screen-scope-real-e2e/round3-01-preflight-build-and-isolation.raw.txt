## 精确端口与数据库身份

~~~text
$ ss -ltnp '( sport = :18082 or sport = :8092 or sport = :30523 )'

$ <受控环境变量> mysql -h127.0.0.1 -P3306 -uroot -D yiti_test -N -B -e 'SELECT DATABASE()'
~~~

没有监听或连接占用 18082、8092、30523。上述数据库命令仅连接 yiti_test。

## 三个隔离闸门的 artifact hash

初检发现 target/classes、模块 jar 与本地 Maven runtime jar 不一致，按授权仅执行根目录构建：

~~~text
$ mvn -Dstyle.color=never clean install -DskipTests
~~~

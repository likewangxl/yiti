## 前端和 8092 -> 18082

~~~text
$ env VITE_USE_MOCK=false VITE_API_BASE=/api \
  VITE_DEV_HOST=127.0.0.1 VITE_DEV_PORT=8092 \
  VITE_DEV_STRICT_PORT=true \
  VITE_PROXY_TARGET=http://127.0.0.1:18082 \
  npm run dev

VITE v4.5.14 ready
Local: http://127.0.0.1:8092/
~~~

官方 CLI 对 http://127.0.0.1:8092/api/... 的大屏相关请求均返回 200；启动命令明确把唯一 Vite /api 代理目标设为本轮唯一后端监听 127.0.0.1:18082，而端口预检和最终端口检查均排除了另一服务。由此可确认这些 8092 API 请求经此受控 Vite proxy 到达本轮 18082 handler。该结论是由代理配置、唯一监听和实际 200 响应组成的运行态链路推断；请求明细见 round3-08-console-and-request-methods.md。

# 分行经营总览地图引导标注

## 变更范围

省级分行总览启用地市两侧折线引导标注。地理锚点保持真实行政中心，标签在屏幕空间排布；其他地图默认标注保持兼容。当前机构信息改为地图下方正常文档流，保证地图、机构卡与趋势区不重叠。

## 浏览器环境

- 官方 `playwright-cli`，独立会话 `map-callout`。
- 路由 `http://127.0.0.1:8092/#/screen-preview`。
- 使用页面自带并明确标识的本地演示数据，**仅开发态演示，非真实业务数据联调**。
- route/拦截器注册清单：空。没有调用 route、routeFromHAR 或改写接口响应；前端资源访问本地 Vite 服务。
- `commands.jsonl` 归档真实命令与原始输出；包括初始失败断言及修复后验证。
- `before.png` 为修改前地市标签效果。
- `check-labels.js` 检查10个地市的标签、连线数量、越界、标签互相重叠及控件遮挡。

## TDD

`dashboard-red.log` 记录新增分行地图标注模式断言失败（未启用 callout）；`dashboard-green.log` 记录修复后通过。浏览器验证还复现了选中机构后1366窗口地图仅144px的问题，修复后地图高度超过280px且机构卡位于地图下方。

## 最终结果

- 最终独立浏览器会话：`map-callout-final`；`route-list` 返回 `No active routes`。
- 7 个测试文件、53 项测试全部通过，见 `tests.log`。
- Vite 生产构建通过，见 `build.log`。现有 Sass API 与大包提示不影响构建。
- 1920×1080、1366×768：10 个城市标签及10条连线，无标签重叠、越界或控件遮挡。
- 1366选中机构后地图约289px高，机构卡与地图、趋势区无重叠。
- 放大后引导线跟随投影，重置后恢复原锚点。
- 点击榆林市标签进入榆林市支行经营全景，返回全省正常。
- 人工触发 `webglcontextlost` 验证二维回退。10 个引导线起点与对应地市标记屏幕坐标误差最大约0.06px，窗口缩放后仍一致。
- 最终会话无JavaScript错误；WebGL Context Lost警告为主动回退验收所触发。
- `after-1920.png` 为三维引导标注；`fallback-1366.png` 为二维回退。
- 本次不修改业务数据或API契约。演示数据视觉验证不能替代真实数据源联调。

## § 3. 改造前后链路对比

### Before（H1 触发链路）

```
Tx1 (txPublisher) commit
  → AFTER_COMMIT → Tx2 (onProcessCompleted REQUIRES_NEW)
    → Tx3 (reconcileApproved REQUIRES_NEW)
      → conditionalUpdate (Tx3) Updates: 1  ✅
      → publishEvent(LeadApprovedEvent) [bound to Tx3 sync]
    → Tx3 commit
      → AFTER_COMMIT → LeadApprovedListener.handle (no @Transactional)
        → assembler.assembleFromLead (@Transactional REQUIRED)
        → Tx4: mybatis "INSERT INTO CUST_MASTER ... Updates: 1" + "committing"
        → ❌ Tx4 实际不持久化（thread-local sync state 异常）
    → Tx2 commit (空)
```

### After（方向 C 链路）

```
Tx1 (txPublisher) commit
  → AFTER_COMMIT → Tx2 (onProcessCompleted REQUIRES_NEW)
    → Tx3 (reconcileApproved REQUIRES_NEW)
      → conditionalUpdate (Tx3) Updates: 1  ✅
      → 同步调 assembler.assembleFromLead (@Transactional REQUIRED, join Tx3)
      → INSERT INTO CUST_MASTER (Tx3) Updates: 1  ✅
    → Tx3 commit  ✅ conditionalUpdate + INSERT 一起 persist
    → Tx2 commit (空)
```

**关键**：方向 C 消除嵌套 AFTER_COMMIT listener 链，conditionalUpdate + INSERT 在 Tx3 内一起 commit，cust_master 真持久化。

## § 4. 副产品发现（V1.11 候选延伸事项）

D-1 实施过程中发现两个 V1.10 测试库治理延伸问题，转 V1.11 候选：

### # 6 onepl_test_bootstrap.TOUCH_TASK 缺 sla_warning 列

- **症状**: CustomerMarketingCenterIT 报 `Unknown column 'sla_warning' in 'field list'`
- **根因**: `customer-marketing-schema.sql` 含 sla_warning，但 `CREATE TABLE IF NOT EXISTS` 不更新现有表；onepl_test_bootstrap.TOUCH_TASK 是 V1.6 之前创建的旧 schema（无 sla_warning 列）
- **临时修复**: `ALTER TABLE TOUCH_TASK ADD COLUMN sla_warning TINYINT DEFAULT 0`（已在本机 mysql 执行）
- **彻底方案（V1.11 候选）**: 全 customer 表 schema column drift audit + 自动修复脚本（schema.sql 改为 DROP + CREATE 或加 ALTER 补丁）

### # 7 onepl_test_bootstrap 同时存在 8 个 customer 小写历史表

- mysql 实测：`CUST_MASTER` (大写，V1.10 治理后业务表) + `cust_master` (小写，V1.10 治理前历史) 同时存在
- 全 8 张：cust_master / cust_lead / cust_claim / cust_tag / cust_tag_rel / touch_task / touch_log / lead_import_batch
- mysql `lower_case_table_names=0` 严格 case-sensitive 让两版本共存
- **V1.11 候选**: 写 cleanup SQL 在 onepl_test_bootstrap DROP 全部 customer 小写历史表

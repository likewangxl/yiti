# 红色引擎初始化与配置要求

> 本文只记录当前有效的菜单、资源、角色和依赖要求，不包含 DDL/DML 或环境执行结果。授权数据由 auth-permission-center 按审批流程维护。

## 1. 前置条件

- auth-permission-center 提供 PT_USER、CurrentUserApi、UserApi 和 RED_ENGINE 资源授权；
- system-governance-center 提供 DictApi、FileApi、JobApi、AuditApi 和平台锁；
- 党组织树及用户党组织映射可用；
- FileApi 对任务附件、材料附件和导出文件的上传/下载权限已配置；
- Quartz 启用时，JobApi 可注册固定任务窗口补偿任务。

红色引擎自管任务和材料审核状态，不接 workflow-center/Flowable，不初始化流程定义或流程表。

## 2. 菜单

当前菜单按功能覆盖：

- 首页与报表：M_RE_REPORT；
- 材料记录：M_RE_RECORDS；
- 任务工作台：M_RE_BRANCH_WORK、M_RE_REVIEW_WORK；
- 任务管理：M_RE_TASK_MGMT；
- 党组织管理：M_RE_ORG_MANAGE；
- 用户党组织映射：M_RE_USER_MAP；
- 驾驶舱和预警：M_RE_COCKPIT、M_RE_WARNING。

菜单可见性只控制导航，不替代接口资源和 Service 层数据范围。

## 3. REST 资源范围

PT_RESOURCE 至少覆盖当前 Controller 的以下资源族，并与 HTTP 方法、路径和 BizAuth 一致：

- /api/re/home/**：首页汇总、排名、预警、逾期查询和逾期处理；
- /api/re/tasks/**：任务管理、可选员工、任务填报、附件；
- /api/re/reviews/tasks/**、/api/re/tasks/branch-review/**、/api/re/tasks/org-review/**：支部/组织任务工作台兼容路径；
- /api/re/orgs/**、/api/re/user-party-maps/**：组织和用户映射；
- /api/re/submits/**、/api/re/reviews/**：材料上报及材料审核；
- /api/re/tasks/{taskId}/exports、/api/re/task-exports/**：任务导出及下载；
- /api/re/cockpit/**：仍由 Controller 提供的驾驶舱兼容入口。

旧年度归档、旧同步导出和不再使用的逾期执行资源保持停用状态，不得通过通配资源重新开放；兼容路径是否可调用以 PT_RESOURCE 当前状态为准。

## 4. 角色边界

| 角色 | 当前职责 |
| --- | --- |
| R_RE_REPORT | 材料上报、报送员任务列表/提交和本人附件 |
| R_RE_SECR | 本支部材料审核及支部任务工作台 |
| R_RE_ORGREV | 组织任务查询/发布、组织审核、组织管理、映射、附件和任务导出 |
| SYS_ADMIN | 在 RED_ENGINE 资源授权范围内执行管理、审核、导出和逾期处理；仍受 Service 实体校验 |

R_RE_BRREV 不作为当前有效角色授予入口。partyRole 字段只用于任务分配/展示，不自动授予以上角色。

## 5. 字典与调度

任务明细项通过治理 DictApi 读取 RE_ITEM_CODE，并在任务/导出服务中校验启用编码；红色引擎不复制 SYS_DICT 或维护本地字典投影。

任务窗口补偿只允许 JobApi 的固定 jobKey RED_ENGINE_TASK_WINDOW 和红色引擎固定 Job 类；请求不得传入任意 jobKey、类名或 Cron。默认情况下 `spring.quartz.enabled` 与 `redengine.task.scheduler.enabled` 均未设置即按启用处理；两者任一显式为 `false` 时不装配红色引擎任务调度器。`branch-dashboard-e2e` 与 `redengine-task-e2e` 联调时恢复内存 Quartz，但将 `redengine.task.scheduler.enabled=false`，只运行分行大屏批次任务。

## 6. 文件边界

任务允许文件类型、提交版本附件和导出结果只保存 FileApi 返回的对象编号与展示快照。下载前必须校验任务、assignment、提交版本、操作者和数据范围；不直接读 FILE_OBJECT、OBS 或治理 Mapper。

## 7. 配置验收

部署验收应只读核对：

1. 当前 Controller 路径与 PT_RESOURCE 方法匹配；
2. 四类角色只拥有表中职责范围，停用资源未被角色重新授权；
3. RE_ITEM_CODE 启用项可被任务创建和导出校验；
4. FileApi、JobApi、CurrentUserApi/UserApi 和审计链路可调用；
5. 任务发布、填报、两级审核、附件访问、导出和逾期处理均按 03 文档完成最小闭环。

环境特定的授权脚本、数据值和验收命令存放在受控部署工单，不写入本文。

# 10-目标设计：材料计分线与任务扣分线重构（规划态）

> **状态：规划态，2026-09-05 评审共识，尚未实现。**
> 本文描述的是目标设计，不是当前实现。当前实现以源码、`03`–`09` 文档和 `red-engine-center/AGENTS.md` 为准。
> 本文与现状冲突之处即为待改造项；实施前不得把本文内容当作已交付能力引用。

## 1. 背景与要解决的现状问题

现状核查（2026-09-05，基于源码与文档）发现以下问题，是本设计的动因：

1. 前端组织审核员工作台对四维材料调用材料审核接口（`/api/re/reviews/{id}/approve`），但后端 `ReReviewService` 守卫只认 `R_RE_SECR`/`SYS_ADMIN`（`RE-40302`），组织审核员审核四维材料在现状下不成立。
2. 材料审核无状态前置校验，允许改判覆盖（旧兼容行为）；任务线有严格状态白名单，两套语义并存。
3. 支部审核通过后需手动「提交组织」，非自动流转。
4. 逾期扣分执行为 `SYS_ADMIN` 专属，业务角色无法处理。
5. 年度归档为断链死代码（`generateAnnualResult` 无 REST 入口且跨年混算；前端 `ArchiveView` 调用不存在的 API）。
6. 四维材料与任务通过 `RE_TASK_RE_SUBMIT_REL` 桥接，是现状复杂度和前后端矛盾的主要来源。

## 2. 总体结构：两条完全独立的业务线

四维材料与任务彻底解耦，取消桥接。组织审核员不能创建四维材料类型的任务；四维材料不出现在报送员的任务处理页。

| | 四大维度材料线（计分线） | 任务线（扣分线） |
|---|---|---|
| 入口 | 报送员随时上报，无窗口、无期限 | 组织审核员建任务，有窗口 |
| 审核链 | 支部书记（不打分）→ 自动流转 → 组织审核员（通过时计分） | 支部书记 → 自动流转 → 组织审核员（不计分） |
| 分值 | 按材料类型配置分值，类型有上限 | 不得分 |
| 逾期 | 不适用 | 进待扣分列表，组织审核员执行 |
| 状态机 | 收紧：过审不可改判 | 严格白名单（维持现状） |

## 3. 四大维度材料线

### 3.1 流程与状态机（目标）

```text
报送员上报（携带"所属年度"，默认当前自然年、可修改，审计留痕）
  -> 1 待支部审
  --支部书记通过--> 4 待组织审（自动流转，无手动"提交组织"）
  --支部书记驳回--> 3 已驳回
4 --组织审核员通过--> 2 已通过（自动计分，写 RE_SCORE）
4 --组织审核员驳回--> 3 已驳回
3 --报送员原记录重报--> 1 待支部审（重走全链路；该通道仅报送员可用）
```

- **状态前置收紧**：审核动作只允许在对应待审状态上执行；已通过/已驳回记录不可被审核员改判。本条推翻现状"允许改判"的兼容行为，属于已确认的产品决策，实施时同步修订 `red-engine-center/AGENTS.md` 的状态机章节。
- **重报**：驳回后报送员在原记录上修改内容/附件重新提交（`3→1`），不新建记录。重报与改判是不同动作：重报是报送侧行为，不受"不可改判"约束。
- **所属年度**：每条材料记录新增年度字段，默认当前自然年，报送员可改（支持年初补报上年度），变更留审计。年度下载按该字段过滤。
- 状态取值（1/4/2/3）为目标语义，具体编码与字典 `RE_SUBMIT_STATUS` 扩展在实施时确定。

### 3.2 计分规则

- 新建**材料类型分值配置表**：材料类型（枚举仍用字典 `RE_ITEM_CODE`）→ 默认分值 + 类型分数上限；由组织审核员在界面维护，带审计。
- 类型上限落在维度上限之内，维度框架保留：党建联建 35 / 业务提升 50 / 头雁与先锋 10 / 督导 5。
- 组织审核员终审通过时按类型配置自动带出分值；审核员**可下调、不可超过类型上限**。
- 计分写入点收敛到组织终审一处；支部书记审核不再写 `RE_SCORE`。
- 具体分值待定，由组织审核员通过配置表维护，不固化在代码中。

## 4. 任务线

### 4.1 流程

- 临时任务与定时任务的区别**仅在窗口生成方式**（组织审核员一次性手工创建 vs 按周期自动生成窗口实例），计分规则一致：均不得分。
- 审核链：报送员填报 → 支部书记审核 → **自动流转**至组织审核员终审（移除手动"提交组织"步骤）。
- 状态白名单、`assignment.current_version` 乐观并发等任务线现有机制维持不变。

### 4.2 待扣分列表与扣分执行

- **进入条件**（窗口关闭时由调度自动生成待扣分记录，原因由系统按情形生成）：
  1. 窗口结束时从未上报；
  2. 组织驳回后，窗口结束前未重新上报；
  3. 支部驳回后，窗口结束前未重新上报。
- **明确排除**：支部已通过、组织尚未审完而窗口结束的情形不进待扣分列表（责任在审核侧）。
- **执行**：组织审核员在待扣分列表逐条执行/取消；执行守卫由现状仅 `SYS_ADMIN` 改为 `R_RE_ORGREV + SYS_ADMIN`。扣分分值默认 5 分，建任务时可按任务配置，执行时可调整；必填原因、独立 URL、独立审计维持现状高危操作要求。
- **扣分落点**：计入党支部考核分。红黄牌公式调整为 `total = 四维得分合计 − 扣分合计`，`final = total × 0.4`；阈值不变（红牌 <60，黄牌 60–80）。

## 5. 导出：四维材料年度下载（替代年度归档）

- 任务管理新增"四大维度材料下载"入口：选择年度 → 异步导出 ZIP，内容：
  1. 支部汇总 Excel：各维度得分、各类型得分、扣分、合计、红黄牌结果；
  2. 材料明细 Excel：每条材料的支部/维度/类型/分值/审核状态/审核人/审核时间；
  3. 全部附件按"支部/材料"目录打包。
- 按材料记录的所属年度字段过滤。
- 权限、幂等键、异步执行（PENDING→RUNNING→SUCCESS/FAILED）、归属校验与过期机制全部沿用现有任务导出体系；执行者为 `R_RE_ORGREV + SYS_ADMIN`。
- **年度归档死代码删除**：`generateAnnualResult`、`ArchiveView.vue`、相关 DTO；`RE_ANNUAL_RESULT` 表标记废弃，结构处置留 DBA 按审批流程处理。本期不再提供年度归档功能。

1. 报送员「任务处理」页：移除四维材料展示，只保留任务。

# 业绩调整 ·「原业绩分配」预览查询口径

> 适用页面：xanzc 前端 **新建调整申请**（以及查看/审批的只读回显）「原业绩分配」区。
> 最近核对：2026-08-25（支持 `NEW` 新开户维度及申请内 `ORIGIN` 原分配快照）。

## 1. 调用链路

```
Adjust.vue loadPreview()
  └─ GET /api/report/alloc-preview?custNo=&allocDim=&custType=&accountNo=&statisDt=
       └─ report: AllocPreviewController.preview(...)            // 只取 custNo + allocDim
            └─ perf: AllocApi.getLastApprovedAllocPreview(custId, allocDim)
                 └─ AllocAdjustPreviewService.getLastApprovedAllocPreview(custId, allocDim)
                      └─ CustAllocRelationMapper.selectCurrentOriginalByCust(custId, allocDim)
```

- 报表端点 `/api/report/alloc-preview` 还接收 `custType / accountNo / statisDt`，但**实际查询只用 `custNo(=custId)` + `allocDim`**，其余参数被忽略。
- 前端把 `dlg.form.custId` 作为 `custNo` 传给报表端点（cust_no 字段已并入 cust_id，值即用户输入的客户编号）。

## 2. 前端触发条件（Adjust.vue）

- 监听 `[dlg.form.custId, dlg.form.allocDim]`：当**客户编号长度 ≥ 2** 且（客户编号或分配维度）变化时，**防抖 600ms** 后调 `loadPreview()`。
- 查看 / 审批的**只读模式不实时查**，直接读提交时快照。
- `allocDim=NEW`（新开户）不要求原业绩分配，页面不应把其他维度的当前关系当作原分配。
- `hasOriginalOwners = (preview.allocList.length > 0)` —— 决定页面是"只读展示历史原业绩分配"还是"手工录入原业绩分配"，并影响"交原业绩所属人审批"是否可选。

## 3. 后端查询条件（权威口径）

当前新增/编辑页面的核心 SQL（`selectCurrentOriginalByCust`）：

```sql
SELECT <base columns>
FROM CUST_ALLOC_RELATION
WHERE cust_id = #{custId}       -- ① 客户编号匹配
  AND is_original = '2'         -- ② 当前生效分配
  -- allocDim=ACCOUNT 时追加 AND alloc_dim = 'ACCOUNT'
ORDER BY (alloc_dim = 'ACCOUNT'), emp_id ASC, id ASC;
```

### 条件汇总

| # | 条件 | 说明 |
|---|------|------|
| ① | `cust_id = 用户输入的客户编号` | cust_no 字段已删除并入 cust_id |
| ② | `is_original = '2'` | 只取当前有效的客户分配关系 |
| ③ | `alloc_dim` 维度过滤 | `allocDim=ACCOUNT` → 只查 ACCOUNT；`allocDim=RULE` 或空 → 查 **RULE + ACCOUNT 两维度并列**；`allocDim=NEW` → 直接返回空 |
| ④ | `ORDER BY (alloc_dim = 'ACCOUNT'), emp_id, id` | RULE 优先、ACCOUNT 其次，并保持员工及明细顺序稳定 |

## 4. 关键说明

- 新增/编辑时的自动预览来源是实时 `CUST_ALLOC_RELATION` 当前有效关系；保存草稿或提交时，后端将该关系复制为申请内 `ORIGIN` 快照，后续编辑和详情优先使用快照，避免当前关系变化覆盖申请内容。
- 申请详情优先读取该申请内已保存的 `ORIGIN` 快照；旧数据或 RULE/ACCOUNT 草稿缺少 ORIGIN 快照时，才回退当前有效关系。`NEW` 维度不回退当前关系。
- 员工工号 / 姓名 / 部门 / 比例直接读**明细行提交时的快照字段**（`username / emp_chn_name / org_code / org_name / ratio`），不再关联 `PT_USER` / 机构表；快照 `username` 为空（历史旧数据）时回退展示工号。
- 某维度查不到记录 → 该维度返回空，前端转为"手工录入原业绩分配"。
- `custId` 为空 → 直接返回空列表，不查表。

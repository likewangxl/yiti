# 绩效计算中心依赖契约摘要

> 本文仅给出本模块实际使用的边界；完整契约以被依赖模块的 api/、DTO 和源码为准。禁止跨模块引用 mapper、entity、内部 Service 或私有表。

## 1. 依赖关系

| 模块 | 当前用途 |
| --- | --- |
| auth-permission-center | CurrentUserApi、UserApi、数据范围和权限上下文 |
| system-governance-center | DictApi、AuditApi、NotifyApi、FileApi、JobApi、LockManager 及公共缓存/Web |
| workflow-center | 流程启动/审批查询以及 ProcessCompletedEvent |
| customer-marketing-center | 客户主数据和 CustomerQueryApi |
| portal-content-center | 员工/通讯录等公开查询 |

模块不直接调用 Flowable；流程引擎访问集中在 workflow-center。对象文件统一通过治理 FileApi，当前实现由治理侧写入 OBS。

## 2. 本模块对外 Java API

其他模块只能依赖本模块 api/ 下的接口和 DTO：

| API | 当前能力 |
| --- | --- |
| AllocApi | 当前/历史客户分配、按员工/客户批量查询、分配汇总、版本和原分配预览 |
| CustStatQueryApi | 从客户主数据按客户编号取得客户名称 |
| DataTaskApi | 接收数据任务状态上报并返回受理/幂等结果 |
| EvalQueryApi | 评价任务摘要查询 |
| KpiApi | 当前 KPI、历史 KPI、方案和评价员工查询 |
| MetricApi | 指标定义、指标卡片、员工/机构/客户指标值和最新数据日期 |
| MetricQueryApi | 员工/机构/客户指标快照批量查询 |
| PerfApprovalCmdApi | 分配调整提交、撤回和审批 |
| PerfApprovalQueryApi | 审批待办/已办、我的申请和详情 |
| PerfCalcApi | 指标/KPI/回算触发和运行任务查询 |
| TargetApi | 目标方案和目标值查询 |

调用方不得假设内部实体字段、宽表列或任务线程的实现细节；参数、空值和异常以对应 Java 方法签名及 DTO 为准。

## 3. 治理模块契约

### DictApi

评价导入读取 EVAL_IMPORT_TYPE、EVAL_WEIGHT_TAG、EVAL_SCORE_TYPE 等字典。字典项由治理模块管理，业务代码负责对需要强校验的值再次校验。

### AuditApi

高风险计算、版本、导入、审批和导出操作通过统一审计组件留痕。业务模块传递资源、动作、操作者、traceId、原因和最小必要摘要，不自行写平行审计表。

### FileApi

导入源文件、错误文件、评价模板、任务附件和导出结果均以 FileApi 文件引用流转。下载前校验业务对象和数据范围，禁止把 objectId 当作直接可访问的存储地址。

### JobApi

指标调度同步和注销使用 JobApi。指标是否可调度由本模块定义和状态决定；当前注册入口短路，不在本模块直接操作 Quartz 表。治理侧的任务配置才是最终运行事实。

### LockManager

SYS_CONTROL 切换/回滚、槽位分配、数据任务上报幂等和 KPI 级联防重使用平台 LockManager。锁失败按业务错误返回，释放失败依靠租期/平台清理，不在业务模块引入另一套锁服务。

## 4. workflow-center 协作

分配调整和目标调整通过 workflow-center 的公开命令/查询契约启动或查询流程。完成事件按业务键筛选，绩效在 AFTER_COMMIT 后独立事务落地批准结果：

- 分配调整批准写入客户分配关系，拒绝只更新申请；
- 目标调整批准 upsert 目标值，拒绝不改目标值；
- 重复事件按业务键/申请状态幂等处理；
- 流程候选人和 Flowable 细节不在绩效模块复制。

## 5. 数据范围与返回语义

公开查询 API 返回 DTO，服务层按调用方身份和业务对象应用数据范围。当前版本由 SYS_CONTROL 解析，批量快照查询不允许调用方绕过版本边界。空结果、缺少有效版本和跨范围对象按各 API 的明确返回/异常契约处理，不以数据库直读替代。

## 6. 契约变更

修改 api/、DTO、错误码或 BizAuth 时，必须同步 03 文档、PT_RESOURCE 和契约检查脚本。依赖方只能使用新增的公开方法；禁止为了兼容而把内部 mapper、实体或 SQL 暴露为跨模块接口。

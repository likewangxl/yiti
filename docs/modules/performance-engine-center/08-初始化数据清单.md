# 绩效计算中心 — 初始化数据清单

> 模块: performance-engine-center
> 版本: v1.0
> 最后更新: 2026-04-10

本文档列出绩效计算中心首次部署上线时需要预置的数据, 包括字典、V1 示例指标、KPI 方案、定时任务、资源登记、`sys_control` 初始化等。所有初始化数据需要通过 `docs/sql/init-performance.sql` 脚本一次性导入。

## 1. 预置字典引用

本模块所需的所有字典均由 `system-governance-center` 的 `DICT_*` 表统一管理。在 performance 启动前, 以下字典必须存在于 `gov_dict` 与 `gov_dict_item` 表中, 可通过 `DictApi.getDictItems(dictCode)` 读取。

### 1.1 基础维度字典

| dict_code | 字典名 | 字典项 (value/label) |
|---|---|---|
| `PERF_BASE_DIM` | 绩效基础维度 | `EMP` / 员工; `ORG` / 机构; `CUST` / 客户 |
| `PERF_TARGET_DIM` | 目标维度 | `EMP` / 员工目标; `ORG` / 机构目标 |

### 1.2 计算相关字典

| dict_code | 字典名 | 字典项 (value/label) |
|---|---|---|
| `PERF_CALC_FREQ` | 计算频率 | `DAY` / 每日; `MONTH` / 每月; `QUARTER` / 每季; `YEAR` / 每年 |
| `PERF_CALC_MODE` | 计算方式 | `AUTO` / 自动计算; `MANUAL` / 手工导入 |
| `PERF_CALC_LOGIC_TYPE` | 计算逻辑类型 | `SQL` / SQL 查询; `PROC` / 存储过程; `EXPR` / 表达式; `SUMMARY` / 聚合规则 |
| `PERF_METRIC_LEVEL` | 指标级别 | `1` / 一级; `2` / 二级; `3` / 三级 |

## 4. 定时任务配置

在 `system-governance-center` 的 `sys_job_conf` 表中注册本模块的定时任务。

### 4.0 定时任务汇总表（2026-04-10 新增）

以下是本模块注册的全部定时任务一览。各任务详细 INSERT 语句见 §4.1-§4.5。

| # | job_code | 任务名称 | cron_expression | 执行时机 | 前置依赖 | 执行时长预期 | 失败处理 | 关键参数 |
|---|---|---|---|---|---|---|---|---|
| 1 | `DAILY_ALLOC_SYNC` | 每日分配关系同步 | `0 0 1 * * ?` | 每日 01:00 | 无 | < 10 min | 通知资财部 | `batchSize=1000` |
| 2 | `DAILY_METRIC_CALC` | 每日指标计算 | `0 0 2 * * ?` | 每日 02:00 | `DAILY_ALLOC_SYNC` | 30-60 min | 通知数据运维 + 延后 `DAILY_KPI_CALC` | `scopeDim=EMP`, `includeLevels=[1,2,3]` |
| 3 | `DAILY_KPI_CALC` | 每日 KPI 计算 | `0 0 3 * * ?` | 每日 03:00 | `DAILY_METRIC_CALC` | 20-40 min | 通知资财部，次日重跑 | `cycleTypes=[MONTHLY,QUARTERLY]` |
| 4 | `CLEAN_PERF_RUN_TASK` | 绩效任务日志清理 | `0 0 4 1 * ?` | 每月 1 日 04:00 | 无 | < 5 min | 仅告警 | `retainMonths=3` |
| 5 | `PERF_PARTITION_MAINTAIN` | 结果表分区维护 | `0 0 0 25 * ?` | 每月 25 日 00:00 | 无 | < 2 min | 紧急告警（写入会失败） | `tables=[emp_index_result,...]` |

#### 执行顺序依赖图

```
01:00 ── DAILY_ALLOC_SYNC ───────┐
                                  │
02:00 ── DAILY_METRIC_CALC ◄──────┘（依赖分配关系已同步）
                 │
                 ├─ 发布 performance.sys-control.updated.v1
                 │
03:00 ── DAILY_KPI_CALC ◄─────────┘（依赖指标计算完成）
                 │
                 └─ 发布 performance.kpi-calc.completed.v1

月末独立任务：
第 1 日 04:00 ── CLEAN_PERF_RUN_TASK（清理历史）
第 25 日 00:00 ── PERF_PARTITION_MAINTAIN（提前建分区）
```

#### 任务失败处理矩阵

| 任务 | 失败检测 | 告警方式 | 自动重试 | 手动恢复步骤 |
|---|---|---|---|---|
| `DAILY_ALLOC_SYNC` | `sys_job_run_log.status = FAILED` | 邮件 + 企业微信 → 资财部 | 不自动重试 | `POST /api/perf/alloc/sync-now` |
| `DAILY_METRIC_CALC` | 同上 | 邮件 + 短信 → 数据运维 + 延后启动 KPI 计算任务 | 不自动重试 | `POST /api/perf/metrics/{code}/execute` 单独重算失败的指标 |
| `DAILY_KPI_CALC` | 同上 | 邮件 + 短信 → 资财部 | 不自动重试 | `POST /api/perf/kpi-schemes/{id}/calc` 单独重算 |
| `CLEAN_PERF_RUN_TASK` | 同上 | 邮件 → 运维 | 下月自动执行 | 手动 DELETE SQL |
| `PERF_PARTITION_MAINTAIN` | 同上 | 短信 + 电话 → DBA（P0 告警） | 不自动重试 | `ALTER TABLE ... ADD PARTITION` 手动建分区 |

#### 参数化配置（通过 sys_config_kv 运行时可调）

| config_key | 默认值 | 说明 |
|---|---|---|
| `perf.job.metric-calc.timeout.minutes` | 90 | 指标计算超时时间 |
| `perf.job.kpi-calc.timeout.minutes` | 60 | KPI 计算超时时间 |
| `perf.job.alloc-sync.batch-size` | 1000 | 分配关系同步批次大小 |
| `perf.job.run-task.retain.months` | 3 | perf_run_task 保留月数 |
| `perf.job.enabled` | true | 全局开关（紧急场景可停所有任务） |
| `perf.job.notify.failure.channels` | `["EMAIL","WECHAT"]` | 失败通知渠道 |

修改参数后无需重启，由 `sys_job_conf` 的 `params_json` 字段热加载。

#### 与 governance JobApi 的集成

本模块通过 `governance.JobApi` 注册定时任务，由 `JobService` 负责调度：

```java
@PostConstruct
public void registerJobs() {
    // 系统启动时检查 5 个定时任务是否已存在，不存在则注册
    for (JobDef def : PERF_JOB_DEFINITIONS) {
        if (!jobApi.exists(def.jobCode())) {
            jobApi.register(def);
            log.info("注册定时任务: {}", def.jobCode());
        }
    }
}
```

```java
if (sysControlMapper.countByScopeDim(scopeDim) == 0) {
    SysControl init = new SysControl();
    init.setScopeDim(scopeDim);
    init.setLatestDataDate(firstImportDataDate);
    init.setCurrentVersion(generateVersion(firstImportDataDate));
    init.setIsValid(1);
    init.setRemark("首次导入自动初始化");
    sysControlMapper.insert(init);
}
```

```sql
-- 应返回 3 行, 每个维度各 1 条 is_valid=1 记录
SELECT scope_dim, COUNT(*) AS valid_count
FROM sys_control
WHERE is_valid = 1
```

```sql
-- 1. 检查字典项
SELECT COUNT(*) FROM gov_dict WHERE dict_code LIKE 'PERF_%';
-- 预期: ≥ 13 条

SELECT COUNT(*) FROM gov_dict_item WHERE dict_code LIKE 'PERF_%';
-- 预期: ≥ 50 条

SELECT COUNT(*) FROM perf_metric_def WHERE status = 1;
-- 预期: ≥ 5 条 (V1 示例指标)

-- 3. 检查 KPI 方案
SELECT COUNT(*) FROM perf_kpi_scheme WHERE status = 1;
-- 预期: ≥ 1 条

-- 4. 检查方案项权重之和
SELECT scheme_id, SUM(weight) AS total_weight
FROM perf_kpi_item
GROUP BY scheme_id
HAVING total_weight != 100;
-- 预期: 无结果 (权重之和必须 = 100)

-- 5. 检查定时任务
SELECT COUNT(*) FROM sys_job_conf WHERE job_group = 'PERF' AND status = 1;
-- 预期: ≥ 4 条

SELECT COUNT(*) FROM PT_RESOURCE WHERE biz_module = 'performance-engine-center';
```

## 0. 依赖强弱级别

| 级别 | 含义 | 故障处理 |
|---|---|---|
| **S（强依赖）** | 依赖不可用时 portal 核心功能不可用 | 直接返回错误 |
| **M（中等依赖）** | 依赖不可用时 portal 部分功能降级 | 降级返回（空列表、占位符） |
| **W（弱依赖）** | 依赖不可用时 portal 展示占位 | 静默降级，前端容错 |

### 1.1 CurrentUserApi — 当前用户上下文

| 方法签名 | 返回 | 异常 | portal 使用场景 | 调用频次 |
|---|---|---|---|---|
| `CurrentUserContext getCurrentUserContext()` | 当前用户完整上下文 | `UnauthorizedException` | Facade 层入口获取工号 + 机构 + 角色 | 每次请求 |
| `String getCurrentEmpId()` | 工号 | `UnauthorizedException` | 工作台按用户过滤 | 高频 |
| `String getCurrentOrgCode()` | 主机构编码 | `UnauthorizedException` | 产品维护权限判定、导航管理权限 | 高频 |
| `Set<String> getCurrentRoles()` | 当前用户角色集合 | `UnauthorizedException` | 判断是否管理员 | 中频 |

**CurrentUserContext 字段：**

```java
public class CurrentUserContext {
    private String empId;               // 工号
    private String empName;             // 姓名
    private String primaryOrgCode;      // 主机构 code
    private String primaryOrgName;      // 主机构名称
    private Set<String> roleCodes;      // 角色 code 集合
    private Set<String> orgCodes;       // 可访问的机构 code 集合
    private String deviceType;          // PC / MOBILE / H5
    private String traceId;             // 全链路追踪 ID
    private LocalDateTime loginTime;    // 登录时间
}
```

**portal 使用示例：**

```java
@RestController
public class WorkbenchController {
    @PostMapping("/api/portal/workbench/aggregate")
    @BizAuth(resource = "PORTAL_WORKBENCH_AGGREGATE")
    public Result<WorkbenchAggregateRespDTO> aggregate() {
        String empId = currentUserApi.getCurrentEmpId();
        return Result.success(workbenchFacade.aggregate(empId));
    }
}
```

**异常处理：**
- `UnauthorizedException` → portal 透传，由 `GlobalExceptionHandler` 转为 401
- 调用上下文缺失 → Session 过期，前端跳登录

**本地缓存：** 用户上下文在请求线程内通过 `ThreadLocal` 缓存，无需跨请求缓存。

### 1.2 BizScopeApi — 业务数据范围 / 写权限

| 方法签名 | 返回 | 异常 | portal 使用场景 |
|---|---|---|---|
| `DataScopeType resolveScope(String empId, BizType bizType)` | `ALL / ORG_SUBTREE / ORG_SELF / SELF` | - | 产品列表、通讯录列表、导航列表数据范围过滤 |
| `boolean checkWritePermission(String empId, BizType bizType, String ownerOrgId, String createdBy)` | true/false | - | 产品编辑/删除前的写权限校验 |
| `DataScopeCondition buildScopeCondition(String empId, BizType bizType)` | SQL WHERE 条件片段 | - | MyBatis Mapper 动态 SQL 注入 |

**BizType 枚举（portal 相关）：**

```java
public enum BizType {
    PRODUCT,        // 产品
    EMPLOYEE,       // 通讯录员工
    NAV,            // 导航
    SHORTCUT,       // 快捷入口
    DOC,            // 文档
    WORKBENCH       // 工作台（ORG_SELF）
}
```

**DataScopeType 语义：**

| 类型 | 含义 | 数据过滤方式 |
|---|---|---|
| `ALL` | 全行可见 | 无过滤 |
| `ORG_SUBTREE` | 当前机构及子机构 | `owner_org_id IN (子树 org codes)` |
| `ORG_SELF` | 仅当前机构 | `owner_org_id = 当前 org code` |
| `SELF` | 仅本人创建 | `created_by = 当前 emp_id` |

**DataScopeCondition 使用示例：**

```java
public PageResult<ProductListItem> listProducts(ListProductCmd cmd) {
    String empId = currentUserApi.getCurrentEmpId();
    DataScopeCondition scope = bizScopeApi.buildScopeCondition(empId, BizType.PRODUCT);
    return productMapper.pageWithScope(cmd, scope);
}
```

**Mapper XML 中的使用：**

```xml
<select id="pageWithScope" resultMap="ProductMap">
    SELECT * FROM product_info
    WHERE deleted = 0
      AND status = 'ACTIVE'
      <include refid="common.DataScopeFragment"/>
    ORDER BY updated_time DESC
    LIMIT #{offset}, #{limit}
</select>
```

**写权限校验示例：**

```java
@Transactional(rollbackFor = Exception.class, timeout = 5)
public void updateProduct(String productId, UpdateProductCmd cmd) {
    ProductInfo p = mapper.selectById(productId);
    boolean canWrite = bizScopeApi.checkWritePermission(
            currentUserApi.getCurrentEmpId(),
            BizType.PRODUCT,
            p.getOwnerOrgId(),
            p.getCreatedBy()
    );
    if (!canWrite) {
        throw new BizException(ErrorCode.NO_WRITE_PERMISSION);
    }
    // 执行更新
}
```

**失败策略：** Fail Close — 权限查询异常时视为无权限，抛出 `BizException(NO_WRITE_PERMISSION)`。

### 1.3 OrgApi — 机构信息

| 方法签名 | 返回 | 异常 | portal 使用场景 |
|---|---|---|---|
| `OrgDTO getOrg(String orgCode)` | 机构 DTO | `OrgNotFoundException` | 通讯录展示机构名、产品展示维护部门 |
| `Set<String> getOrgSubtreeCodes(String orgCode)` | 子树所有 code 集合 | - | 组织树数据范围展开 |
| `List<OrgDTO> listOrgsByCodes(Set<String> orgCodes)` | 批量机构列表 | - | 通讯录/产品列表批量回填机构名 |
| `List<OrgTreeNode> getOrgTree(String rootOrgCode)` | 机构树形结构 | - | 通讯录"按机构浏览"前端树 |

**OrgDTO 字段：**

```java
public class OrgDTO {
    private String orgCode;          // 机构编码
    private String orgName;          // 机构名称
    private String parentOrgCode;    // 父机构
    private String orgType;          // BRANCH / SUBBRANCH / DEPT
    private Integer orgLevel;        // 1=分行 2=支行 3=网点 4=部门
    private String regionCode;       // 区域
    private String status;           // ACTIVE / DISABLED
}
```

**portal 使用示例：**

```java
// 通讯录列表批量回填机构名
public List<EmployeeListItemDTO> listEmployees(ListEmployeeCmd cmd) {
    List<AddrbookEmployee> list = mapper.list(cmd);
    Set<String> orgCodes = list.stream().map(AddrbookEmployee::getOrgCode).collect(Collectors.toSet());
    List<OrgDTO> orgs = orgApi.listOrgsByCodes(orgCodes);
    Map<String, String> orgCodeToName = orgs.stream()
            .collect(Collectors.toMap(OrgDTO::getOrgCode, OrgDTO::getOrgName));
    return list.stream()
            .map(e -> EmployeeConverter.toListItem(e, orgCodeToName.get(e.getOrgCode())))
            .collect(Collectors.toList());
}
```

**缓存策略：** 机构树相对稳定，portal 端可对 `getOrgSubtreeCodes` 结果缓存 10 分钟。

| 事件名 | 触发时机 | portal 处理 | 监听器类 |
|---|---|---|---|
| `auth.user.created.v1` | 新员工入职 | INSERT addrbook_employee | `AuthUserCreatedListener` |
| `auth.user.updated.v1` | 员工基础信息变更 | UPDATE addrbook_employee（非自维护字段） | `AuthUserUpdatedListener` |
| `auth.user.disabled.v1` | 停用/离职 | UPDATE status='RESIGNED' | `AuthUserDisabledListener` |
| `auth.user.org-changed.v1` | 机构变动 | UPDATE org_code + org_name | `AuthUserOrgChangedListener` |

public class DictItemDTO {

**portal 常用字典：**

```java
@GetMapping("/api/products")
public Result<PageResult<ProductListItem>> list(ListProductCmd cmd) {

    page.getRecords().forEach(item -> item.setCategoryName(categoryMap.get(item.getProductCategory())));
    return Result.success(page);
}
```

**缓存策略：** DictApi 内部已缓存，portal 无需再缓存。

### 2.2 NotifyApi — 通知服务

| 方法签名 | 返回 | 异常 | portal 使用场景 |
|---|---|---|---|
| `String sendNotification(NotificationCmd cmd)` | 通知 ID | `NotifyException` | 60 天提醒、产品变更通知 |
| `PageResult<NotificationDTO> queryNotifications(String empId, Boolean isRead, PageQuery page)` | 通知列表 | - | 工作台通知聚合 |
| `int countUnread(String empId)` | 未读数量 | - | 工作台未读角标 |
| `void markAsRead(String empId, List<String> notificationIds)` | void | - | 点击通知后标记已读 |
| `void markAllAsRead(String empId)` | void | - | 全部已读 |

**NotificationCmd 字段：**

```java
public class NotificationCmd {
    private String templateCode;           // 模板 code（必填）
    private String targetEmpId;            // 目标员工（必填，或用 targetEmpIds 批量）
    private List<String> targetEmpIds;     // 批量发送时使用
    private String bizType;                // 业务类型（portal 使用 ADDR_BOOK / PRODUCT / DOC）
    private String bizId;                  // 业务主键
    private Map<String, Object> params;    // 模板参数
    private String channel;                // INTERNAL / EMAIL / SMS / APP_PUSH，默认 INTERNAL
    private String priority;               // LOW / NORMAL / HIGH，默认 NORMAL
}
```

**NotificationDTO 字段：**

```java
public class NotificationDTO {
    private String id;
    private String title;
    private String content;
    private String bizType;
    private String bizId;
    private String jumpUrl;
    private Boolean isRead;
    private LocalDateTime createdTime;
    private String senderType;   // USER / SYSTEM
}
```

**portal 使用示例：**

```java
// 60 天提醒发送
NotificationCmd cmd = NotificationCmd.builder()
        .templateCode("ADDR_BOOK_STALE_REMIND")
        .targetEmpId(emp.getMaintainerEmpId())
        .bizType("ADDR_BOOK")
        .bizId(emp.getEmpId())
        .params(Map.of(
                "empName", emp.getEmpName(),
                "lastUpdate", DateUtil.format(emp.getUpdatedTime())
        ))
        .build();
notifyApi.sendNotification(cmd);

// 工作台聚合
int unreadCount = notifyApi.countUnread(empId);
```

**异常处理：** 通知发送失败不回滚业务事务，记录警告日志，依赖 NotifyApi 内部的重试机制。

**FileObjectDTO 字段：**

```java
public class FileObjectDTO {
    private String id;                  // 文件对象 ID
    private String originalName;        // 原始文件名
    private String storeKey;            // MinIO 存储 key
    private Long fileSize;              // 字节数
    private String mimeType;            // MIME 类型
    private String fileMd5;             // MD5
    private String bizType;             // 业务类型（可选）
    private String bizId;               // 业务主键（可选）
    private String uploadedBy;
    private LocalDateTime uploadedTime;
    private String status;              // ACTIVE / DELETED
}
```

**portal 使用示例：**

```java
// 文档上传
public String uploadDoc(MultipartFile file, String title, String category) {
    String empId = currentUserApi.getCurrentEmpId();
    FileObjectDTO fileObj = fileApi.upload(file, empId);
    try {
        return docService.createInTx(fileObj.getId(), title, category, empId);
    } catch (Exception ex) {
        fileApi.deleteFile(fileObj.getId());
        throw ex;
    }
}

// 产品附件关联
fileApi.attachBizRelation(fileObjectId, "PRODUCT", productId);
```

**业务类型约定（portal 使用）：**

| bizType | 说明 |
|---|---|
| `PRODUCT` | 产品主附件 |
| `DOC` | 文档中心文件 |
| `PRODUCT_ATTACHMENT` | 产品扩展附件（V2） |

**降级策略：**
- V1 performance-engine-center 模块未实现时，portal 端所有 metric 调用直接返回空列表
- 使用 `@ConditionalOnBean(MetricApi.class)` 或 `@Autowired(required = false)` 优雅降级
- 配置开关 `portal.dependency.performance.enabled=false` 彻底关闭

```java
@Service
public class MetricAdapter {
    @Autowired(required = false)
    private MetricApi metricApi;

    public List<MetricCardDTO> fetch(String empId) {
        if (metricApi == null) {
            return Collections.emptyList();
        }
        return metricApi.getUserMetricCards(empId);
    }
}
```

## 7. 依赖契约变更管理

1. **契约版本化**：所有 DTO 变更须升级 API 版本号（如 `auth-permission-center-api-1.0.0` → `1.1.0`），遵循 SemVer
2. **向后兼容**：新增字段允许，删除/修改字段必须提前在周会通知并给出适配期
3. **冲突解决**：portal 发现本文档与源文档冲突时，**以源文档为准**，并提 PR 修正本文档
4. **定期 Review**：每次版本发布前，portal 负责人需重新 review 本文档，更新签名与版本号

## 8. 跨模块调用规范红线

根据项目 CLAUDE.md 的模块间依赖规则：

1. portal **只能** 通过 `*Api` / `*QueryApi` 接口调用其他模块，**禁止** 直接依赖其他模块的 `mapper`/`entity`/`serviceImpl`
2. portal 的所有写操作必须先调用 `BizScopeApi.checkWritePermission()` 再执行
3. portal 的所有读接口必须应用 `DataScopeCondition` 做数据范围过滤
4. portal **不允许** 直接访问 Flowable API（必须通过 `WorkflowQueryApi`）
5. portal **不允许** 直接访问 MinIO SDK（必须通过 `FileApi`）
6. portal **不允许** 直接访问其他模块的 Redis key 命名空间

### 10.2 MyBatis 过滤片段（PORTAL_PRODUCT 完整示例）

```xml
<!-- ProductMapper.xml -->
<select id="listProducts" resultType="ProductEntity">
    SELECT * FROM product_info
    <where>
        AND deleted = 0
        <if test="keyword != null">AND product_name LIKE CONCAT('%', #{keyword}, '%')</if>
        <include refid="dataScopeFilter"/>
    </where>
    ORDER BY updated_time DESC LIMIT #{offset}, #{limit}
</select>

<sql id="dataScopeFilter">
    <choose>
        <when test="dataScope.type == 'ALL'"/>
        <when test="dataScope.type == 'ORG_SUBTREE'">
            AND product_dept_org_code IN
            <foreach collection="dataScope.orgSubtree" item="org" open="(" close=")" separator=",">#{org}</foreach>
        </when>
        <when test="dataScope.type == 'ORG_SELF'">
            AND product_dept_org_code = #{dataScope.orgCode}
        </when>
        <when test="dataScope.type == 'SELF_CREATED'">
            AND created_by = #{dataScope.empId}
        </when>
        <otherwise>AND 1 = 0</otherwise>
    </choose>
</sql>
```

# 门户与内容中心 — 功能规格

## 1. 文档定位

本文描述当前源码已经提供的门户能力：工作台、网址导航、快捷入口、通讯录、产品资料、文档、担保信息和公告。实现行为以 `portal-content-center/src/main/java`、Mapper 和运行配置为准；本文不是 DDL、初始化脚本或未来功能清单。

模块维护门户内容及用户门户配置，不持有客户、业务申请、绩效或报表核心状态。跨模块访问只能使用公开 `*Api`/`*QueryApi`，文件、通知和审计分别经治理中心公开 API。

## 2. 工作台与快捷入口

### 2.1 聚合内容

`GET /api/portal/workspace` 在当前登录上下文中返回：

- `todoCount`、`recentTodos`：由 `WorkflowQueryApi` 经 `WorkflowQueryAdapter` 查询；
- `unreadNotificationCount`、`recentNotifications`：由可选的治理 `NotifyApi` 查询；治理 Bean 不可用时返回 `0`/空列表；
- `metricCards`：由门户 `adapter.MetricApi` 查询，bootstrap 的 `PerformanceMetricApiBridge` 将绩效 API 投影到门户 DTO；桥接缺失或失败时返回空列表；
- `shortcuts`：系统级快捷入口与当前用户自定义入口；
- `aggregateErrors`：记录发生异常的聚合分支，不影响可用分支返回。

聚合查询并行执行，整体有超时和逐分支空值降级。工作台 Controller 与快捷入口 Controller 是“已登录即可访问”的明确架构例外，不据此推导其他接口免鉴权。`PortalApi.getWorkspace(String)` 的 Facade 当前从认证上下文取用户，调用方必须在有效登录请求中传入与上下文一致的员工标识。

### 2.2 快捷入口

`GET /api/portal/shortcuts` 的 `shortcutType` 支持：

| 值 | 结果 |
| --- | --- |
| 未传、空串、`ALL` | 系统级入口 + 当前用户的自定义入口 |
| `SYSTEM` | 仅系统级入口 |
| `CUSTOM` | 仅当前用户的自定义入口 |
| 其他值 | 空列表 |

`PUT /api/portal/shortcuts` 只接受当前用户的自定义入口列表，保存是全量替换（删除旧自定义记录后批量插入新记录）；系统级入口不受影响。请求项包含名称、URL、图标、目标类型（`INTERNAL`/`EXTERNAL`）和非负排序号，列表不能为空。

## 3. 网址导航

前台 `GET /api/nav` 返回按 `navCategory` 分组的导航。未指定分类和状态时只返回 `ACTIVE`；传分类时按该分类返回启用导航；传 `status=ALL` 返回全部状态；其他状态值按精确状态查询。导航按 `sortOrder` 升序。

管理端提供：

- `POST /api/admin/nav` 新增；
- `PUT /api/admin/nav/{id}` 部分更新；
- `DELETE /api/admin/nav/{id}` 将状态改为 `DISABLED`；
- `PUT /api/admin/nav/sort` 在一个事务中批量更新排序。

名称在同一分类的启用导航中不得重复；URL 必须通过 DTO 的 HTTP(S) 校验。新增、编辑、删除由服务层写审计日志，排序当前没有单独的审计调用。

## 4. 分行通讯录

### 4.1 数据和查询

员工主数据来自 auth 的 `UserDirectoryApi`：`PT_USER` 提供用户及联系方式，`EXT_USER_ORG`/`EXT_ORG_INFO` 提供主机构；门户不再读取或维护旧的 `ADDRBOOK_EMPLOYEE` 镜像。负责人关系来自门户用户—产品关系表。

`GET /api/employees` 查询在职用户，支持关键字、机构、分页参数。请求中保留的 `position`、`status` 只为兼容现有报文，当前服务不据此过滤，实际口径由 `pageActiveUsers` 的在职查询决定。`GET /api/employees/{empId}` 返回员工及负责产品简要信息；`GET /api/employees/search` 面向员工选择器，服务端限制返回规模。

跨模块 `AddressBookApi` 返回的手机号已脱敏；REST 详情为本人编辑场景保留联系方式原值。auth 三表没有岗位说明、自我描述来源，相关跨模块字段当前可为空。

### 4.2 自助维护

`PUT /api/employees/me` 不接受目标员工 ID，只允许维护：

- `mobile`：省略表示保留，空串表示清空；
- `email`：省略表示保留，空串表示清空；
- `responsibleProductIds`：省略表示不修改，传空列表表示清空关系。

服务层再次从认证上下文确定操作者，并校验所选产品存在、启用且支持中场支持，然后整组替换负责人关系。姓名、机构、岗位、状态等主数据不能由该接口修改。联系方式更新与关系替换处在同一门户事务边界内，但 auth 公开 API 的外部持久化不等同于同一数据库事务。

## 5. 产品资料库

产品主表为 `PRODUCT_INFO`，负责人单独存于用户—产品关系表，附件只保存治理 `FileApi` 的文件对象 ID。

- `GET /api/products` 支持关键字、类别、维护机构、是否支持中场支持、状态及分页，并应用 `BizScopeApi` 的产品数据范围；
- `GET /api/products/{id}` 返回产品和负责人 ID/姓名等展示信息；
- `GET /api/products/support-available` 只返回 `ACTIVE` 且支持中场支持的产品；
- `POST /api/products` 创建产品，校验产品代码唯一、维护机构权限和负责人在职状态；
- `PUT /api/products/{id}` 对非空字段部分更新，当前允许修改维护机构并同步归属机构；
- `DELETE /api/products/{id}` 逻辑删除，存在负责人关系时拒绝删除；
- `GET /api/products/export` 同步导出当前过滤结果，单次导出超过服务能力时拒绝请求，不伪装为异步任务。

产品新增、删除在服务层复核操作者的机构权限；编辑在行锁内执行部分更新，具体实体权限边界以当前服务实现为准。相关写操作和导出写审计。支持产品列表使用门户缓存，写入后尝试失效缓存。

## 6. 文档下载

文档主表为 `DOC_INFO`，`status` 使用 `ACTIVE`/`DISABLED`。当前 REST 能力为：

- `GET /api/documents`：按标题关键字、分类、状态分页查询；
- `GET /api/documents/{id}/download`：通过治理 `FileApi` 返回对象存储下载 URL；
- `POST /api/admin/documents`：新建文档，接收已上传文件对象 ID；
- `PUT /api/admin/documents/{id}`：部分更新标题、分类、文件对象或状态；
- `DELETE /api/admin/documents/{id}`：将文档置为 `DISABLED`，不删除文件对象。

文件由治理中心写入华为云 OBS；门户不直连对象存储客户端，也不把历史的本地路径或 MinIO 描述当作当前契约。

## 7. 担保信息

担保查询和维护使用 `zh_guarantee_info`，合同命中查询只读访问 `ccms_business_contract`。`GET /api/guarantee` 按客户名称分页，详情、新增、编辑、批量删除和导出均已提供；主键为数据库自增的 `Long`。

新增先按客户号和客户名称检查重复：命中合同记录时按合同记录批量落库并忽略表单金额，未命中时落库表单单条数据。手工金额按“万元”接收，清洗货币符号和千分位后按“元”保存，查询转换回“万元”；合同金额已是“元”。批量删除是物理删除。导出为同步 XLSX，超过服务能力时拒绝。

`GuaranteeSyncJob` 通过治理 Quartz 配置触发 `GuaranteeSyncService`，将前一日 `clms_ed_credit_info` 的担保类数据更新/补入担保表，并归集相应合同数据。任务配置和隔离要求见 `08-初始化数据清单.md`，不在本文复制执行脚本。

## 8. 公告

公告使用 `ANNOUNCEMENT` 和 `ANNOUNCEMENT_FILE`：

- `GET /api/portal/announcements` 查询未删除公告，按置顶和发布日期排序；
- `GET /api/portal/announcements/recent` 查询工作台使用的最近公告；
- `GET /api/portal/announcements/{id}` 查询详情及附件列表；
- `GET /api/portal/announcements/files/{fileId}/download` 经 `FileApi` 从 OBS 读取附件；
- `GET /api/admin/announcements` 查询管理端公告（含已删除）；
- `POST /api/admin/announcements` 新增公告；
- `POST /api/admin/announcements/{announcementId}/files` 上传附件；
- `PUT /api/admin/announcements/{id}/toggle-pin` 切换置顶；
- `DELETE /api/admin/announcements/{id}` 将公告标记为已删除。

公告状态由 `isDeleted` 映射为 `已发布`/`已删除`，置顶由 `isPinned` 映射为布尔值。公告新增、删除、置顶在事务中执行；附件上传包含 OBS 写入和本地关联写入，二者不是同一事务，失败时可能需要按运行日志清理孤立对象。公告当前没有门户 `AuditApi` 调用，不能在文档中宣称已完成审计。

## 9. 权限、审计与非目标

- 除工作台和快捷入口登录态例外外，Controller 的业务方法均使用 `@BizAuth`，资源登记要求见 `08-初始化数据清单.md`。
- 读、详情和导出必须遵守服务层数据范围；写操作必须在服务层复核实体归属，不能只依赖前端入口隐藏。
- 当前显式审计覆盖导航、产品、产品导出、文档和本人通讯录维护；快捷入口、公告、担保及担保导出当前没有 `AuditApi` 调用，属于交付风险而非已完成能力。
- 本模块不承诺尚未在当前 Controller/API 中存在的导入、模板、批量通讯录维护、异步导出、60 天提醒或额外工作台卡片；不恢复旧表、旧路径和未来版本清单。

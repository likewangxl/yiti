## 1. 依赖 auth-permission-center（强依赖 S）

**来源**：`docs/modules/auth-permission-center/04-对外API契约.md`

**依赖类型**：强依赖（S） -- 本地方法调用（Spring Bean 注入），无 RPC 开销

---

### 1.1 本模块使用的接口

| 接口 | 方法签名 | 返回类型 | 用途 |
|:---|:---|:---|:---|
| CurrentUserApi | `getCurrentUserContext()` | `CurrentUserContext` | 获取当前用户完整上下文（审计日志记录操作人、机构等信息） |
| CurrentUserApi | `getCurrentEmpId()` | `String` | 获取当前用户工号（通知发送、created_by 字段填充） |
| CurrentUserApi | `getCurrentOrgCode()` | `String` | 获取当前用户主机构编码（审计日志记录操作人机构） |
| CurrentUserApi | `isSystemAdmin()` | `boolean` | 判断是否系统管理员（系统配置/任务调度/SQL探查等管理功能权限校验） |
| BizScopeApi | `resolveScope(empId, BizType)` | `DataScopeType` | 解析数据范围（审计日志查询时的数据权限控制） |
| BizScopeApi | `buildScopeContext(empId, BizType, BizAction)` | `DataScopeContext` | 构建完整数据范围上下文（审计日志列表查询的数据范围过滤） |
| OrgApi | `getUserMainOrg(empId)` | `OrgDTO` | 获取用户主机构信息（审计日志中记录操作人所属机构） |
| OrgApi | `getOrg(orgCode)` | `OrgDTO` | 获取机构信息（审计日志查询时展示机构名称） |

### 1.2 各场景使用详情

#### 场景 1：审计日志写入

```
触发时机：每次需审计的接口请求完成后
调用链路：
  AuditLogAspect (AOP)
    → CurrentUserApi.getCurrentUserContext()    // 获取 empId, empName
    → CurrentUserApi.getCurrentOrgCode()         // 获取操作人机构
    → AuditLogService.log(...)                   // 写入 audit_log 表
```

#### 场景 2：审计日志查询（数据范围控制）

```
触发时机：管理员查询审计日志列表
调用链路：
  AuditLogController.pageQuery()
    → BizScopeApi.buildScopeContext(empId, BizType.SYS_CONFIG, BizAction.READ)
    → 根据 DataScopeContext 构建 SQL WHERE 条件：
      - ALL → 无额外条件
      - ORG → WHERE emp_org_code = #{currentOrgCode}
      - ORG_SUBTREE → WHERE emp_org_code IN (#{orgSubtreeCodes})
      - SELF → WHERE emp_id = #{currentEmpId}
```

#### 场景 3：管理功能权限校验

```
触发时机：系统配置/任务调度/字典管理等管理接口调用时
调用链路：
  @BizAuth 注解 → BizAuthInterceptor
    → CurrentUserApi.isSystemAdmin()             // 系统管理员直接放行
    → BizScopeApi.resolveScope(empId, BizType)   // 非管理员检查数据范围
```

#### 场景 4：通知发送

```
触发时机：业务事件触发通知
调用链路：
  NotificationService.send(...)
    → CurrentUserApi.getCurrentEmpId()            // 获取发送人（系统通知可为空）
    → INSERT user_notification (emp_id=接收人工号)
```

#### 场景 5：文件上传记录

```
触发时机：文件上传
调用链路：
  FileService.upload(...)
    → CurrentUserApi.getCurrentEmpId()            // 获取上传人
    → INSERT file_object (uploaded_by=当前用户工号)
```

### 1.3 使用的 DTO 结构

#### CurrentUserContext

```java
package com.bank.branch.platform.common.security.context;

/**
 * 当前用户上下文（不可变对象）
 * 定义在 common-security 模块中
 */
public record CurrentUserContext(
    String empId,              // 用户工号（PT_USER.USER_ID）
    String mainOrgCode,        // 主机构编码（EXT_USER_ORG.ORG_CODE）
    Set<String> roleIds,       // 角色ID集合
    Set<String> roleCodes,     // 角色编码集合
    Set<String> candidateGroupKeys, // 候选组Key集合（用于工作流）
    boolean systemAdmin        // 是否系统管理员
) {}
```

**本模块使用的字段**：

| 字段 | 使用场景 |
|:---|:---|
| empId | 审计日志 emp_id、文件 uploaded_by、通知 created_by |
| mainOrgCode | 审计日志中记录操作人机构 |
| systemAdmin | 管理功能权限快速判断 |
| roleIds | 不直接使用（通过 BizScopeApi 间接使用） |
| roleCodes | 不直接使用 |
| candidateGroupKeys | 不直接使用 |

#### OrgDTO

```java
package com.bank.branch.platform.auth.api.dto;

/**
 * 机构信息DTO
 */
public class OrgDTO {
    private String orgCode;        // 机构编码
    private String orgName;        // 机构名称
    private Integer orgLevel;      // 机构等级（1总行/2分行/3支行）
    private String parentOrgCode;  // 上级机构编码
    private Integer organState;    // 状态（0启用/1删除）
    // getter/setter 省略
}
```

**本模块使用的字段**：

| 字段 | 使用场景 |
|:---|:---|
| orgCode | 审计日志查询数据范围过滤 |
| orgName | 审计日志查询结果中展示操作人机构名称 |

#### DataScopeContext

```java
package com.bank.branch.platform.auth.api.dto;

/**
 * 数据范围上下文（ThreadLocal传递）
 */
public record DataScopeContext(
    DataScopeType scopeType,       // 数据范围类型
    String empId,                   // 当前用户工号
    String orgCode,                 // 当前用户主机构编码
    Set<String> orgSubtreeCodes,   // 机构子树编码集合（ORG_SUBTREE时填充）
    BizType bizType,               // 当前业务类型
    BizAction action               // 当前业务动作
) {}
```

### 1.4 使用的枚举

#### BizType

```java
package com.bank.branch.platform.common.security.enums;

/**
 * 业务类型枚举
 * 本模块使用 SYS_CONFIG 作为所有管理接口的 BizType
 */
public enum BizType {
    SYS_CONFIG,     // 系统配置管理（字典/日历/配置/任务调度/审计日志）
    // 其他模块的 BizType...
    LEAD,           // 线索管理
    CUSTOMER,       // 客户管理
    LOAN,           // 资产投放
    SUPPORT,        // 中场支持
    // ...
}
```

**本模块使用**：`BizType.SYS_CONFIG` -- 涵盖字典管理、日历管理、系统配置、任务调度、审计日志查询等全部管理接口

#### BizAction

```java
package com.bank.branch.platform.common.security.enums;

/**
 * 业务动作枚举
 */
public enum BizAction {
    READ,           // 读取/查询
    WRITE,          // 写入/新增/编辑
    DELETE,         // 删除
    CONFIG,         // 配置变更
    JOB_TRIGGER,    // 手动触发任务（高危）
    EXECUTE_SQL,    // 执行SQL探查（高危）
    EXPORT,         // 数据导出（高危）
    IMPORT,         // 数据导入（高危）
    APPROVE,        // 审批
    // ...
}
```

**本模块使用的动作**：

| BizAction | 使用场景 |
|:---|:---|
| READ | 字典查询、日历查询、配置查询、任务列表、审计查询 |
| CONFIG | 字典新增/编辑/删除、日历修改、配置修改 |
| JOB_TRIGGER | 手动触发定时任务（高危） |
| EXECUTE_SQL | 执行 SQL 探查（高危） |
| EXPORT | 审计日志导出（高危） |
| IMPORT | 日历批量导入（高危） |

#### DataScopeType

```java
package com.bank.branch.platform.common.security.enums;

/**
 * 数据范围类型枚举
 * 合并策略优先级：ALL > ORG_SUBTREE > ORG > SELF_CREATED/SELF
 */
public enum DataScopeType {
    ALL,             // 全部数据
    ORG_SUBTREE,     // 本机构及下级机构
    ORG,             // 仅本机构
    SELF_CREATED,    // 仅自己创建的
    SELF,            // 仅与自己相关
    SELF_ASSIGNED,   // 仅分配给自己的
    WORKFLOW_PARTICIPANT // 流程参与者
}
```

### 1.5 调用约束与注意事项

| 约束项 | 说明 |
|:---|:---|
| 调用方式 | 本地方法调用（Spring Bean 注入），非 RPC，无网络开销 |
| 线程安全 | 所有 Api 方法线程安全 |
| 事务传播 | Api 方法参与调用方的事务（REQUIRED 传播） |
| CurrentUserApi | 从 ThreadLocal 获取，无 DB IO，性能极高。必须在 AuthenticationFilter 之后调用 |
| BizScopeApi | resolveScope() 使用 Redis 缓存（TTL=5min），Key: `auth:biz-scope:{roleId}` |
| OrgApi | getUserMainOrg() 建议缓存，getOrg() 使用 Redis 缓存（TTL=10min） |

### 1.6 异常处理

| 异常类型 | 场景 | 本模块处理方式 |
|:---|:---|:---|
| `AuthException` | 未登录/Session过期 | 由全局异常处理器重定向到登录页 |
| `PermissionDeniedException` | 权限拒绝（无 SYS_CONFIG BizType 权限） | 返回 403 |
| `BizException` | 资源不存在/用户无机构 | 按错误码返回对应业务错误 |

## 2. 被其他模块依赖的接口（governance 提供）

governance 模块作为基础设施模块，对外提供以下接口供其他模块调用：

### 2.1 DictQueryApi -- 字典查询

```java
package com.bank.branch.platform.governance.api;

/**
 * 字典查询对外API
 * 供其他模块按字典类型查询字典项
 */
public interface DictQueryApi {

    /**
     * 按字典类型查询所有启用的字典项列表
     * 优先走 Redis 缓存
     */
    List<DictItemDTO> listByType(String dictType);

    /**
     * 按字典类型和编码获取单个字典项
     */
    DictItemDTO getByTypeAndCode(String dictType, String dictCode);

    /**
     * 字典值翻译（code → label）
     */
    String translateLabel(String dictType, String dictCode);
}
```

**调用方**：所有业务模块（customer-marketing-center、business-application-center、performance-engine-center 等）

### 2.2 NotifyApi -- 通知发送

```java
package com.bank.branch.platform.governance.api;

/**
 * 通知发送对外API
 * 供其他模块发送用户通知
 */
public interface NotifyApi {

    /**
     * 发送单条通知
     */
    void send(NotificationCreateDTO dto);

    /**
     * 批量发送通知
     */
    void batchSend(List<NotificationCreateDTO> notifications);
}
```

**调用方**：workflow-center（流程节点到达通知）、customer-marketing-center（业务提醒通知）等

### 2.3 FileApi -- 文件管理

```java
package com.bank.branch.platform.governance.api;

/**
 * 文件管理对外API
 * 供其他模块上传、下载、关联文件
 */
public interface FileApi {

    FileObjectDTO upload(MultipartFile file, String uploadedBy);
    FileObjectDTO upload(MultipartFile file, String uploadedBy, String category);
    FileObjectDTO upload(byte[] bytes, String filename, String contentType,
                         String uploadedBy, String category);
    byte[] getFileContent(String fileId);
    void writeFileContent(String fileId, java.io.OutputStream outputStream);
    String getDownloadUrl(String fileId);
    void bindFile(String bizType, String bizId, String fileObjectId, String fileRole);
    List<FileObjectDTO> listBizFiles(String bizType, String bizId);
    void deleteFile(String fileId);
}
```

`MultipartFile` 上传使用流式 MD5 + OBS 输入流；`writeFileContent` 用于将 OBS 对象直接写入 HTTP 等调用方输出流。`FileObjectDTO.newlyCreated` 仅用于区分本次新建与 MD5 命中既有对象，便于调用方安全补偿。

**调用方**：所有需要文件附件功能的业务模块

### 2.4 AuditApi -- 审计日志

### 2.6 ConfigQueryApi -- 系统配置查询

```java
package com.bank.branch.platform.governance.api;

/**
 * 系统配置查询对外API
 * 供其他模块读取系统配置参数
 */
public interface ConfigQueryApi {

    /**
     * 获取配置值（字符串）
     */
    String getString(String configKey);

    /**
     * 获取配置值（整数），不存在返回默认值
     */
    int getInt(String configKey, int defaultValue);

    /**
     * 获取配置值（布尔），不存在返回默认值

```

**调用方**：所有模块（获取分页大小、导出限制、缓存 TTL 等全局配置）

## 3. 依赖关系图

```
                  ┌─────────────────────────────────┐
                  │   auth-permission-center         │
                  │   (CurrentUserApi / BizScopeApi  │
                  │    / OrgApi / ResourceApi)        │
                  └───────────────┬─────────────────┘
                                  │ 强依赖 (S)
                                  ▼
                  ┌─────────────────────────────────┐
                  │   system-governance-center       │
                  │   (本模块)                        │
                  │                                   │
                  │   提供：                           │
                  │   - DictQueryApi                  │
                  │   - NotifyApi                     │
                  │   - FileApi                       │
                  │   - AuditApi                      │
                  │   - CalendarQueryApi              │
                  │   - ConfigQueryApi                │
                  └───────────────┬─────────────────┘
                                  │ 被依赖
                                  ▼
            ┌───────────┬─────────┼──────────┬──────────────┐
            │           │         │          │              │
            ▼           ▼         ▼          ▼              ▼
      customer-   business-  workflow-  performance-   portal-
      marketing   application  center   engine-center  content
      center      center                               center
```

**关键约束**：
- governance 依赖 auth-permission-center（单向）
- governance **不依赖** workflow-center（workflow 依赖 governance，不反向）
- governance **不依赖**任何业务模块
- governance 可被所有业务模块依赖（提供字典、通知、文件、审计、日历、配置等基础能力）

## 4. 工作日历初始化

### 4.1 年度初始化流程

1. 系统上线或每年年初，管理员调用年度初始化接口：`POST /api/sys/calendar/init-year`
2. 接口生成当年 1月1日 ~ 12月31日 共 365/366 天的日历记录
3. 默认规则：周一至周五为工作日（is_workday=1），周六周日为休息日（is_workday=0）
4. 使用 `INSERT IGNORE` 保证幂等，已存在的日期不会被覆盖

### 4.2 节假日调整

年度初始化后，需手动或批量导入国家法定节假日调整：

| 调整类型 | 操作方式 | 说明 |
|:---|:---|:---|
| 法定节假日放假 | 批量导入 / 单日修改 | 将工作日标记为休息日 |
| 调休上班 | 批量导入 / 单日修改 | 将休息日（周末）标记为工作日 |

**操作流程**：
1. 准备 Excel 文件，格式：日期(yyyy-MM-dd) | 是否工作日(1/0) | 备注
2. 调用批量导入接口：`POST /api/sys/calendar/batch-import`
3. 或逐日修改：`PUT /api/sys/calendar/{date}`

### 4.3 示例：2026年国庆调休

```
2026-09-27 (周日) → is_workday=1, remark="国庆调休上班"
2026-10-01 (周四) → is_workday=0, remark="国庆节"
2026-10-02 (周五) → is_workday=0, remark="国庆节"
2026-10-03 (周六) → is_workday=0, remark="国庆节"
2026-10-04 (周日) → is_workday=0, remark="国庆节"
2026-10-05 (周一) → is_workday=0, remark="国庆节"
2026-10-06 (周二) → is_workday=0, remark="国庆节"
2026-10-07 (周三) → is_workday=0, remark="国庆节"
2026-10-10 (周六) → is_workday=1, remark="国庆调休上班"
```

## 7. 初始化执行顺序

系统初始化时，数据加载需按以下顺序执行：

```
1. 执行 DDL 脚本
   └── docs/schema/ddl-governance.sql（创建表结构）

2. 执行种子数据脚本
   ├── docs/schema/seed-v1.sql（字典、角色、资源、权限绑定）
   ├── 任务调度种子 SQL（本文档第 2 节）
   └── 系统配置种子 SQL（本文档第 3 节）

3. 执行初始化接口
   └── POST /api/sys/calendar/init-year?year=2026（生成年度工作日历）

4. 手动数据配置
   └── 导入法定节假日调整（批量导入或逐日修改）
```

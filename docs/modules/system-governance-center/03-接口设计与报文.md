# 系统治理中心 -- 接口设计与报文

> 本文档是 governance 模块最重要的接口参考文件，所有接口均达到字段级可执行精度。
> 统一响应格式：`ResponseWrapper<T>`，包含 code/message/data/traceId/timestamp 五个字段。

---

## A. 字典管理

### A.1 GET /api/sys/dicts -- 查询字典类型列表

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = READ)`
- **说明**：查询字典类型列表，支持按类型精确匹配、按关键词模糊搜索、按状态筛选

**Query 参数：**

| 参数 | Java类型 | 必填 | 校验 | 说明 |
|:---|:---|:---|:---|:---|
| dictType | String | 否 | `@Size(max=100)` | 精确匹配字典类型 |
| keyword | String | 否 | `@Size(max=100)` | 按字典类型/标签模糊搜索 |
| status | String | 否 | `ACTIVE/DISABLED` | 状态筛选 |

**响应体 `ResponseWrapper<List<DictTypeRespDTO>>`：**

**DictTypeRespDTO：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| dictType | String | 字典类型编码 |
| dictTypeLabel | String | 字典类型显示名称（取该类型下首条记录的 remark 或 dictType） |
| itemCount | Integer | 该类型下字典项数量 |
| status | String | 状态（取该类型下是否有 ACTIVE 项） |

**响应示例：**

```json
{
  "code": "0",
  "message": "success",
  "traceId": "a1b2c3d4",
  "data": [
    {
      "dictType": "INDUSTRY",
      "dictTypeLabel": "行业分类",
      "itemCount": 15,
      "status": "ACTIVE"
    }
  ],
  "timestamp": "2026-04-01T10:00:00"
}
```

### A.2 GET /api/sys/dicts/{dictType}/items -- 查询指定类型的字典项列表

- **权限**：无需 @BizAuth（公共只读数据，所有登录用户可访问）
- **说明**：查询指定字典类型下的所有启用状态字典项，按 sort_order 升序排列

**路径参数：**

| 参数 | Java类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| dictType | String | 是 | 字典类型编码（如 `INDUSTRY`） |

**响应体 `ResponseWrapper<List<DictItemRespDTO>>`：**

**DictItemRespDTO：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| id | String | 字典ID（32位UUID） |
| dictType | String | 字典类型 |
| dictCode | String | 字典编码 |
| dictLabel | String | 字典标签（用于前端显示） |
| dictValue | String | 字典值（用于存储/传输） |
| sortOrder | Integer | 排序号 |
| status | String | 状态 ACTIVE/DISABLED |

**业务规则：**
1. 默认只返回 `status=ACTIVE` 的字典项
2. 若 dictType 不存在，返回空列表（不报错）

### A.3 POST /api/admin/sys/dicts -- 新增字典项

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = CONFIG)`
- **说明**：新增一个字典项

**请求体 DictCreateReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 字典/取值范围 | 示例值 |
|:---|:---|:---|:---|:---|:---|
| dictType | String | 是 | `@NotBlank @Size(max=100) @Pattern(regexp="^[A-Z_]+$")` | 大写字母+下划线 | `"INDUSTRY"` |
| dictCode | String | 是 | `@NotBlank @Size(max=100)` | - | `"IT"` |
| dictLabel | String | 是 | `@NotBlank @Size(max=200)` | - | `"信息技术"` |
| dictValue | String | 是 | `@NotBlank @Size(max=500)` | - | `"IT"` |
| sortOrder | Integer | 否 | `@Min(0)` | 默认 0 | `1` |
| remark | String | 否 | `@Size(max=500)` | - | `"信息技术行业"` |

**响应体 `ResponseWrapper<DictItemRespDTO>`：**

返回新增的字典项完整信息。

**业务规则：**
1. `dict_type + dict_code` 唯一，重复返回 `GOV-40002`
2. 新增字典项默认 `status=ACTIVE`
3. 新增后清除该 dictType 的 Redis 缓存

**错误响应示例：**

```json
{
  "code": "GOV-40002",
  "message": "字典编码已存在",
  "traceId": "a1b2c3d4",
  "data": null,
  "timestamp": "2026-04-01T10:00:00"
}
```

## B. 工作日历

### B.1 GET /api/sys/calendar -- 查询日历（按月）

- **权限**：无需 @BizAuth（公共只读数据）
- **说明**：查询指定年月的日历数据，返回该月每天的工作日/休息日状态

**Query 参数：**

| 参数 | Java类型 | 必填 | 校验注解 | 说明 |
|:---|:---|:---|:---|:---|
| year | Integer | 是 | `@NotNull @Min(2020)` | 年份 |
| month | Integer | 是 | `@NotNull @Min(1) @Max(12)` | 月份 |

**响应体 `ResponseWrapper<List<CalendarDayRespDTO>>`：**

**CalendarDayRespDTO：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| day | String | 日期（yyyy-MM-dd 格式） |
| isWorkday | Boolean | 是否工作日 |
| dayOfWeek | Integer | 星期几（1=周一 ... 7=周日） |
| remark | String | 备注（如"国庆节"） |

**响应示例：**

```json
{
  "code": "0",
  "message": "success",
  "traceId": "a1b2c3d4",
  "data": [
    {
      "day": "2026-04-01",
      "isWorkday": true,
      "dayOfWeek": 3,
      "remark": null
    },
    {
      "day": "2026-04-04",
      "isWorkday": false,
      "dayOfWeek": 6,
      "remark": "清明节"
    }
  ],
  "timestamp": "2026-04-01T10:00:00"
}
```

---

### B.2 PUT /api/admin/sys/calendar/{date} -- 切换某天工作/休息状态

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = CONFIG)`
- **说明**：设置指定日期为工作日或休息日

**路径参数：**

| 参数 | Java类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| date | String | 是 | 日期（yyyy-MM-dd 格式） |

**请求体 CalendarDayUpdateReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 说明 |
|:---|:---|:---|:---|:---|
| isWorkday | Boolean | 是 | `@NotNull` | true=工作日，false=休息日 |
| remark | String | 否 | `@Size(max=500)` | 备注（如"国庆调休"） |

**响应体 `ResponseWrapper<Void>`**

**业务规则：**
1. 日期 <= 今天，返回 `GOV-40902`（已过去日期不允许修改）
2. 日期对应记录不存在时自动创建
3. 更新后清除该年份的日历缓存

---

### B.3 POST /api/admin/sys/calendar/init -- 年初初始化

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = CONFIG)`
- **说明**：基于常规周末规则（周六日为休息日）生成指定年份全年日历数据

**请求体 CalendarInitReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 说明 |
|:---|:---|:---|:---|:---|
| year | Integer | 是 | `@NotNull @Min(2026)` | 年份 |

**响应体 `ResponseWrapper<CalendarInitRespDTO>`：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| year | Integer | 初始化年份 |
| totalDays | Integer | 总天数（365/366） |
| workdays | Integer | 工作日天数 |
| restDays | Integer | 休息日天数 |

**业务规则：**
1. 若目标年份已有数据，仅覆盖未来日期（今天及以前的数据不变）
2. 初始化完成后清除该年份的日历缓存

---

### B.4 POST /api/admin/sys/calendar/import -- 批量导入节假日

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = IMPORT)`
- **说明**：通过 Excel 文件批量导入节假日安排。属于 IMPORT 高危动作，需审计。

**请求格式**：`Content-Type: multipart/form-data`

| 参数 | Java类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| file | MultipartFile | 是 | Excel 文件（.xlsx） |

**Excel 格式要求：**

| 列 | 表头 | 类型 | 说明 |
|:---|:---|:---|:---|
| A | 日期 | yyyy-MM-dd | 日期 |
| B | 是否工作日 | 1/0 | 1=工作日，0=休息日 |
| C | 备注 | 文本 | 备注（如"国庆节"） |

**响应体 `ResponseWrapper<CalendarImportRespDTO>`：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| totalRows | Integer | 导入总行数 |
| successRows | Integer | 成功行数 |
| skippedRows | Integer | 跳过行数（已过去的日期） |

**业务规则：**
1. 只覆盖未来日期，已过去的日期自动跳过
2. 导入完成后清除相关年份的日历缓存

### C.3 POST /api/admin/sys/jobs/{jobId}/trigger -- 手动触发任务

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = JOB_TRIGGER)`
- **说明**：手动触发指定任务执行。属于 JOB_TRIGGER 高危动作，需审计。

**路径参数：**

| 参数 | Java类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| jobId | String | 是 | 任务ID |

**请求体 JobTriggerReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 说明 |
|:---|:---|:---|:---|:---|
| reason | String | 是 | `@NotBlank @Size(max=500)` | 触发原因（高危动作必填） |

**响应体 `ResponseWrapper<JobTriggerRespDTO>`：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| runLogId | String | 本次执行的日志ID |
| jobKey | String | 任务 KEY |
| triggerTime | String | 触发时间（ISO 8601） |

**业务规则：**
1. 任务不存在返回 `GOV-40402`
2. 任务 `allow_manual_trigger=0` 返回 `GOV-40901`
3. 任务已有 RUNNING 状态的执行日志返回 `GOV-40901`
4. 审计日志记录：action=JOB_TRIGGER，reason 必填

**错误响应示例：**

```json
{
  "code": "GOV-40901",
  "message": "调度任务状态冲突：任务正在运行中，无法重复触发",
  "traceId": "a1b2c3d4",
  "data": null,
  "timestamp": "2026-04-01T10:00:00"
}
```

## E. 通知消息

### E.1 GET /api/notifications -- 查询我的通知列表（分页）

- **权限**：无需 @BizAuth（天然按当前用户 emp_id 过滤）
- **说明**：查询当前用户的通知列表

**Query 参数：**

| 参数 | Java类型 | 必填 | 说明 |
|:---|:---|:---|:---|

### H.1 POST /api/admin/sys/sql-probe/execute -- 执行SQL

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = EXECUTE_SQL)`
- **说明**：执行只读 SQL 查询。属于 EXECUTE_SQL 高危动作，需审计。

**请求体 SqlProbeReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 说明 |
|:---|:---|:---|:---|:---|
| sql | String | 是 | `@NotBlank @Size(max=5000)` | SQL 语句（仅 SELECT） |
| remark | String | 否 | `@Size(max=500)` | 备注 |

**响应体 `ResponseWrapper<SqlProbeRespDTO>`：**

**SqlProbeRespDTO：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| columns | List\<String\> | 列名列表 |
| rows | List\<Map\<String,Object\>\> | 结果数据 |
| rowCount | Integer | 返回行数 |
| executionTime | Integer | 执行耗时（ms） |

**响应示例：**

```json
{
  "code": "0",
  "message": "success",
  "traceId": "a1b2c3d4",
  "data": {
    "columns": ["id", "dict_type", "dict_code", "dict_label"],
    "rows": [
      {"id": "1", "dict_type": "INDUSTRY", "dict_code": "IT", "dict_label": "信息技术"}
    ],
    "rowCount": 1,
    "executionTime": 35
  },
  "timestamp": "2026-04-01T10:00:00"
}
```

**业务规则：**
1. 非 SELECT 语句返回 `GOV-42201`
2. 超时返回 `GOV-42202`（默认 30 秒）
3. 访问白名单外的 Schema/表返回 `GOV-42203`
4. 自动追加 LIMIT（默认 1000，最大值从 sys_config_kv 读取）
5. 审计日志记录完整 SQL 语句、执行耗时、返回行数

**错误响应示例：**

```json
{
  "code": "GOV-42201",
  "message": "SQL语法校验失败：仅允许SELECT语句",
  "traceId": "a1b2c3d4",
  "data": null,
  "timestamp": "2026-04-01T10:00:00"
}
```

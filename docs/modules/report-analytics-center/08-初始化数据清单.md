## 1. SQL 探查 Schema 白名单配置

SQL 探查功能的所有运行时参数存储在 `system-governance-center.sys_config_kv` 表，通过 `ConfigApi.getConfigValue` 读取。

### 1.3 白名单维护策略

- 新增白名单表：通过 `ConfigApi.setConfigValue` 接口（需 R_ADMIN 权限），不需要发布版本；
- 移除白名单表：影响面较大，建议发布版本变更；
- 审计：任何对 `sql.probe.*` 配置的修改都会被 `system-governance-center` 的配置审计自动记录。

## 6. V1 分行行长仪表盘指标配置

### 6.1 预置指标清单（硬编码于代码）

分行行长仪表盘 V1 的指标配置采用**硬编码**方式（避免首次部署时需配置元数据）。存放位置：`com.bank.branch.platform.report.config.DashboardPresidentMetrics`。

```java
public class DashboardPresidentMetrics {

    /** 核心指标（顶部 KPI 区） */
    public static final List<String> CORE_METRICS = List.of(
        "DEP_BAL_ORG_DAILY",      // 全行存款日均余额
        "LOAN_BAL_ORG_DAILY",     // 全行贷款日均余额
        "INT_INCOME_ORG_MONTH",   // 本月净利息收入
        "FEE_INCOME_ORG_MONTH"    // 本月中间业务收入
    );

    /** 达成率指标（进度条区） */
    public static final List<String> ACHIEVEMENT_METRICS = List.of(
        "DEP_ACHIEVE_RATE_ORG",   // 存款达成率
        "LOAN_ACHIEVE_RATE_ORG",  // 贷款达成率
        "NEW_CUST_ACHIEVE_ORG",   // 新增客户达成率
        "KPI_ACHIEVE_RATE_ORG"    // 综合绩效达成率
    );

    /** 对比指标（同比/环比） */
    public static final List<String> TREND_METRICS = List.of(
        "DEP_BAL_YOY_RATE",       // 存款余额同比增长率
        "LOAN_BAL_YOY_RATE",      // 贷款余额同比增长率
        "DEP_BAL_MOM_RATE",       // 存款余额环比增长率
        "LOAN_BAL_MOM_RATE"       // 贷款余额环比增长率
    );

    /** 排行榜指标（下属机构排名） */
    public static final List<String> RANKING_METRICS = List.of(
        "KPI_TOTAL_SCORE_ORG",    // 综合得分
        "DEP_BAL_ORG_DAILY"       // 存款余额
    );

    /** Top 客户贡献指标 */
    public static final List<String> CUST_CONTRIBUTION_METRICS = List.of(
        "AUM_TOTAL_CUST",         // 客户 AUM
        "PROFIT_CONTRIB_CUST"     // 客户利润贡献
    );
}
```

### 6.2 指标元数据依赖

以上指标需要 `performance-engine-center.metric_def` 表中存在对应记录。**V1 部署前**必须确认 performance 模块已初始化这些指标，否则行长仪表盘会报错。

验证 SQL：

```sql
SELECT metric_code, metric_name, base_dim, metric_level, status
FROM metric_def
WHERE metric_code IN (
    'DEP_BAL_ORG_DAILY', 'LOAN_BAL_ORG_DAILY', 'INT_INCOME_ORG_MONTH',
    'FEE_INCOME_ORG_MONTH', 'DEP_ACHIEVE_RATE_ORG', 'LOAN_ACHIEVE_RATE_ORG',
    'NEW_CUST_ACHIEVE_ORG', 'KPI_ACHIEVE_RATE_ORG', 'DEP_BAL_YOY_RATE',
    'LOAN_BAL_YOY_RATE', 'DEP_BAL_MOM_RATE', 'LOAN_BAL_MOM_RATE',
    'KPI_TOTAL_SCORE_ORG', 'AUM_TOTAL_CUST', 'PROFIT_CONTRIB_CUST'
)
AND status = 'ACTIVE';
```

## 8. 启动校验

报表模块启动时会执行以下校验，任一失败则启动失败：

### 8.1 配置完整性校验

```java
@Component
public class ReportConfigValidator implements ApplicationRunner {

    private static final List<String> REQUIRED_CONFIG_KEYS = List.of(
        "sql.probe.schema.whitelist",
        "sql.probe.forbidden.keywords",
        "sql.probe.max.rows",
        "sql.probe.timeout.seconds",
        "report.dynamic-query.max.subjects",
        "report.dynamic-query.max.metrics",
        "report.saved-query.max.per.user",
        "report.dashboard.cache.ttl.minutes",
        "report.export.max.rows.sync"
    );

    @Override
    public void run(ApplicationArguments args) {
        for (String key : REQUIRED_CONFIG_KEYS) {
            if (configApi.getConfigValue(key).isEmpty()) {
                throw new IllegalStateException(
                    "缺失必要配置：" + key + "，请检查 sys_config_kv");
            }
        }
        log.info("Report module config validation passed");
    }
}
```

### 8.2 依赖模块校验

启动时调用一次 `MetricApi.listMetrics(null, null)`，若抛出异常则说明 performance 模块未就绪，启动失败并明确提示。

### 8.3 只读数据源校验

SQL 探查使用的只读数据源在启动时执行 `SELECT 1` 验证连通性。

# 报表分析中心 — 接口设计与报文

> **模块**: report-analytics-center
> **版本**: V1.0
> **最后更新**: 2026-04-10
> **统一响应模型**: `CommonResult<T>` (code, msg, data, traceId)

---

## 通用说明

### 请求头
| 请求头 | 必填 | 说明 |
|--------|------|------|
| `Authorization` | 是 | Bearer Token |
| `X-Trace-Id` | 否 | 全链路 TraceID（未提供时由网关生成） |
| `Content-Type` | 是 | application/json |

### 统一响应结构
```json
{
  "code": 0,
  "msg": "success",
  "data": { ... },
  "traceId": "abcd-1234"
}
```

### 错误响应示例
```json
{
  "code": 40001,
  "msg": "查询方案不存在",
  "errorCode": "RPT-40001",
  "data": null,
  "traceId": "abcd-1234"
}
```

## A. 动态指标查询

### A.1 GET /api/reports/query-dimensions — 获取可查询维度与指标树

**用途**：前端进入动态查询页面时，获取当前维度下可用的指标树。

**权限**：`@BizAuth(bizType = REPORT, action = READ)`

**请求参数（Query）**：
| 字段 | 类型 | 必填 | 校验 | 说明 |
|------|------|------|------|------|
| `dim` | String | 是 | EMP/ORG/CUST | 维度 |

**响应 DTO：`QueryDimensionRespDTO`**
| 字段 | 类型 | 说明 |
|------|------|------|
| `dim` | String | 维度 |
| `dimName` | String | 维度中文名 |
| `metrics` | List\<MetricTreeNodeDTO\> | 可用指标树（嵌套结构） |

**`MetricTreeNodeDTO`**（树节点）
| 字段 | 类型 | 说明 |
|------|------|------|
| `groupCode` | String | 分组编码（叶子节点为空） |
| `groupName` | String | 分组名称 |
| `metricCode` | String | 指标编码（叶子节点必填） |
| `metricName` | String | 指标名称 |
| `unit` | String | 单位（如"万元"、"%"） |
| `description` | String | 指标说明 |
| `children` | List\<MetricTreeNodeDTO\> | 子节点 |

**示例请求**：
```
GET /api/reports/query-dimensions?dim=EMP
```

**示例响应**：

### A.2 POST /api/reports/dynamic-query — 执行动态查询

**用途**：执行动态指标查询，返回表格数据。

**权限**：`@BizAuth(bizType = REPORT, action = LIST)`

**请求体 DTO：`DynamicQueryReqDTO`**
| 字段 | 类型 | 必填 | 校验 | 说明 |
|------|------|------|------|------|
| `dim` | String | 是 | `@NotBlank` `@Pattern(EMP/ORG/CUST)` | 维度 |
| `subjectIds` | List\<String\> | 是 | `@NotEmpty` `@Size(max=100)` | 对象 ID 列表 |
| `metricCodes` | List\<String\> | 是 | `@NotEmpty` `@Size(max=20)` | 指标编码列表 |
| `dataDate` | LocalDate | 是 | `@NotNull` | 数据日期（单选） |

**响应 DTO：`DynamicQueryRespDTO`**
| 字段 | 类型 | 说明 |
|------|------|------|
| `dim` | String | 维度 |
| `dataDate` | LocalDate | 数据日期 |
| `dataVersion` | String | sys_control 版本号 |
| `columns` | List\<MetricColumnDTO\> | 指标列定义 |
| `rows` | List\<Map\<String,Object\>\> | 数据行（key=metricCode 或 subject 字段） |
| `rowCount` | Integer | 行数 |
| `executionTimeMs` | Integer | 查询耗时 |

**`MetricColumnDTO`**
| 字段 | 类型 | 说明 |
|------|------|------|
| `metricCode` | String | 指标编码 |
| `metricName` | String | 指标名称 |
| `unit` | String | 单位 |
| `dataType` | String | 数据类型：NUMBER/PERCENT/CURRENCY |
| `precision` | Integer | 小数位数 |

**示例请求**：
```json
POST /api/reports/dynamic-query
{
  "dim": "EMP",
  "subjectIds": ["EMP001", "EMP002", "EMP003"],
  "metricCodes": ["EMP_DEPOSIT_BAL", "EMP_DEPOSIT_NEW", "EMP_LOAN_BAL"],
  "dataDate": "2026-04-09"

**用途**：获取当前用户保存的查询方案列表。

**权限**：`@BizAuth(bizType = REPORT, action = LIST)`

**请求参数（Query）**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|

**响应**：`List<SavedQueryRespDTO>`

**`SavedQueryRespDTO`**
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 方案 ID |
| `name` | String | 方案名 |
| `dim` | String | 维度 |
| `subjectIds` | List\<String\> | 对象 ID 列表 |
| `subjectNames` | List\<String\> | 对象名称（冗余展示） |
| `metricCodes` | List\<String\> | 指标编码列表 |
| `metricNames` | List\<String\> | 指标名称（冗余展示） |
| `createdTime` | LocalDateTime | 创建时间 |

**示例响应**：

      "dim": "EMP",

      "updatedTime": "2026-04-01T10:00:00"
    }
  ]

```

---

### B.2 POST /api/reports/saved-queries — 保存查询方案

**权限**：`@BizAuth(bizType = REPORT, action = CREATE)`

**请求体 DTO：`SavedQueryCreateReqDTO`**
| 字段 | 类型 | 必填 | 校验 | 说明 |
|------|------|------|------|------|
| `name` | String | 是 | `@NotBlank` `@Size(max=200)` | 方案名称 |
| `dim` | String | 是 | `@NotBlank` EMP/ORG/CUST | 维度 |
| `subjectIds` | List\<String\> | 是 | `@NotEmpty` `@Size(max=100)` | 对象 ID |
| `metricCodes` | List\<String\> | 是 | `@NotEmpty` `@Size(max=20)` | 指标编码 |

**业务规则**：
- 每个用户最多保存 10 条
- 超过 10 条时，系统自动删除最旧的一条
- 方案归属当前登录员工

**响应**：`SavedQueryRespDTO`（同 B.1）

**错误码**：
- `RPT-40003`：超出 10 条限制（理论上不会触发，因为系统自动删除）

---

### B.3 PUT /api/reports/saved-queries/{id} — 更新查询方案

**权限**：`@BizAuth(bizType = REPORT, action = UPDATE)`

**路径参数**：
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 方案 ID |

**请求体 DTO：`SavedQueryUpdateReqDTO`**（同 B.2，所有字段为非必填但 dim 不可修改）

**业务规则**：
- 只能更新本人的方案
- 不允许修改 `dim` 字段
- 自动刷新 `updated_time`

**响应**：`SavedQueryRespDTO`

**错误码**：
- `RPT-40001`：方案不存在
- `RPT-40002`：无权访问（非本人）

---

### B.4 DELETE /api/reports/saved-queries/{id} — 删除查询方案

**权限**：`@BizAuth(bizType = REPORT, action = DELETE)`

**路径参数**：
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 方案 ID |

**业务规则**：
- 只能删除本人的方案

**响应**：
```json
{
  "code": 0,
  "msg": "success",
  "data": true
}
```

## D. SQL 探查

### D.1 POST /api/reports/sql-probe/execute — 执行 SQL 探查

**用途**：执行受限的 SQL 查询（仅科技部特定角色）。

**权限**：`@BizAuth(bizType = SYS_CONFIG, action = EXECUTE_SQL)` — 高危动作

**请求体 DTO：`SqlProbeExecuteReqDTO`**
| 字段 | 类型 | 必填 | 校验 | 说明 |
|------|------|------|------|------|
| `sql` | String | 是 | `@NotBlank` `@Size(max=5000)` | SQL 文本 |
| `remark` | String | 是 | `@NotBlank` `@Size(max=500)` | 执行原因（reason） |

**响应 DTO：`SqlProbeExecuteRespDTO`**
| 字段 | 类型 | 说明 |
|------|------|------|
| `historyId` | String | 历史记录 ID |
| `columns` | List\<String\> | 列名 |
| `rows` | List\<Map\<String,Object\>\> | 数据行 |
| `rowCount` | Integer | 行数 |
| `executionTimeMs` | Integer | 执行耗时（毫秒） |

**示例请求**：
```json
POST /api/reports/sql-probe/execute
{
  "sql": "SELECT emp_id, deposit_bal FROM perf_kpi_snapshot WHERE data_version = 'V20260409001'",
  "remark": "排查数据异常，核对V20260409001版本存款余额数据"
}
```

**示例响应**：
```json
{
  "code": 0,
  "data": {
    "historyId": "SPH20260409001",
    "columns": ["emp_id", "deposit_bal"],
    "rows": [
      {"emp_id": "EMP001", "deposit_bal": 12500.50},
      {"emp_id": "EMP002", "deposit_bal": 9800.25}
    ],
    "rowCount": 2,
    "executionTimeMs": 150
  }
}
```

**错误码**：
- `RPT-40302`：无权使用 SQL 探查
- `RPT-42001`：SQL 语法校验失败
- `RPT-42002`：访问了白名单外的表
- `RPT-42003`：包含禁用关键字
- `RPT-42005`：执行超时
- `RPT-42006`：并发数超限
- `RPT-42007`：仅允许 SELECT
- `RPT-42008`：SQL 长度超限

---

### D.2 GET /api/reports/sql-probe/history — SQL 探查历史

**用途**：查询 SQL 探查历史（仅查本人）。

**权限**：`@BizAuth(bizType = SYS_CONFIG, action = LIST)`

**请求参数（Query）**：
| 字段 | 类型 | 必填 | 说明 |

| `pageNo` | Integer | 是 | 页码（默认 1） |

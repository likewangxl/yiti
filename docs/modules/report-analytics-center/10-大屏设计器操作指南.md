# 大屏设计器(V2)操作指南

> **版本**: V1.5(2026-08-21,草稿数据预览、地图/全图表拖入、图层排序与归档选择回滚)
> **适用范围**: `report-analytics-center` 大屏子域——画布设计器(`DesignerV2.vue`)与运行时渲染(`ScreenView.vue`)
> **设计规格**: `docs/superpowers/specs/2026-08-11-screen-scope-map-decoupling-design.md`(本期数据模型/接口/安全的唯一真相)
> **维护约定**: 本文只写"怎么用",不重复维护接口报文与表结构;操作项均与前端源码一一对应,改功能时须同步本文

## 1. 启动与进入

1. **启动后端**: `cd bootstrap && mvn spring-boot:run`(端口 18081)
2. **启动前端**: `cd xanzc_frontend && npm run dev`(`/api` 已代理到 18081)
3. **登录后访问设计器**: `#/screen-admin/designer`(菜单归属「报表分析」分组,标题「大屏设计器」)
4. **配套页面**:
   - 大屏数据源管理: `#/screen-admin/datasources`(图表绑定数据源的来源)
   - 运行时大屏: `#/screen/{屏编码}`(如 `SCR_PROVINCE` / `SCR_BRANCH` / `SCR_PERSON`)

### 1.1 权限要求(PT_RESOURCE)

| 资源码 | URL | 说明 |
|--------|-----|------|
| `R_RPT_SCR_CV_GET` | `GET /api/screen/admin/canvas/*` | 画布加载(进设计器必需) |
| `R_RPT_SCR_CV_SAVE` | `POST /api/screen/admin/canvas/save` | 保存草稿 |
| `R_RPT_SCR_CV_DISC` | `POST /api/screen/admin/canvas/discard` | 放弃草稿 |
| `R_RPT_SCR_CV_LOG` | `GET /api/screen/admin/canvas/*/publish-logs` | 发布归档列表 |
| `R_RPT_SCR_CV_PUB` | `POST /api/screen/admin/canvas/publish` | **发布(高危,独立授权)** |
| `R_RPT_SCR_CV_RB` | `POST /api/screen/admin/canvas/rollback` | **回滚(高危,独立授权)** |
| `R_RPT_SCR_CFG_SAVE` | `POST /api/screen/admin/screens` | 新建大屏(复用屏保存既有资源) |
| `R_RPT_SCR_META_SAVE` | `PUT /api/screen/admin/screens/*/metadata` | 更新屏元数据与机构范围（不含画布/角色，带 expectedVersion/reason） |
| `R_RPT_SCR_AR_SAVE` | `PUT /api/screen/admin/screens/*/access-roles` | **覆盖查看角色白名单（高危；默认仅精确授予 SYS_ADMIN）** |
| `R_RPT_SCR_DS_PROBE` | `POST /api/screen/admin/datasources/*/probe-columns` | **已保存数据源列探测（高危；默认不自动授予角色）** |

发布/回滚仅授屏管理角色；授权身份按当前 `ROLE_CODE` 解析并要求数字 `ROLE_ID`，不使用历史 `R_ADMIN` 绑定。`R_RPT_SCR_AR_SAVE` 的脚本默认只按唯一 `ROLE_CODE=SYS_ADMIN` 插入，绝不从 `R_RPT_SQL_EXEC` 推导；`R_RPT_SCR_DS_PROBE` 仍需单独审批。运行用户即使拥有 `SYS_ADMIN` 资源权限，仍须同时满足屏白名单、同角色绑定与机构组范围交集；不存在管理员旁路。授权 SQL 见 `docs/superpowers/sql/2026-08-11-screen-scope-map-align.sql`。

## 3. 标准工作流程(五步)

**选屏(或新建) → 编辑 → 保存草稿 → 预览草稿 → 发布**

0. (可选)点下拉框旁的**新建**按钮:弹框显式填**屏名称**、**层级**、**业务条线**(CORP/RETAIL/COMMON)与**机构范围模式**(LEGACY_CONTEXT/NAMED_GROUP；后者还须机构组编码)→ `POST /api/screen/admin/screens` 创建空画布，后端自动生成 `SCR_XXXXXXXX` 屏编码；后续改名称/条线/范围只调用 `PUT /api/screen/admin/screens/{id}/metadata`，并提交当前 `expectedVersion` 与审计 `reason`；该请求不携带组件、block 或角色，机构组编码传空串表示显式清空；
1. 工具条最左侧下拉框**选择大屏**(显示「屏名 (层级)」),切换即加载该屏当前草稿;
2. 在画布上编辑(见 §4);
3. 点**保存**(或 Ctrl+S)→ 提示「已保存草稿」——保存的是草稿态,**线上不受影响**;
4. 点**预览草稿**→ 新窗口打开 `#/screen/{屏编码}?preview=draft`,按真实运行时渲染草稿;
5. 确认无误后点**发布**(红色按钮)→ 填写非空审计原因并确认「发布后大屏线上立即生效」→ 自动**先保存再发布**,线上立即切到新版本,旧版本进入归档(滚动保留 10 份)。

## 4. 画布编辑操作

### 4.1 添加组件

从左栏「组件」页签**按住拖拽**到画布任意位置松手即创建:

| 分组 | 可拖入的组件 |
|------|------|
| 素材组件 | 文本、图片、矩形、边框装饰、时钟、科技标题条、装饰线、跑马灯、周期过滤器 |
| 地图组件 | 经营地图（陕西旧地图 / 西安复合地图，由属性面板选择模式） |
| 图表组件 | 数值卡片、趋势折线、占比饼图、排行榜、流程状态、柱状对比、仪表盘、明细表格、堆叠面积图、KPI 细项表、KPI 雷达、水波完成度、进度条列表、双轴组合、漏斗转化、散点气泡、热力矩阵、旭日分层、迷你趋势卡（共 19 种） |

> - 当前 19 种图表均已启用；注册表仍保留对未来 `enabled:false` 类型的拒绝门禁；
> - 经营地图可从独立「地图组件」分组拖入。新节点默认使用陕西旧地图模式，需要西安复合地图时在属性面板显式切换，并补齐机构组、画像与卫星节点配置。

### 4.2 选中、移动、缩放

- **单击**组件选中(出现选框与 8 个缩放点);单击画布空白处取消选中;
- **按住拖动**移动位置;拖动 **8 个缩放点**改变宽高;
- 移动/缩放时自动出现**青色吸附对齐线**(与其他组件的上/中/下、左/中/右 6 条基准线对齐,3px 内自动吸附);
- **方向键**微调:每次 1px;**Shift+方向键**每次 10px;
- 所有移动路径(拖拽/8 点缩放/方向键/属性面板数值输入)统一经 `clampRect` 限制在 1920×1080 设计基准内,组件拖不出画布。

### 4.3 右键菜单

在组件上**右键**弹出菜单:

| 菜单项 | 作用 |
|--------|------|
| 复制 / 粘贴 | 粘贴时自动偏移 (+20, +20) 并选中新组件 |
| 删除 | 删除当前组件 |
| 置顶 / 置底 / 上移一层 / 下移一层 | 调整叠放层级 |
| 锁定 / 解锁 | 锁定后组件不可拖动误改 |

### 4.4 图层面板(左栏「图层」页签)

- 列表**从上到下 = 画布从顶层到底层**;点击条目即选中对应组件;
- 顶部按钮:置顶 / 置底 / 上移 / 下移;
- 每行右侧两个图标:**眼睛** = 显示/隐藏,**锁** = 锁定/解锁;
- 可直接拖动列表条目调整叠放顺序（原生 HTML5 拖拽，不引入运行时新依赖）；
- 双击图层名称可改名，Enter/失焦保存，Esc 取消。

### 4.5 撤销 / 重做

- 工具条「撤销/重做」按钮,或 **Ctrl+Z / Ctrl+Y**;
- 快照按操作自动记录,连续微调 3 秒防抖合并为一步(避免按 10 次方向键要撤销 10 次)。

### 4.6 画布缩放(仅视图,不影响数据)

- 缩放滑杆 50%~150%,步进 10%;「适应窗口」一键把画布缩放到刚好铺满中间区域(进入设计器加载完首屏后会自动执行一次);
- 这是**编辑视图缩放**,组件坐标始终按 1920×1080 设计基准存储,不会因视图缩放漂移(交互增量统一经 `screenDeltaToDesign` 除以 scale 换算)。

## 5. 属性面板(右栏)

### 5.1 选中组件时 → 组件属性

所有组件共有「**位置与尺寸**」(X/Y/宽/高数值输入)和「**外观**」(透明度滑杆)两组;往下是各组件私有属性(文本内容/图片地址/矩形与边框样式/时钟格式等)。

**图表(ChartWidget)** 额外有取数配置:

| 字段 | 说明 |
|------|------|
| 数据源 | 下拉选择,来自「大屏数据源」管理页配置 |
| 周期 | 如 `LATEST` / `LAST_10D` |
| 标题 | 图表标题 |
| 刷新(秒) | 运行时自动轮询间隔,0 = 不自动刷新 |
| 钻取 | 开关 |

图表首次保存后由后端自动 upsert 分配 blockId,无需手工填写。

新增图表的默认取列规则如下，均只消费 `/api/screen/data` 返回的真实 `columns`/`rows`，没有数据时显示空态：

| 图表 | 默认取列与视觉控制 |
|---|---|
| 双轴组合 | 首列类目，前两个数值列分别柱/线；支持图例、数据标签、曲线平滑与 `columnsMeta` 别名 |
| 漏斗转化 | 优先 `bind.nameCol`/`bind.valueCol`，否则首个文本列+数值列；按值降序并显示相对百分比 |
| 散点气泡 | 标签列+两个坐标数值列，第三数值列控制气泡大小；使用色阶与悬浮提示 |
| 热力矩阵 | 前两个类目列+数值列；使用连续色阶，数据标签由视觉设置控制 |
| 旭日分层 | 一到两列类目+数值列生成层级；同父节点同名项自动汇总 |
| 迷你趋势卡 | 仅绑定 `TIMESERIES` 数据源，日期列+首个数值列；显示最新值、可安全计算的较上期变化与渐变迷你折线 |

图表属性中的「视觉预设」继续使用 `aurora`/`graphite`/`vivid`；新图表不改变数据源绑定契约，`SPARKLINE_CARD` 的全屏周期过滤器联动与趋势折线一致。

### 5.2 未选中组件时 → 画布全局设置

- **背景色**: 取色器;
- **适配策略**(决定运行时在不同分辨率下如何显示): 不缩放居中(keep) / **等比适配(keepProportion,推荐)** / 宽度铺满(widthFirst) / 高度铺满(heightFirst);
- **设计基准**: 固定 1920×1080,不可修改(唯一来源 `utils/scale.js` 的 DESIGN_W/DESIGN_H)。

## 7. 版本与发布管理

大屏采用**草稿 / 已发布双版本模型**(`CANVAS_DRAFT_JSON` / `CANVAS_PUBLISHED_JSON`):编辑永远只改草稿,线上永远只读已发布版。

| 操作 | 说明 |
|------|------|
| **保存** | 写入完整草稿组件树并使 `canvas_version` +1；CAS 成功后，已从组件树删除的本屏 ChartWidget 对应草稿 block 一并删除；线上无感知 |
| **预览草稿** | 新窗口以运行时视角渲染草稿(`?preview=draft`)；图表使用当前草稿 block 的只读绑定快照取数；仍先通过整屏 RBAC/白名单/同角色范围门禁，并额外要求 `R_RPT_SCR_CV_GET`，`SYS_ADMIN` 没有旁路 |
| **发布** | 填非空 `reason`、二次确认 → 先自动保存 → 草稿转正为不可变线上发布包,旧版本写入 `RPT_SCREEN_PUBLISH_LOG` 归档(滚动 10 份),线上立即生效；版本 CAS 冲突必须重载 |
| **放弃草稿** | 二次确认 → 提交 `screenId + expectedVersion + reason`，CAS 恢复发布组件树；若草稿 block 已删除，按可信发布 `bindSnapshots` 以原 blockId 恢复可编辑绑定，同时清除发布组件之外的草稿孤儿 block |
| **回滚** | 读取最近 10 份发布归档，显式选择目标版本并填写非空 `reason`，二次确认后以 `expectedVersion` CAS 回滚；只有可信不可变 `bindSnapshots` 的归档可回滚，无快照归档返回 `RPT-43023`，不得用当前草稿/block 补证 |

### 7.1 保存冲突(RPT-43012)

多人/多标签页同时编辑同一屏时,保存可能弹出「保存冲突」框(真乐观锁 `UPDATE ... WHERE canvas_version=?` 拦截),三个选择:

- **强制覆盖**: 用你本地的改动覆盖服务器最新版(⚠️ 对方的修改会丢失);
- **放弃本地并重载**: 丢弃你的改动,加载服务器最新草稿;
- **直接关闭弹框**: 什么都不做,保留你当前编辑态(可先去别处确认再决定)。

## 8. 运行时查看大屏

- 访问 `#/screen/{屏编码}`,页面按发布时选定的**适配策略**自适应浏览器窗口,窗口缩放实时重算;
- 顶部 72px 标题栏为半透明浮层(仅「返回」按钮可点击),画布与设计器所见即所得;
- 屏**从未发布**时显示中性引导文案「该大屏尚未发布」,不报错;
- 图表按各自「刷新(秒)」自动轮询取数;缺少组织/员工上下文时显示引导态而非报错(可加 `?orgCode=xxx&empId=xxx` 参数);
- 省级屏(PROVINCE)地图点位由渲染接口实时回填,不烘焙进发布包。
- 草稿处于待发布状态也不影响线上：线上读取上一次不可变发布包；删除草稿区块不会使已发布图表失效。

## 9. 注意事项与 FAQ

1. **随手保存**: 草稿保存零风险(不影响线上),建议编辑中频繁 Ctrl+S;
2. **发布是高危操作**: 立即影响线上,且需要独立的发布权限;没把握先用「预览草稿」;
3. **回滚只接受可信快照归档**；无 `bindSnapshots` 的历史归档不能直接回滚，须按上线只读盘点从可信历史/审计/备份受控回填，或经业务核对后重新发布；
4. **后端校验四件套**: 画布 JSON 上限 2MB、组件类型白名单、blockId 归属校验、坐标必须在设计基准内——超限保存会被拒绝并提示;
5. 图表拖入后**必须绑定数据源**才有数据,否则显示占位/引导态;
6. `?preview=draft` 是受服务端强制保护的设计态读取：除运行时四项门禁外还必须具备 `R_RPT_SCR_CV_GET`；无权时不返回草稿、屏配置或数据源身份。
7. 已被当前发布包或发布归档引用的数据源不可原地改查询语义或删除。若要改 `dsType`、来源、条线、配置、时间参数或状态，先在数据源管理页新建副本，再改草稿绑定并重新发布；错误提示会列出全部引用屏。
8. 图表属性面板如需列预览，只调用独立 `probe-columns` 管理 API（带非空 `reason`）；绝不可用运行时 `/api/screen/data` 的 v1 请求探测任意数据源。

# report-analytics-center 文档维护指导

本文件约束 `docs/modules/report-analytics-center/`，继承上级文档规则。

## 目录职责

- 记录动态/固定报表、保存查询、导出、SQL 探查、自由报表、外部数据查询和大屏设计/运行时。
- report 不写上游业务数据，但可以按事务写保存查询、导出任务、自由报表和大屏配置等自有状态。

## 阅读顺序

1. `01-功能规格.md`：报表范围、上游只读边界和自有写状态。
2. `03-接口设计与报文.md`：查询、导出和管理端 REST 契约。
3. `05-表结构DDL.md`：自有/外部表模型说明；不作为 DDL 执行入口。
4. `09-依赖契约摘要.md`：读侧来源；`10-大屏设计器操作指南.md`：草稿/发布/运行时操作。

## 契约同步与边界

- report 依赖 auth、governance、customer、performance，不依赖 workflow；业务模块不得依赖 report。
- 当前不对外暴露 `*Api`/`*QueryApi`。上游聚合走数据所有者公开 API；外部同步表只读且不归 report 管理结构。
- 保存查询乐观锁、导出任务状态、大屏草稿/发布快照、数据源引用或访问范围变化时，同步 `01`、`03`、相关事务说明和大屏指南。
- SQL 探查、导出和大屏访问属于高风险能力，必须同步独立资源、理由、审计、脱敏和 fail-close 规则。

## 2. 流程定义部署（由 workflow-center 负责）

本模块依赖的流程定义均在 `workflow-center` 模块部署，由 `Flowable RepositoryService` 加载 BPMN 文件。

### 2.1 流程清单

| Process Key | 流程名称 | 场景 | BPMN 文件 | 版本 |
|------------|--------|-----|---------|-----|
| loan_approve_v1 | 资产投放审批 | LOAN | bpmn/loan_approve_v1.bpmn20.xml | v1 |
| support_simple_v1 | 中场支持(场景A) | 产品负责人直接处理 | bpmn/support_simple_v1.bpmn20.xml | v1 |
| support_complex_v1 | 中场支持(场景B) | 秘书派单+支持人员 | bpmn/support_complex_v1.bpmn20.xml | v1 |

### 2.2 流程节点摘要

**loan_approve_v1 — 资产投放审批**

```
[发起] → [客户经理节点(start_form)]
       → [团队长审核(team_leader_review)]
       → [公司部审核(corp_review)] ← 含节点表单: isNeedCreditMeeting/creditMeetingConclusion
       → [信贷审批(credit_approval)] ← 含节点表单: approvalOpinion/approvedAmount/approvedTerm
       → [审批完成]
```

**support_simple_v1 — 中场支持场景A**

```
[发起] → [产品负责人处理(product_owner_handle)] ← 候选人=ProductApi.getProductResponsibleEmpIds
       → [办理完成]
```

**support_complex_v1 — 中场支持场景B**

```
[发起] → [部门秘书派单(dispatch)] ← 候选人=部门秘书角色
       → [支持人员办理(support_handle)] ← 候选人=秘书指定的 assignee
       → [办理完成]
```

### 2.3 部署方式

由 `workflow-center` 的 `ProcessDefinitionDeployer` 在 Spring Boot 启动时扫描 `classpath:bpmn/*.bpmn20.xml` 并调用：

```java
repositoryService.createDeployment()
    .name("bizapp_v1")
    .addClasspathResource("bpmn/loan_approve_v1.bpmn20.xml")
    .addClasspathResource("bpmn/support_simple_v1.bpmn20.xml")
    .addClasspathResource("bpmn/support_complex_v1.bpmn20.xml")
    .deploy();
```

**部署幂等性：** Flowable 内置哈希校验，BPMN 文件未变化则不会重复部署。

具体节点候选人配置与流程变量定义参见 `docs/modules/workflow-center/08-初始化数据清单.md`。

| 规则 | 说明 |

### 11.3 共享流程配置 `docs/schema/workflow-seed-v1.sql`

本模块依赖的流程定义 key：

| 流程 key | 节点 | 说明 |
|---|---|---|
| `loan_approve_v1` | `branch_approve` → `corp_review` → `credit_check` → `credit_approval` | 资产投放审批（4 节点） |
| `support_simple_v1` | `product_owner_handle` | 中场支持-场景 A（产品直达） |
| `support_complex_v1` | `dept_secretary_dispatch` → `support_staff_handle` | 中场支持-场景 B（部门承接） |

**种子数据位置**：

- `biz_process_map`：需配置 `LOAN → loan_approve_v1`、`SUPPORT:A → support_simple_v1`、`SUPPORT:B → support_complex_v1`

### 11.6 关键校验 SQL

```sql
-- 校验本模块资源登记
SELECT COUNT(*) FROM PT_RESOURCE
WHERE resource_id LIKE 'LOAN_%' OR resource_id LIKE 'SUPPORT_%';
-- 预期：≥ 14 条

-- 校验流程定义映射
SELECT biz_type, process_definition_key FROM biz_process_map
WHERE biz_type IN ('LOAN','SUPPORT','SUPPORT:A','SUPPORT:B');
-- 预期：3-4 条

-- 校验节点候选角色配置
SELECT process_definition_key, node_key, candidate_type, candidate_value
FROM wf_node_candidate_conf
WHERE process_definition_key IN ('loan_approve_v1','support_simple_v1','support_complex_v1')
ORDER BY process_definition_key, node_key;
-- 预期：至少 7 行
```

# 业务申请中心 — 依赖契约摘要

> 依赖关系以本模块 `pom.xml` 和源码 import 为准。跨模块只依赖公开 API、QueryApi、DTO 或事件；不直接 join 对方私有表。

## 1. 依赖关系

| 依赖模块 | 使用的公开契约 | 当前用途 |
|---|---|---|
| `common` | web、security、aop、db、trace | 统一响应、鉴权、审计、事务/持久化和链路 |
| `auth-permission-center` | `CurrentUserApi`、`OrgApi`、相关 DTO | 获取当前员工/机构、转换展示名称和执行数据范围 |
| `customer-marketing-center` | `CustomerQueryApi`、`AssetProjectQueryApi`、`CustomerDTO` | 客户有效性和展示；跨域统计资产立项数量/金额 |
| `portal-content-center` | `ProductApi`、`ProductDTO` | 支持产品列表、产品可用性、产品负责人和展示名称 |
| `workflow-center` | `WorkflowApi`、`StartProcessCmd`、`WorkflowLaunchResp`、`ProcessCompletedEvent` | 启动支持流程和接收审批结果 |
| `system-governance-center` | `NotifyApi`、统一 AOP 能力 | 申请人审批结果通知、公共审计/文件能力 |

## 2. 客户营销契约

`SupportService` 创建时调用 `CustomerQueryApi.isValidCustomer(custId)`；DTO converter 用 `getCustomer` 补充客户名称。`BizApplyQueryApiImpl` 通过可选的 `AssetProjectQueryApi` 取得资产统计，客户 ID 不能转换为数字时返回 0，不应让统计接口改变支持申请写入。

本模块只保存 `cust_id` 和可选的 `source_touch_task_id`，不访问客户或触达任务表。若需查询触达来源，应由客户营销模块公开新的只读契约，而不是在本模块增加 Mapper。

## 3. 产品与组织契约

- `SupportController` 的 `/available-products` 直接代理 `ProductApi.listSupportAvailableProducts()`。
- `SupportProductSplitService` 通过 `ProductApi` 查询产品，要求产品支持中场支持；产品负责人信息用于场景 A 的处理人初始化。
- `SupportRequestDTOConverter` 通过 `ProductApi` 补充产品名称，并通过 `OrgApi` 补充承接部门名称。
- `support_dept_id`、`owner_org_id` 和员工字段保存编码，不复制组织主数据。

## 4. 工作流契约

提交时构造 `StartProcessCmd`：

| 字段 | 值 |
|---|---|
| `bizType` | `SUPPORT` |
| `bizId` | 申请 ID |
| `businessKey` | `SUPPORT:{id}` |
| `processDefinitionKey` | `support_simple_v1` 或 `support_complex_v1` |
| `startUser`/`startOrgId` | 当前员工/机构 |
| `title` | `中场支持申请-{requestNo}` |

`SupportWorkflowListener` 消费 `ProcessCompletedEvent`，仅处理 `SUPPORT:` 前缀；回调在 `AFTER_COMMIT` 的新事务中条件更新 `IN_APPROVAL`，再发布支持完成/驳回事件。当前撤回不调用流程取消 API，承接侧转交也不依赖工作流 QueryApi。

## 5. 本模块对外契约

| 契约 | 消费方/用途 |
|---|---|
| `SupportApi` | 其他模块按 ID、业务键、客户、提交分组或 ID 列表只读查询 |
| `SupportQueryApi` | 报表/绩效按条件分页和按创建人/承接人统计完成数量 |
| `BizApplyQueryApi` | 报表/绩效获取跨域运行中数量和员工统计 |
| `SupportSubmittedEvent` | 支持申请进入审批后的事件通知 |
| `SupportDispatchedEvent` | 部门派单后的事件通知 |
| `SupportCompletedEvent`、`SupportRejectedEvent` | 支持办理/审批结果通知 |

公共 API 返回 DTO，不承诺 Mapper 查询列、内部逻辑删除字段或数据库结构稳定。

## 6. 变更约束

- 修改公共 API、DTO、事件字段、REST 端点或 `@BizAuth` 时，同步修改 `03-接口设计与报文.md`、`04-对外API契约.md`、资源登记和契约检查。
- 依赖方故障按各公开契约的异常语义处理；不能通过直连数据库、复制实体或引入平行缓存绕过依赖边界。
- 版本号、构件数量、调用耗时和一次性联调步骤不属于稳定契约，现场配置和测试结果另行记录。

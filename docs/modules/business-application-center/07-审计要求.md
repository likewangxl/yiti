# 业务申请中心 — 审计要求

> 本文以当前 `SupportController`、`SupportDeptController` 的 `@BizAuth`/`@AuditLog` 注解为准，记录支持申请的审计边界。统一审计落库和脱敏实现由公共基础设施负责。

## 1. 审计动作

| 端点操作 | `@AuditLog.action` | 资源类型 | 高危/原因 |
|---|---|---|---|
| 创建 | `CREATE_SUPPORT_REQUEST` | `SUPPORT_REQUEST` | 写操作 |
| 提交 | `SUBMIT_SUPPORT_REQUEST` | `SUPPORT_REQUEST` | 写操作 |
| 删除草稿 | `DELETE_SUPPORT_REQUEST` | `SUPPORT_REQUEST` | 写操作 |
| 撤回 | `CANCEL_SUPPORT_REQUEST` | `SUPPORT_REQUEST` | `reasonRequired=true` |
| 导出入口 | `EXPORT_SUPPORT_REQUEST` | `SUPPORT_REQUEST` | `SUPPORT/EXPORT`，当前实现返回 501 |
| 承接侧派单 | `DISPATCH_SUPPORT_REQUEST` | `SUPPORT_REQUEST` | 写操作 |
| 承接侧转交 | `TRANSFER_SUPPORT_REQUEST` | `SUPPORT_REQUEST` | `reasonRequired=true` |
| 承接侧办理完成 | `COMPLETE_SUPPORT_REQUEST` | `SUPPORT_REQUEST` | 写操作 |

每个端点同时声明匹配的 `@BizAuth`：发起侧使用 `SUPPORT`，承接侧使用 `SUPPORT_DEPT`；资源授权必须与 Controller 路径和动作一致。

## 2. 审计时机与目标字段

统一 AOP 在请求进入业务方法时记录操作人、机构、traceId、资源 ID、动作、结果和耗时；Service 层权限校验失败也应保留失败审计。写操作的目标记录以数据库行实际状态为准，不能只记录前端提交值。

操作与关键业务字段的审计重点：

- 创建：`custId`、`productIds`、`supportDeptId`、`sourceTouchTaskId`、路由场景和生成的 `submitGroupId`；
- 提交：申请 ID、`requestNo`、`businessKey`、状态变化和 `processInstanceId`；
- 派单/转交：变更前后的 `assignedEmpId`，以及派单人、承接部门；
- 办理完成：`success`、状态变化和办理人；
- 撤回/导出/转交：按统一审计组件要求采集原因。导出入口当前不产生文件或数据查询结果。

## 3. 数据范围与权限

- `SUPPORT` 列表/详情使用 `owner_org_id` 与 `created_by` 的统一数据范围；
- `SUPPORT_DEPT` 使用 `support_dept_id` 与 `assigned_emp_id` 的部门/个人范围；
- 写操作在 `SupportService`/`SupportDeptService` 基于锁定的目标申请再次校验创建人、承接部门和当前承接人；
- 非白名单接口必须同时具备 `@BizAuth` 和 `PT_RESOURCE` 登记，不能以隐藏前端入口替代授权。

## 4. 敏感数据与日志

日志和审计载荷不得输出凭据、完整手机号、证件号等敏感信息；客户名称、需求文本和附件/文件标识按公共审计脱敏规则处理。应用日志只保留申请 ID、申请编号、traceId、操作结果等定位信息，避免打印完整请求体。

工作流审批节点的办理审计由 `workflow-center` 负责；本模块只审计本模块 Controller 的动作和状态回写结果，避免重复记录同一审批动作。

## 5. 事件回写审计

`SupportWorkflowListener` 在 `AFTER_COMMIT`、`REQUIRES_NEW` 事务中条件更新 `IN_APPROVAL` 状态。重复回调影响行数为 0 时不再次发布完成/驳回事件；监听器异常记录日志但不反向修改已提交的工作流事务。领域事件载荷和通知结果应以申请 ID、业务键和 traceId 关联审计。

## 6. 维护约束

新增或修改 Controller、`@BizAuth`、`@AuditLog`、错误码或 DTO 时，必须同步更新接口文档和 `PT_RESOURCE`；高危动作必须使用独立资源授权和可追溯审计。本文不规定未落地的归档脚本、阈值或异步导出流程。

# AUTH 认证授权中心 -- 接口设计与报文

> 本文档是 AUTH 模块最重要的接口参考文件，所有接口均达到字段级可执行精度。
> 统一响应格式：`ResponseWrapper<T>`，包含 code/message/data/traceId/timestamp 五个字段。

---

## A. 会话管理

### A.1 POST /api/auth/login -- 用户登录

- **权限**：无需认证（白名单URL）
- **说明**：验证用户名密码，创建Session，返回用户基本信息与角色列表

**请求体 LoginReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 字典/取值范围 | 示例值 |
|:---|:---|:---|:---|:---|:---|
| username | String | 是 | `@NotBlank @Size(max=50)` | PT_USER.USERNAME | `"E10001"` |
| password | String | 是 | `@NotBlank @Size(min=6, max=64)` | - | `"******"` |

**响应体 LoginRespDTO：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| empId | String | 工号（PT_USER.USER_ID） |
| username | String | 用户名 |
| displayName | String | 中文姓名（PT_USER.USERCHNNAME） |
| mainOrgCode | String | 主机构编码（EXT_USER_ORG.ORG_CODE） |
| mainOrgName | String | 主机构名称（EXT_ORG_INFO.ORG_NAME） |
| roles | List\<RoleSimpleDTO\> | 角色列表 |
| token | String | 会话令牌（Spring Session ID） |

**RoleSimpleDTO：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| roleId | String | 角色ID |
| roleCode | String | 角色编码 |
| roleChName | String | 角色中文名 |

**业务规则：**
1. 用户名不存在 -> AUTH-40101
2. 密码错误 -> AUTH-40101（不暴露"用户名存在但密码错误"）；同时 PASS_WRONG_COUNT + 1
3. PASS_WRONG_COUNT >= 5 -> 自动锁定（ISLOCKED = 1），返回 AUTH-40106
4. ISLOCKED = 1 -> AUTH-40102
5. ISEXPIRED = 1 -> AUTH-40103
6. ISENABLED = 1（未启用）-> AUTH-40104
7. 登录成功 -> PASS_WRONG_COUNT 重置为 0，创建 HttpSession

**错误响应示例：**

```json
{
  "code": "AUTH-40101",
  "message": "用户名或密码错误",
  "traceId": "a1b2c3d4e5f6",
  "data": null,
  "timestamp": "2026-04-01T10:30:00"
}
```


## B. 角色管理

### B.1 GET /api/admin/roles -- 角色列表（分页）

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = READ)`
- **说明**：分页查询角色列表，支持模糊搜索

**请求参数（Query）：**

| 参数 | Java类型 | 必填 | 校验 | 说明 |
|:---|:---|:---|:---|:---|
| keyword | String | 否 | `@Size(max=100)` | 角色编码/名称模糊搜索 |
| recordStatus | Integer | 否 | `0` 或 `1` | 0可用 / 1不可用 |
| pageNo | int | 否 | `@Min(1)` 默认1 | 页码 |
| pageSize | int | 否 | `@Min(1) @Max(100)` 默认20 | 每页条数 |

**响应体 PageResult\<RoleRespDTO\>：**

**RoleRespDTO 字段：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| roleId | String | 角色ID |
| roleCode | String | 角色编码 |
| roleChName | String | 角色中文名 |
| recordStatus | Integer | 状态（0可用/1不可用） |
| sysCode | String | 系统编号 |
| createTime | LocalDateTime | 创建时间 |
| updateTime | LocalDateTime | 更新时间 |
| remark | String | 备注 |
| userCount | Integer | 该角色下用户数 |

---

### B.2 POST /api/admin/roles -- 新增角色

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = CONFIG)`
- **说明**：新增一个角色

**请求体 RoleCreateReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 字典/取值范围 | 示例值 |
|:---|:---|:---|:---|:---|:---|
| roleCode | String | 是 | `@NotBlank @Size(max=10) @Pattern(regexp="^[A-Z_]+$")` | 大写字母+下划线 | `"CUST_MGR"` |
| roleChName | String | 是 | `@NotBlank @Size(max=100)` | - | `"客户经理"` |
| remark | String | 否 | `@Size(max=100)` | - | `"一线营销人员"` |

**业务规则：**
1. ROLE_ID 由系统自动生成（`R_` + UUID前8位大写）
2. ROLE_CODE 唯一性校验（查库去重），重复返回 AUTH-40901
3. SYS_CODE 默认为 `"PLATFORM"`
4. RECORD_STATUS 默认为 0（可用）

**响应体**：`ResponseWrapper<RoleRespDTO>`

---

### B.4 DELETE /api/admin/roles/{roleId} -- 删除角色（逻辑删除）

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = PERMISSION_CHANGE)`
- **说明**：逻辑删除角色（RECORD_STATUS 设为 1），**高危动作，需审计**

**路径参数**：roleId (String) -- 角色ID

**请求参数（Query）：**

| 参数 | Java类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| reason | String | 是 | 操作原因（高危动作必填） |

**业务规则：**
1. roleId 不存在返回 AUTH-40401
2. 检查角色下是否还有绑定用户，如有需先解绑
3. 逻辑删除：RECORD_STATUS = 1
4. 同时清除该角色的 PT_ROLE_RESOURCE 和 PT_ROLE_BIZ_SCOPE 配置
5. 发布权限缓存失效事件
6. 写审计日志（变更前后快照）

**响应体**：`ResponseWrapper<Void>`

### C.2 POST /api/admin/users/{userId}/roles -- 绑定角色

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = PERMISSION_CHANGE)`
- **说明**：为指定用户批量绑定角色，**高危动作，需审计**

**路径参数**：userId (String) -- 用户工号

**请求体 UserRoleBindReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 说明 |
|:---|:---|:---|:---|:---|
| roleIds | List\<String\> | 是 | `@NotEmpty @Size(max=20)` | 要绑定的角色ID列表 |

### D.2 POST /api/admin/resources -- 新增资源

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = CONFIG)`
- **说明**：新增一个资源（菜单或接口动作）

**请求体 ResourceCreateReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 字典/取值范围 | 示例值 |
|:---|:---|:---|:---|:---|:---|
| resourceUrl | String | 是 | `@NotBlank @Size(max=256)` | 支持Ant通配 | `"/api/leads"` |
| resourceMethod | String | 是 | `@NotBlank @Pattern(regexp="^(GET\|POST\|PUT\|DELETE\|\\*)$")` | GET/POST/PUT/DELETE/* | `"POST"` |
| menuName | String | 是 | `@NotBlank @Size(max=256)` | - | `"新增线索"` |
| isMenu | Integer | 是 | `@NotNull` | 0是菜单 / 1不是 | `1` |
| menuEndFlag | String | 否 | `@Pattern(regexp="^[01]$")` | "0"非叶子 / "1"叶子 | `"1"` |
| menuRankNo | Integer | 否 | `@Min(0)` | 排序号 | `10` |
| parentResourceId | String | 否 | `@Size(max=60)` | 上级资源ID | `"R_LEAD"` |
| sysCode | String | 否 | `@Size(max=10)` | 默认PLATFORM | `"PLATFORM"` |

**业务规则：**
1. RESOURCE_ID 由系统自动生成（`RES_` + 业务前缀 + 序号）
2. URL + Method + SysCode 唯一约束校验，重复返回 AUTH-40902
3. parentResourceId 不为空时需校验父资源存在

**响应体**：`ResponseWrapper<ResourceTreeNodeDTO>`

### F.3 POST /api/admin/biz-scopes -- 保存/更新配置

- **权限**：`@BizAuth(bizType = SYS_CONFIG, action = PERMISSION_CHANGE)`
- **说明**：为指定角色的指定BizType设置DataScope，**高危动作，需审计**

**请求体 BizScopeSaveReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 字典/取值范围 | 示例值 |
|:---|:---|:---|:---|:---|:---|
| roleId | String | 是 | `@NotBlank @Size(max=50)` | PT_ROLE.ROLE_ID | `"R_RM"` |
| bizType | String | 是 | `@NotBlank` | 必须为有效BizType枚举值 | `"LEAD"` |
| dataScope | String | 是 | `@NotBlank` | 必须为有效DataScopeType枚举值 | `"SELF_CREATED"` |
| reason | String | 是 | `@NotBlank @Size(max=200)` | - | `"客户经理线索设为本人创建"` |

**业务规则：**
1. roleId 不存在返回 AUTH-40401
2. bizType 不在 BizType 枚举中返回参数校验错误
3. dataScope 不在 DataScopeType 枚举中返回参数校验错误
4. 采用 UPSERT 策略：已存在则更新 DATA_SCOPE，不存在则新增
5. ID 使用 `S_` + ROLE_CODE + `_` + BIZ_TYPE 格式
6. 发布权限缓存失效事件
7. 写审计日志（变更前后快照）

### H.2 POST /api/auth/check-permission -- 校验权限

- **权限**：需认证（已登录用户）
- **说明**：校验当前用户是否有指定资源/BizType的权限

**请求体 CheckPermissionReqDTO：**

| 字段 | Java类型 | 必填 | 校验注解 | 说明 |
|:---|:---|:---|:---|:---|
| resourceUrl | String | 是 | `@NotBlank @Size(max=256)` | 要校验的资源URL |
| resourceMethod | String | 是 | `@NotBlank @Pattern(regexp="^(GET\|POST\|PUT\|DELETE)$")` | GET/POST/PUT/DELETE |
| bizType | String | 否 | - | BizType（可选，不传则只校验RBAC） |
| action | String | 否 | - | BizAction（可选） |

**响应体 CheckPermissionRespDTO：**

| 字段 | Java类型 | 说明 |
|:---|:---|:---|
| allowed | Boolean | 是否允许 |
| rbacPassed | Boolean | RBAC是否通过 |
| scopePassed | Boolean | 数据范围是否通过（仅传了bizType时有值） |
| scope | String | 命中的DataScopeType（如有） |
| denyReason | String | 拒绝原因（如有） |

**响应示例（允许）：**

```json
{
  "code": "200",
  "message": "操作成功",
  "traceId": "x1y2z3",
  "data": {
    "allowed": true,
    "rbacPassed": true,
    "scopePassed": true,
    "scope": "SELF_CREATED",
    "denyReason": null
  },
  "timestamp": "2026-04-01T11:00:00"
}
```

**响应示例（拒绝）：**

```json
{
  "code": "200",
  "message": "操作成功",
  "traceId": "x1y2z3",
  "data": {
    "allowed": false,
    "rbacPassed": true,
    "scopePassed": false,
    "scope": null,
    "denyReason": "用户角色未配置LEAD的数据范围"
  },
  "timestamp": "2026-04-01T11:00:00"
}
```

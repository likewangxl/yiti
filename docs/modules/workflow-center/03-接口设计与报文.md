# 工作流中心 -- 接口设计与报文

> 版本：V1.0 | 最后更新：2026-04-02
> 本文档定义所有 HTTP 接口的字段级精度，可直接用于开发。

---

## 接口分组总览

| 分组 | 路由前缀 | Controller | 说明 |
|:---|:---|:---|:---|
| A. 待办/已办查询 | `/api/workflow/tasks` | WorkflowTaskController | 待办列表、已办列表、任务详情 |
| B. 任务操作 | `/api/workflow/tasks/{taskId}/*` | WorkflowTaskController | 签收、审批、驳回、转交 |
| C. 流程查询 | `/api/workflow/processes` | WorkflowProcessController | 流程实例详情、进度图、审批日志、流程映射 |
| D. 管理接口 | `/api/admin/workflow` | WorkflowConfigController | 超时规则、候选人配置、表单配置、流程定义 |

---

## A. 待办/已办查询

### A.1 GET /api/workflow/tasks -- 查询待办列表（分页）

**权限说明**：无需 `@BizAuth`（待办天然按当前用户过滤，待办可见范围由 Flowable + 本系统候选组解析控制）。

#### 请求参数（Query）

| 参数 | 类型 | 必填 | 校验 | 说明 |
|:---|:---|:---|:---|:---|
| bizType | String | 否 | 枚举值 | 按业务类型过滤：LEAD / LOAN / SUPPORT / TOUCH / TARGET_ADJUST / ALLOC_ADJUST |
| keyword | String | 否 | @Size(max=100) | 按标题模糊搜索 |
| pageNo | int | 否 | @Min(1) | 页码，默认 1 |
| pageSize | int | 否 | @Min(1) @Max(100) | 每页条数，默认 20 |

#### 响应体

```json
{
  "code": 200,
  "message": "success",
  "traceId": "TRC_20260402150000_001",
  "data": {
    "pageNo": 1,
    "pageSize": 20,
    "total": 156,
    "totalPages": 8,
    "records": [
      {
        "taskId": "TSK_00001",
        "processInstanceId": "PRC_00001",
        "businessKey": "LOAN:LA202603060001",
        "bizType": "LOAN",
        "bizId": "LA202603060001",
        "title": "资产投放申请 - XX科技有限公司",
        "startUser": "E10001",
        "startUserName": "张三",
        "startOrgName": "城南支行",
        "startTime": "2026-03-06T09:00:00+08:00",
        "taskName": "公司部审核",
        "taskCreateTime": "2026-03-06T14:30:00+08:00",
        "assignee": null,
        "candidateGroups": ["ROLE_CORP_REVIEWER"],
        "slaStatus": "YELLOW",
        "warningTime": "2026-03-08T09:00:00+08:00",
        "timeoutTime": "2026-03-10T09:00:00+08:00",
        "claimable": true
      }
    ]
  }
}
```

#### TaskRespDTO 字段定义

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| taskId | String | Flowable 任务ID |
| processInstanceId | String | 流程实例ID |
| businessKey | String | 业务键 |
| bizType | String | 业务类型 |
| bizId | String | 业务对象ID |
| title | String | 流程标题 |
| startUser | String | 发起人工号 |
| startUserName | String | 发起人姓名 |
| startOrgName | String | 发起人机构名称 |
| startTime | String(ISO 8601) | 流程发起时间 |
| taskName | String | 节点名称（如"公司部审核"） |
| taskCreateTime | String(ISO 8601) | 到达节点时间 |
| assignee | String | 当前处理人工号（未签收时为 null） |
| candidateGroups | List\<String\> | 候选组列表（已签收后为空） |
| slaStatus | String | 红绿灯状态：GREEN / YELLOW / RED |
| warningTime | String(ISO 8601) | 黄灯预警时间点（根据工作日历计算） |
| timeoutTime | String(ISO 8601) | 红灯超时时间点（根据工作日历计算） |
| claimable | boolean | 是否可领取（true = 用户在候选组中且任务未签收） |

## B. 任务操作

### B.1 POST /api/workflow/tasks/{taskId}/claim -- 签收

**权限说明**：BizType 通过 business_key 前缀动态解析，校验当前用户在候选组范围内。

#### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| taskId | String | 是 | Flowable 任务ID |

#### 请求体

无（或空 JSON `{}`）

#### 成功响应

```json
{
  "code": 200,
  "message": "签收成功",
  "traceId": "TRC_20260402150003_004",
  "data": null
}
```

#### 错误响应示例

**WF-40902 任务不存在或已完成：**
```json
{
  "code": 409,
  "message": "任务不存在或已完成",
  "traceId": "TRC_20260402150003_005",
  "errorCode": "WF-40902",
  "data": null
}
```

**WF-40903 无权签收（非候选人）：**
```json
{
  "code": 403,
  "message": "无权签收，当前用户非候选人",
  "traceId": "TRC_20260402150003_006",
  "errorCode": "WF-40903",
  "data": null
}
```

**WF-40904 任务已被签收：**
```json
{
  "code": 409,
  "message": "任务已被签收",
  "traceId": "TRC_20260402150003_007",
  "errorCode": "WF-40904",
  "data": null
}
```

### B.2 POST /api/workflow/tasks/{taskId}/approve -- 审批通过

**权限说明**：BizType 动态解析，校验当前用户为 assignee。

#### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| taskId | String | 是 | Flowable 任务ID |

#### 请求体 TaskApproveReqDTO

| 字段 | 类型 | 必填 | 校验 | 说明 |
|:---|:---|:---|:---|:---|
| opinion | String | 否 | @Size(max=500) | 审批意见 |
| formData | Map\<String, Object\> | 否 | 按节点 required_fields 校验 | 节点表单数据（仅 editable_fields 中的字段） |

#### 请求示例

```json
{
  "opinion": "同意，客户资质良好",
  "formData": {
    "needCreditMeeting": "YES",
    "creditMeetingResult": "信贷会一致通过，授信金额5000万"
  }
}
```

#### 成功响应

```json
{
  "code": 200,
  "message": "审批通过",
  "traceId": "TRC_20260402150004_008",
  "data": null
}
```

#### 错误响应示例

**WF-40905 无权办理：**
```json
{
  "code": 403,
  "message": "无权办理，当前用户非任务处理人",
  "traceId": "TRC_20260402150004_009",
  "errorCode": "WF-40905",
  "data": null
}
```

**WF-42202 必填字段缺失：**
```json
{
  "code": 422,
  "message": "必填字段缺失",
  "traceId": "TRC_20260402150004_010",
  "errorCode": "WF-42202",
  "data": {
    "missingFields": ["needCreditMeeting", "creditMeetingResult"]
  }
}
```


### D.6 PUT /api/admin/workflow/node-forms/{id} -- 编辑节点表单

**权限注解**：`@BizAuth(bizType = "SYS_CONFIG", action = "CONFIG")`

#### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| id | String | 是 | 表单配置ID |

#### 请求体 NodeFormUpdateReqDTO

| 字段 | 类型 | 必填 | 校验 | 说明 |
|:---|:---|:---|:---|:---|
| formFields | List\<FormFieldDTO\> | 是 | @NotEmpty | 表单字段定义列表 |
| editableFields | List\<String\> | 是 | @NotNull | 可编辑字段 Key 列表 |
| requiredFields | List\<String\> | 是 | @NotNull | 必填字段 Key 列表 |

#### FormFieldDTO

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| fieldKey | String | 是 | 字段键名 |
| fieldLabel | String | 是 | 字段显示名称 |
| fieldType | String | 是 | 字段类型：text / number / select / date / textarea |

#### 请求示例

```json
{
  "formFields": [
    {"fieldKey": "custName", "fieldLabel": "客户名称", "fieldType": "text"},
    {"fieldKey": "loanAmount", "fieldLabel": "授信金额", "fieldType": "number"},
    {"fieldKey": "needCreditMeeting", "fieldLabel": "是否需要上信贷会", "fieldType": "select"},
    {"fieldKey": "creditMeetingResult", "fieldLabel": "信贷会结论", "fieldType": "text"}
  ],
  "editableFields": ["needCreditMeeting", "creditMeetingResult"],
  "requiredFields": ["needCreditMeeting", "creditMeetingResult"]
}
```

#### 校验规则

1. `editableFields` 中的每个字段必须在 `formFields` 中存在
2. `requiredFields` 中的每个字段必须在 `editableFields` 中存在（必填字段必须可编辑）

#### 成功响应

```json
{
  "code": 200,
  "message": "更新成功",
  "traceId": "TRC_20260402150016_027",
  "data": null
}
```

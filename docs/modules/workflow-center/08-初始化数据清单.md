### 4.3 BPMN 通用配置

所有流程定义需配置以下通用元素：

| 配置项 | 值 | 说明 |
|---|---|---|
| `flowable:candidateGroups` | 由 TaskListener 动态设置 | 不在 BPMN XML 中硬编码，从 `wf_node_candidate_conf` 读取 |
| `flowable:executionListener`(start) | `ProcessStartListener` | 流程启动监听器，初始化流程变量 |
| `flowable:executionListener`(end) | `ProcessEndListener` | 流程结束监听器，更新 biz_process_map 状态 |
| `flowable:taskListener`(create) | `TaskCreateListener` | 任务创建监听器，设置候选组、更新 biz_process_map |
| `flowable:taskListener`(complete) | `TaskCompleteListener` | 任务完成监听器，刷新 biz_process_map |
| 驳回处理 | 网关判断 `approved` 变量 | `approved=true` 继续，`approved=false` 跳转到 EndEvent(REJECTED) |

### 4.4 部署方式

Flowable 自动部署（Spring Boot 集成）：

```yaml
flowable:
  process-definition-location-prefix: classpath*:processes/
  process-definition-location-suffixes:
    - "**.bpmn20.xml"
  database-schema-update: true
  history-level: audit
```

将 BPMN 文件放置在 `workflow-center/src/main/resources/processes/` 目录下，应用启动时 Flowable 自动扫描并部署。

## 6. 种子数据文件引用

| 数据类别 | 文件路径 | 备注 |
|---|---|---|
| 自有表 DDL | `docs/schema/ddl-workflow.sql` | 4 张自有表建表语句 |
| 候选人/表单/超时配置 | `docs/schema/workflow-seed-v1.sql` | 57 条种子数据（INSERT ON DUPLICATE KEY UPDATE） |
| 资源登记 | `docs/schema/seed-v1.sql` 第 3.5 节 | 12 条 PT_RESOURCE 记录 |
| 角色-资源绑定 | `docs/schema/seed-v1.sql` 第 4.2-4.11 节 | 各角色的工作流资源绑定 |
| BPMN 流程定义 | `docs/workflow/`（待创建） | 9 个 BPMN XML 文件（V1 开发时编写） |

### 6.1 执行顺序

```
1. docs/schema/ddl-workflow.sql        -- 建表（自有表）
2. Flowable 自动建表                     -- 引擎表（应用启动时自动执行）
3. docs/schema/seed-v1.sql             -- 资源登记 + 角色绑定
4. docs/schema/workflow-seed-v1.sql    -- 工作流配置种子数据
5. BPMN 自动部署                         -- 应用启动时 Flowable 自动扫描部署
```

### 6.2 幂等策略

- 自有表 DDL：`CREATE TABLE IF NOT EXISTS`
- 资源登记：`INSERT IGNORE`
- 工作流配置种子数据：`INSERT ... ON DUPLICATE KEY UPDATE`
- BPMN 部署：Flowable 自动比较资源内容，未变更不重复部署

### 6.3 当前节点可审批员工的数据来源

- 候选范围仍由本文 §1 的既有节点候选人配置解析并写入 Flowable 运行时任务身份链接。
- `WorkflowQueryApi.getActiveTaskCandidates` 不直接重算静态配置，仅读取当前任务实际 assignee/candidate，因此能保留任务创建时已应用的机构范围缩减结果。
- 员工展示信息来自现有 `PT_USER`：`USERNAME` 为工号，`USERCHNNAME` 为姓名；无需 DDL 或 seed 变更。

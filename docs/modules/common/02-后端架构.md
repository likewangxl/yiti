# COMMON 基础层 — 后端架构

## 1. 包结构


## 2. Maven 模块结构

将 common 拆分为 5 个子模块，所有业务模块统一引入 common 父依赖即可：

```xml
<modules>
    <module>common-web</module>       <!-- 统一响应、分页、异常处理 -->
    <module>common-trace</module>     <!-- traceId 链路追踪 -->
    <module>common-aop</module>       <!-- 日志、耗时、审计切面 -->
    <module>common-db</module>        <!-- 分页拦截、审计字段、慢 SQL -->
    <module>common-security</module>  <!-- 权限注解、枚举、上下文、脱敏 -->
</modules>
```

子模块间依赖关系：

```
common-security  ──>  common-web（依赖异常类）
common-aop       ──>  common-trace（依赖 traceId 上下文）
                 ──>  common-security（依赖脱敏工具）
common-db        ──>  common-security（依赖 CurrentUserContext 填充审计字段）
```

所有子模块均为**必选**，业务模块通过引入 common 父 POM 一次性引入全部子模块。

## 3. 依赖原则

| 规则 | 说明 |
|------|------|
| common 不依赖任何业务模块 | 单向依赖，业务模块依赖 common，反向禁止 |
| common 只依赖基础框架 | Spring Boot Starter、MyBatis、Redis Client、SLF4J、Jackson 等 |
| 所有业务模块通过 Maven 依赖 common | 在业务模块 pom.xml 中引入 common 父依赖 |
| common 定义接口/注解/枚举 | 具体鉴权判定由 auth-permission-center 实现 |
| common 中禁止引入 Flowable 依赖 | Flowable 仅限 workflow-center 使用 |
| common 中禁止引入 MinIO 依赖 | 对象存储由 portal-content-center 封装 |

## 4. 分层规范

| 允许 | 禁止 |
|------|------|
| @Component | @Controller / @RestController |
| @Configuration | @Mapper |
| @Aspect | Entity 类（数据库实体） |
| record（上下文/DTO） | Service 实现类（含业务逻辑） |
| 枚举、注解 | 直接数据库操作 |
| Filter / Interceptor | 业务相关的常量 |

## 5. 自动装配

各子模块通过 Spring Boot 自动装配机制生效：

```
resources/
└── META-INF/
    └── spring/
        └── org.springframework.boot.autoconfigure.AutoConfiguration.imports
```

每个子模块注册各自的自动配置类：

| 子模块 | 自动配置类 |
|--------|------------|
| common-web | WebAutoConfiguration（注册 GlobalExceptionHandler、CorsConfig） |
| common-trace | TraceAutoConfiguration（注册 TraceIdFilter、TraceIdInterceptor） |
| common-aop | AopAutoConfiguration（注册 ApiLogAspect、MethodTimingAspect、AuditLogAspect） |
| common-db | DbAutoConfiguration（注册 PageInterceptor、AuditFieldFiller、SlowSqlInterceptor） |
| common-security | SecurityAutoConfiguration（注册 DataScopeContext 清理 Filter） |

## 6. 请求处理链路

```
HTTP Request
    │
    ├── TraceIdFilter              # 1. 生成 traceId，注入 MDC
    │
    ├── Spring Security Filter     # 2. 认证（auth-permission-center 提供）
    │
    ├── DataScopeFilter            # 3. 解析权限上下文，写入 DataScopeContext
    │
    ├── Controller                 # 4. 请求分发
    │   │
    │   ├── @BizAuth 拦截          # 4.1 权限校验（auth-permission-center 实现）
    │   │
    │   ├── ApiLogAspect           # 4.2 记录入参
    │   │
    │   ├── Service 层             # 4.3 业务处理
    │   │   ├── AuditLogAspect     #     高危操作审计
    │   │   └── MethodTimingAspect #     耗时统计
    │   │
    │   └── ApiLogAspect           # 4.4 记录出参
    │
    ├── GlobalExceptionHandler     # 5. 异常统一处理
    │
    └── ResponseWrapper            # 6. 统一响应包装
        │
        └── DataScopeContext.clear()  # 7. 清理 ThreadLocal
```

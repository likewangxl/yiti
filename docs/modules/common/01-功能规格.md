# COMMON 基础层 — 功能规格

## 1. 模块定位

- common 是平台公共基础设施层，为所有业务模块提供统一的基础能力
- 不包含任何业务逻辑
- 所有业务模块必须依赖 common
- common 不依赖任何业务模块，仅依赖 Spring Boot Starter、MyBatis、Redis Client 等基础框架

## 2. 子模块职责

### 2.1 common-web

职责：

- **ResponseWrapper\<T\>** — 统一响应包装，包含 code / message / traceId / data / page / timestamp 字段
- **PageRequest / PageResult\<T\>** — 统一分页模型，默认 pageSize=20，最大 100，排序字段白名单校验
- **GlobalExceptionHandler** — 全局异常处理器，将异常转为统一响应格式，区分业务异常与系统异常
- **BizException / AuthException / PermissionDeniedException** — 业务异常层次体系
  - BizException：通用业务异常基类
  - AuthException：登录态失效、未认证
  - PermissionDeniedException：资源未授权、数据范围不足、写范围校验失败
- **RequestValidator** — 参数校验增强（与 javax.validation 配合），提供自定义校验注解支持
- **跨域配置（CORS）** — 开发环境跨域支持

### 2.2 common-trace

职责：

- **TraceIdFilter** — 在 Filter 层生成 traceId 并注入 MDC，确保每个请求都有唯一追踪标识
- **TraceIdInterceptor** — 确保跨模块调用传递 traceId，保持全链路可追踪
- **MDC 工具类** — 封装 SLF4J MDC 操作，方便在日志中输出 traceId
- **链路上下文模型** — TraceContext，保存本次请求的 traceId、请求来源、时间戳等上下文信息

### 2.3 common-aop

职责：

- **ApiLogAspect** — 接口入参/出参日志（含脱敏），自动记录每个 Controller 方法的请求参数和响应结果
- **MethodTimingAspect** — 方法耗时统计，慢方法告警（阈值可配置，默认 500ms 告警）
- **AuditLogAspect** — 高危动作审计切面，拦截 @AuditLog 注解标注的方法，记录操作人、操作时间、操作内容
- **@AuditLog 注解定义** — 标记需要审计的高危操作，支持 action / resourceType / reasonRequired 属性

### 2.4 common-db

职责：

- **MyBatis 分页拦截器** — 自动拦截分页查询，注入分页 SQL（基于 PageRequest）
- **审计字段自动填充** — created_by / created_time / updated_by / updated_time 在 INSERT/UPDATE 时自动注入当前用户和时间
- **慢 SQL 拦截与告警** — 执行时间超过 5s 的 SQL 自动告警（记录完整 SQL、参数、耗时）
- **Druid 连接池监控配置** — 内置 Druid 监控页面配置和统计过滤器

### 2.5 common-security

职责：

- **BizType 枚举**（17 个值）— 定义平台所有业务类型标识
  - NAV / ADDRBOOK / PRODUCT / DOC / TAG / LEAD / CUSTOMER / CUSTOMER_POOL / CLAIM / TOUCH_TASK / TOUCH_REPORT / LOAN / SUPPORT / SUPPORT_DEPT / REPORT / PERF_CONFIG / SYS_CONFIG
- **BizAction 枚举**（15 个值）— 定义平台所有业务操作类型
  - READ / LIST / WRITE / DELETE / TRANSFER / APPROVE / REJECT / IMPORT / EXPORT / EXECUTE / CONFIG / RECALC / JOB_TRIGGER / PERMISSION_CHANGE / EXECUTE_SQL
- **DataScopeType 枚举**（7 个值）— 定义数据范围类型
  - SELF_CREATED / SELF / SELF_ASSIGNED / ORG / ORG_SUBTREE / ALL / WORKFLOW_PARTICIPANT
- **@BizAuth 注解定义** — 标记接口所需的业务权限，属性：bizType, action
- **CurrentUserContext record** — 当前用户上下文（empId, mainOrgCode, roleIds, candidateGroupKeys, isSystemAdmin）
- **DataScopeContext** — ThreadLocal 保存本次请求的权限上下文，请求结束后自动清理
- **ObjectMeta record** — 业务对象元数据注册模型，声明数据表、所属组织列、创建人列等映射关系
- **SensitiveDataMasker** — 脱敏工具（手机号、身份证号、银行账号、金额）
- **SignatureUtils** — 签名工具，用于接口签名和验签

## 3. 不负责什么

- **不包含具体业务逻辑** — 所有业务规则由各业务模块自行实现
- **不直接操作数据库** — 不含 mapper / entity，common 中无任何数据库表定义
- **不实现鉴权判定逻辑** — 只定义注解和枚举，具体鉴权判定由 auth-permission-center 实现
- **不管理具体审计日志存储** — 只负责切面拦截和日志采集，存储由 system-governance-center 实现
- **不提供 REST 接口** — common 中不允许出现 @Controller / @RestController

# COMMON 基础层 — 功能规格

## 1. 模块定位

common 是平台公共基础设施层，为业务模块提供统一的 Web、链路追踪、安全元数据、AOP、数据库和通用锁能力；不包含具体业务规则，不依赖任何业务模块。

实现范围和依赖关系以 `common/pom.xml`、各子模块 POM 及自动配置 imports 为准，本文不复制类、依赖或枚举清单。

## 2. 能力边界

### 2.1 Web 与基础设施

- 提供 `ResponseWrapper<T>`、`PageRequest`、`PageResult<T>` 和全局异常映射；文件流、重定向等特殊响应遵循各自契约。
- 提供基于 `PT_LOCK` 的 JDBC 分布式锁，跨实例释放时校验 holder。
- 提供 sidecar 通用 HTTP/SOAP 客户端；业务协议、流水号和超时以 sidecar 源码及运行配置为准。

### 2.2 链路、日志与审计

- 生成或传播 traceId，并通过 MDC 和响应头保持链路可追踪。
- 提供接口日志、方法耗时和 `@AuditLog` 审计切面；敏感字段必须先脱敏。
- `AuditLogHandler` 是审计 SPI，默认处理器只作兜底；持久化实现由治理模块提供。

### 2.3 数据库与安全模型

- 提供 MyBatis-Plus 公共配置、分页、审计字段填充和慢 SQL 拦截；新增访问优先使用 `BaseMapper` 与 Lambda Wrapper。
- 提供 `@BizAuth` 元数据、当前用户/数据范围 ThreadLocal、安全脱敏和签名工具；实际认证、RBAC 和数据范围裁决由 auth-permission-center 执行。
- 枚举合法值以 `common-security` 源码为准，不在文档维护一份可能过期的全集。

## 3. 明确不负责

- 不承载客户、线索、申请、绩效、报表、流程等业务逻辑。
- 不提供业务 Controller，不直接访问业务表，也不定义业务 Entity/Mapper。
- 不负责认证授权决策、审计日志持久化或 Flowable 引擎调用。
- 不引入 Redis 作为 Session 或跨实例锁实现；不重新引入 MinIO。实际对象存储和外部业务渠道由所有者模块负责。

# COMMON 基础层 — 关键组件设计

## 1. 统一响应模型

### 1.1 ResponseWrapper\<T\>

统一所有接口的响应格式，确保前端可以一致化处理返回数据。

```java
package com.bank.branch.platform.common.web;

import com.fasterxml.jackson.annotation.JsonInclude;
import lombok.Data;
import java.time.Instant;

/**
 * 统一响应包装器
 * 所有 REST 接口统一返回此格式
 *
 * @param <T> 响应数据类型
 */
@Data
@JsonInclude(JsonInclude.Include.NON_NULL)
public class ResponseWrapper<T> {

    /** 响应码，"0" 表示成功，其他为错误码 */
    private String code;

    /** 响应消息 */
    private String message;

    /** 链路追踪 ID，来自 MDC */
    private String traceId;

    /** 响应数据 */
    private T data;

    /** 分页信息，仅分页接口返回 */
    private PageResult<?> page;

    /** 响应时间戳，ISO 8601 格式 */
    private String timestamp;

    private ResponseWrapper() {
        this.timestamp = Instant.now().toString();
    }

    /**
     * 成功响应（带数据）
     */
    public static <T> ResponseWrapper<T> success(T data) {
        ResponseWrapper<T> wrapper = new ResponseWrapper<>();
        wrapper.setCode("0");
        wrapper.setMessage("success");
        wrapper.setTraceId(MdcUtils.getTraceId());
        wrapper.setData(data);
        return wrapper;
    }

    /**
     * 成功响应（无数据）
     */
    public static ResponseWrapper<Void> success() {
        return success(null);
    }

    /**
     * 分页响应
     */
    public static <T> ResponseWrapper<T> page(PageResult<T> pageResult) {
        ResponseWrapper<T> wrapper = new ResponseWrapper<>();
        wrapper.setCode("0");
        wrapper.setMessage("success");
        wrapper.setTraceId(MdcUtils.getTraceId());
        wrapper.setPage(pageResult);
        return wrapper;
    }

    /**
     * 失败响应
     */
    public static ResponseWrapper<?> error(String code, String message) {
        ResponseWrapper<?> wrapper = new ResponseWrapper<>();
        wrapper.setCode(code);
        wrapper.setMessage(message);
        wrapper.setTraceId(MdcUtils.getTraceId());
        return wrapper;
    }
}
```

**使用示例：**

```java
// Controller 中使用
@GetMapping("/users/{id}")
@BizAuth(bizType = BizType.CUSTOMER, action = BizAction.READ)
public ResponseWrapper<UserDTO> getUser(@PathVariable String id) {
    UserDTO user = userService.getById(id);
    return ResponseWrapper.success(user);
}

// 分页查询
@PostMapping("/users/list")
@BizAuth(bizType = BizType.CUSTOMER, action = BizAction.LIST)
public ResponseWrapper<UserDTO> listUsers(@RequestBody @Valid PageRequest pageRequest) {
    PageResult<UserDTO> result = userService.listByPage(pageRequest);
    return ResponseWrapper.page(result);
}
```

### 1.2 PageRequest

统一分页请求参数，内置安全校验。

```java
package com.bank.branch.platform.common.web;

import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.Pattern;
import lombok.Data;

/**
 * 统一分页请求模型
 * 所有分页查询接口的请求参数必须继承或包含此类
 */
@Data
public class PageRequest {

    /** 页码，从 1 开始，默认 1 */
    @Min(value = 1, message = "页码最小为 1")
    private int pageNo = 1;

    /** 每页大小，默认 20，最大 100 */
    @Min(value = 1, message = "每页大小最小为 1")
    @Max(value = 100, message = "每页大小最大为 100")
    private int pageSize = 20;

    /** 排序字段，默认按创建时间排序，必须在白名单内 */
    private String sortBy = "createdTime";

    /** 排序方向，asc 或 desc，默认 desc */
    @Pattern(regexp = "^(asc|desc)$", message = "排序方向只能为 asc 或 desc")
    private String sortDir = "desc";

    /**
     * 计算分页偏移量
     */
    public int getOffset() {
        return (pageNo - 1) * pageSize;
    }
}
```

### 1.3 PageResult\<T\>

统一分页结果模型。

```java
package com.bank.branch.platform.common.web;

import lombok.Data;
import java.util.List;

/**
 * 统一分页结果模型
 *
 * @param <T> 数据记录类型
 */
@Data
public class PageResult<T> {

    /** 当前页码 */
    private int pageNo;

    /** 每页大小 */
    private int pageSize;

    /** 总记录数 */
    private long total;

    /** 当前页数据列表 */
    private List<T> records;

    /**
     * 构建分页结果
     */
    public static <T> PageResult<T> of(int pageNo, int pageSize, long total, List<T> records) {
        PageResult<T> result = new PageResult<>();
        result.setPageNo(pageNo);
        result.setPageSize(pageSize);
        result.setTotal(total);
        result.setRecords(records);
        return result;
    }

    /**
     * 计算总页数
     */
    public int getTotalPages() {
        return (int) Math.ceil((double) total / pageSize);
    }
}
```

## 2. 异常层次

### 2.1 BizException

业务异常基类，所有可预期的业务错误均应抛出此类或其子类。

```java
package com.bank.branch.platform.common.web.exception;

import lombok.Getter;

/**
 * 业务异常基类
 * 所有可预期的业务错误均抛出此异常或其子类
 * GlobalExceptionHandler 会将其转为统一响应格式
 */
@Getter
public class BizException extends RuntimeException {

    /** 错误码 */
    private final String code;

    /** 错误消息 */
    private final String message;

    public BizException(String code, String message) {
        super(message);
        this.code = code;
        this.message = message;
    }

    public BizException(String code, String message, Throwable cause) {
        super(message, cause);
        this.code = code;
        this.message = message;
    }
}
```

### 2.2 AuthException

登录态失效、未认证时抛出。HTTP 状态码映射为 401。

### 2.3 PermissionDeniedException

资源未授权、数据范围不足、写范围校验失败时抛出。HTTP 状态码映射为 403。

```java
package com.bank.branch.platform.common.web.exception;

/**
 * 权限拒绝异常

    private static final String DEFAULT_CODE = "PERM_001";

    public PermissionDeniedException(String message) {
        super(DEFAULT_CODE, message);
    }

    public PermissionDeniedException(String code, String message) {
        super(code, message);
    }
}
```

**使用示例：**

```java

if (session == null || session.isExpired()) {
    throw new AuthException("登录态已失效，请重新登录");
}

// 权限校验
if (!hasPermission) {
    throw new PermissionDeniedException("无权访问该资源");
}
```

## 4. 注解定义

### 4.1 @BizAuth

标记接口所需的业务权限，由 auth-permission-center 的拦截器解析并执行鉴权。

```java
package com.bank.branch.platform.common.security.annotation;

import com.bank.branch.platform.common.security.enums.BizAction;
import com.bank.branch.platform.common.security.enums.BizType;

import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

/**
 * 业务权限注解
 * 标记在 Controller 方法上，声明该接口所需的业务权限
 * 由 auth-permission-center 的拦截器解析并执行鉴权
 *
 * 使用示例：
 * {@code @BizAuth(bizType = BizType.CUSTOMER, action = BizAction.READ)}
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface BizAuth {

    /**
     * 业务类型
     */
    BizType bizType();

    /**
     * 业务操作，默认为 READ
     */
    BizAction action() default BizAction.READ;
}
```

**使用示例：**

```java
@GetMapping("/customers/{id}")
@BizAuth(bizType = BizType.CUSTOMER, action = BizAction.READ)
public ResponseWrapper<CustomerDTO> getCustomer(@PathVariable String id) {
    // 进入此方法时，@BizAuth 已校验通过
    return ResponseWrapper.success(customerService.getById(id));
}

@PostMapping("/leads/import")
@BizAuth(bizType = BizType.LEAD, action = BizAction.IMPORT)
public ResponseWrapper<ImportResultDTO> importLeads(@RequestBody List<LeadDTO> leads) {
    return ResponseWrapper.success(leadService.batchImport(leads));
}
```

### 4.2 @AuditLog

标记需要审计的高危操作，由 common-aop 的 AuditLogAspect 拦截处理。

```java
package com.bank.branch.platform.common.aop.annotation;

import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

/**
 * 审计日志注解
 * 标记在需要审计的高危操作方法上
 * 由 AuditLogAspect 拦截，记录操作人、操作时间、操作内容
 * 具体存储由 system-governance-center 实现
 *
 * 使用示例：
 * {@code @AuditLog(action = "DELETE", resourceType = "CUSTOMER", reasonRequired = true)}
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface AuditLog {

    /**
     * 操作动作描述
     * 如："DELETE"、"TRANSFER"、"PERMISSION_CHANGE"、"EXECUTE_SQL"
     */
    String action();

    /**
     * 资源类型
     * 如："CUSTOMER"、"LEAD"、"ROLE"
     */
    String resourceType();

    /**
     * 是否要求操作人填写操作原因
     * 高危操作（如删除客户、权限变更）应设置为 true
     * 默认 false
     */
    boolean reasonRequired() default false;
}
```

**使用示例：**

```java
@DeleteMapping("/customers/{id}")
@BizAuth(bizType = BizType.CUSTOMER, action = BizAction.DELETE)
@AuditLog(action = "DELETE", resourceType = "CUSTOMER", reasonRequired = true)
public ResponseWrapper<Void> deleteCustomer(
        @PathVariable String id,
        @RequestParam String reason) {
    customerService.delete(id, reason);
    return ResponseWrapper.success();
}
```

## 5. 上下文模型

### 5.1 CurrentUserContext

保存当前登录用户的基本信息，在认证成功后由 auth-permission-center 构建并存入请求上下文。

```java
package com.bank.branch.platform.common.security.context;

import java.util.Set;

/**
 * 当前用户上下文
 * 在认证成功后由 auth-permission-center 构建
 * 通过 ThreadLocal 或 Request Attribute 传递
 *
 * 约束说明：
 * - empId 口径统一为 PT_USER.USER_ID
 * - mainOrgCode 来源于 EXT_USER_ORG
 * - V1 版本单用户单主机构
 * - candidateGroupKeys 按当前角色/岗位/组织解析，
 *   用于工作流任务的候选组匹配
 *
 * @param empId              员工 ID，口径为 PT_USER.USER_ID
 * @param mainOrgCode        主机构编码，来源于 EXT_USER_ORG
 * @param roleIds            角色 ID 集合
 * @param candidateGroupKeys 候选组 Key 集合（角色/岗位/组织解析）
 * @param systemAdmin        是否系统管理员
 */
public record CurrentUserContext(
        String empId,
        String mainOrgCode,
        Set<String> roleIds,
        Set<String> candidateGroupKeys,
        boolean systemAdmin
) {
    /**
     * 判断是否拥有指定角色
     */
    public boolean hasRole(String roleId) {
        return roleIds != null && roleIds.contains(roleId);
    }

    /**
     * 判断是否拥有任意一个指定角色
     */
    public boolean hasAnyRole(Set<String> targetRoleIds) {
        if (roleIds == null || targetRoleIds == null) {
            return false;
        }
        return targetRoleIds.stream().anyMatch(roleIds::contains);
    }
}
```

### 5.2 DataScopeContext

ThreadLocal 保存本次请求的数据权限上下文，在请求结束时自动清理。

```java
package com.bank.branch.platform.common.security.context;

import com.bank.branch.platform.common.security.enums.BizAction;
import com.bank.branch.platform.common.security.enums.BizType;
import com.bank.branch.platform.common.security.enums.DataScopeType;
import lombok.Data;

import java.util.Set;

/**
 * 数据范围上下文
 * 通过 ThreadLocal 保存本次请求的权限上下文
 * 由 auth-permission-center 的 Filter 在请求进入时设置
 * 在请求结束后必须调用 clear() 清理，防止 ThreadLocal 泄漏
 *
 * 使用方式：
 * 1. Filter 中设置：DataScopeContext.set(ctx)
 * 2. Service/Mapper 中读取：DataScopeContext.current()
 * 3. Filter 的 finally 中清理：DataScopeContext.clear()
 */
@Data
public class DataScopeContext {

    private static final ThreadLocal<DataScopeContext> HOLDER = new ThreadLocal<>();

    /** 当前请求的业务类型 */
    private BizType bizType;

    /** 当前请求的业务操作 */
    private BizAction action;

    /** 当前用户在此业务类型上的数据范围 */
    private DataScopeType scope;

    /** 当前用户 ID */
    private String empId;

    /** 当前用户主机构编码 */
    private String orgCode;

    /** 当前用户机构及下属机构编码集合（ORG_SUBTREE 时使用） */
    private Set<String> orgSubtreeCodes;

    /** 候选组 Key 集合（WORKFLOW_PARTICIPANT 时使用） */
    private Set<String> candidateGroupKeys;

    /**
     * 获取当前线程的数据范围上下文
     *
     * @return 当前上下文，可能为 null
     */
    public static DataScopeContext current() {
        return HOLDER.get();
    }

    /**
     * 设置当前线程的数据范围上下文
     *
     * @param ctx 上下文
     */
    public static void set(DataScopeContext ctx) {
        HOLDER.set(ctx);
    }

    /**
     * 清理当前线程的数据范围上下文
     * 必须在请求结束时调用，防止 ThreadLocal 泄漏
     */
    public static void clear() {
        HOLDER.remove();
    }
}
```

## 6. ObjectMeta Registry

业务对象元数据注册模型，声明每种业务对象的数据表映射关系和支持的数据范围。

```java
package com.bank.branch.platform.common.security.meta;

import com.bank.branch.platform.common.security.enums.DataScopeType;

import java.util.Set;

/**
 * 业务对象元数据注册模型
 * 声明业务对象的数据表映射关系、列名规则、支持的数据范围
 * 由各业务模块在启动时注册到全局 Registry
 *
 * 强约束：
 * 1. 未声明的 scope 必须 fail-fast（抛出 PermissionDeniedException）
 * 2. 禁止默认降级为 ALL
 * 3. 每个 objectKey 全局唯一
 *
 * @param objectKey        业务对象标识，如 "LEAD"、"CUSTOMER"
 * @param tableName        对应数据表名，如 "cust_lead"
 * @param ownerOrgCol      所属机构列名，如 "owner_org_id"
 * @param createdByCol     创建人列名，如 "created_by"
 * @param assigneeCol      被分配人列名，如 "assignee_emp_id"，可为 null
 * @param selfCol          本人关联列名，如 "emp_id"，可为 null
 * @param businessKeyCol   业务主键列名，如 "business_key"，可为 null
 * @param joinPolicyKey    join 策略名，复杂查询时使用，可为 null
 * @param supportedScopes  该对象支持的数据范围类型集合
 * @param viewBizType      逻辑视图 BizType，跨模块查询时使用，可为 null
 */
public record ObjectMeta(
        String objectKey,
        String tableName,
        String ownerOrgCol,
        String createdByCol,
        String assigneeCol,
        String selfCol,
        String businessKeyCol,
        String joinPolicyKey,
        Set<DataScopeType> supportedScopes,
        String viewBizType
) {
    /**
     * 校验指定的 scope 是否被此对象支持
     * 不支持时抛出 PermissionDeniedException
     *
     * @param scope 待校验的数据范围类型
     * @throws com.bank.branch.platform.common.web.exception.PermissionDeniedException 不支持的 scope
     */
    public void validateScope(DataScopeType scope) {
        if (!supportedScopes.contains(scope)) {
            throw new com.bank.branch.platform.common.web.exception.PermissionDeniedException(
                    "SCOPE_001",
                    String.format("业务对象 [%s] 不支持数据范围 [%s]", objectKey, scope.getCode())
            );
        }
    }
}
```

## 7. 脱敏工具

提供常见敏感字段的脱敏方法，用于日志输出和接口返回值处理。

```java
package com.bank.branch.platform.common.security.masker;

import java.math.BigDecimal;

/**
 * 敏感数据脱敏工具
 * 用于日志输出、接口返回等场景的敏感字段脱敏
 *
 * 脱敏规则：
 * - 手机号：保留前 3 位和后 4 位，中间用 **** 代替
 * - 身份证：保留前 3 位和后 4 位，中间用 * 代替
 * - 银行账号：仅保留后 4 位，前面用 **** 代替
 * - 金额：全部脱敏为 ***.**
 */
public class SensitiveDataMasker {

    private SensitiveDataMasker() {
        // 工具类禁止实例化
    }

    /**
     * 手机号脱敏
     * 示例：13812345678 -> 138****5678
     *
     * @param phone 原始手机号
     * @return 脱敏后的手机号
     */
    public static String maskPhone(String phone) {
        if (phone == null || phone.length() < 7) {
            return "***";
        }
        return phone.substring(0, 3) + "****" + phone.substring(phone.length() - 4);
    }

    /**
     * 身份证号脱敏
     * 示例：110101199001011234 -> 110***********1234
     *
     * @param idCard 原始身份证号
     * @return 脱敏后的身份证号
     */
    public static String maskIdCard(String idCard) {
        if (idCard == null || idCard.length() < 7) {
            return "***";
        }
        int maskLen = idCard.length() - 3 - 4;
        return idCard.substring(0, 3) + "*".repeat(maskLen) + idCard.substring(idCard.length() - 4);
    }

    /**
     * 银行账号脱敏
     * 示例：6222021234567890 -> ****7890
     *
     * @param account 原始银行账号
     * @return 脱敏后的银行账号
     */
    public static String maskBankAccount(String account) {
        if (account == null || account.length() < 4) {
            return "****";
        }
        return "****" + account.substring(account.length() - 4);
    }

    /**
     * 金额脱敏
     * 示例：12345.67 -> ***.**
     *
     * @param amount 原始金额
     * @return 脱敏后的金额字符串
     */
    public static String maskAmount(BigDecimal amount) {
        if (amount == null) {
            return "***.**";
        }
        return "***.**";
    }
}
```

```java

    SensitiveDataMasker.maskPhone(user.getPhone()),
    SensitiveDataMasker.maskIdCard(user.getIdCard()));
```

## 8. 签名工具

提供接口签名和验签能力，用于防篡改和防重放。

```java
package com.bank.branch.platform.common.security.sign;

import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;
import java.util.Base64;
import java.util.Map;
import java.util.TreeMap;
import java.util.stream.Collectors;

/**
 * 签名工具
 * 提供接口签名和验签能力
 *
 * 签名算法：HmacSHA256
 * 签名步骤：
 * 1. 将所有参数按 key 字典序排列
 * 2. 拼接为 key1=value1&key2=value2 格式
 * 3. 追加时间戳和 nonce 防重放
 * 4. 使用 HmacSHA256 计算签名
 * 5. Base64 编码输出
 */
public class SignatureUtils {

    private static final String HMAC_SHA256 = "HmacSHA256";

    private SignatureUtils() {
        // 工具类禁止实例化
    }

    /**
     * 生成签名
     *
     * @param params    请求参数
     * @param timestamp 时间戳（毫秒）
     * @param nonce     随机数（防重放）
     * @param secretKey 签名密钥
     * @return Base64 编码的签名字符串
     */
    public static String sign(Map<String, String> params, long timestamp, String nonce, String secretKey) {
        // 按 key 字典序排列
        String sortedParams = new TreeMap<>(params).entrySet().stream()
                .map(e -> e.getKey() + "=" + e.getValue())
                .collect(Collectors.joining("&"));

        // 追加时间戳和 nonce
        String signContent = sortedParams + "&timestamp=" + timestamp + "&nonce=" + nonce;

        return hmacSha256(signContent, secretKey);
    }

    /**
     * 验证签名
     *
     * @param params    请求参数
     * @param timestamp 时间戳（毫秒）
     * @param nonce     随机数
     * @param secretKey 签名密钥
     * @param signature 待验证的签名
     * @return 签名是否有效
     */
    public static boolean verify(Map<String, String> params, long timestamp, String nonce,
                                  String secretKey, String signature) {
        String expected = sign(params, timestamp, nonce, secretKey);
        return expected.equals(signature);
    }

    /**
     * HmacSHA256 计算
     */
    private static String hmacSha256(String content, String secretKey) {
        try {
            Mac mac = Mac.getInstance(HMAC_SHA256);
            SecretKeySpec keySpec = new SecretKeySpec(
                    secretKey.getBytes(StandardCharsets.UTF_8), HMAC_SHA256);
            mac.init(keySpec);
            byte[] hash = mac.doFinal(content.getBytes(StandardCharsets.UTF_8));
            return Base64.getEncoder().encodeToString(hash);
        } catch (Exception e) {
            throw new RuntimeException("签名计算失败", e);
        }
    }
}
```

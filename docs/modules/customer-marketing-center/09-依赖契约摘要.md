# 客户营销中心 — 依赖契约摘要

> 本文只保留当前代码实际使用的跨模块契约和边界。完整方法签名以依赖模块的 api/ 包、DTO 和事件为准；本模块不依赖对方 Mapper、Entity 或私有表。

## 1. Maven 依赖

| 依赖 | 当前职责 |
|---|---|
| common-web、common-trace、common-security、common-aop、common-db | 统一响应、链路、鉴权、审计切面和持久化基础设施 |
| auth-permission-center | 当前用户、用户/机构信息、角色及业务数据范围 |
| workflow-center | 流程启动/取消、任务审批、流程映射/结果和只读流程查询 |
| system-governance-center | 字典、文件、通知和平台调度 |
| MyBatis-Plus、EasyExcel | 本模块持久化及导入导出 |

模块不依赖 portal-content-center、report-analytics-center 或 performance-engine-center；反向调用只能通过本文件和 04-对外API契约.md 所述公开 API。

## 2. 认证与数据范围

本模块从 auth-permission-center 使用：

- CurrentUserApi：当前员工、机构、角色和请求上下文；
- UserApi / OrgApi：员工、机构和机构关系查询；
- BizScopeApi：按 BizType 解析列表数据范围、构造过滤条件，并在写操作前复核目标记录；
- BizType、BizAction、DataScopeType 及相关 DTO。

列表、详情、历史和导出查询必须把数据范围传入 Mapper；Service 对目标记录再次校验。SYS_ADMIN 只在源码声明的业务门禁中生效，不能作为通用越权约定。

## 3. 工作流契约

业务 Service 通过 WorkflowApi 使用以下能力：startProcess、cancelProcess、getProcessByBusinessKey、getProcessByBizTypeAndBizId、getProcessOutcome，以及审批服务使用的 approveByEmp / rejectByEmp。流程只由 workflow-center 操作，客户模块不直接调用 Flowable。

审批列表和资产详情通过 WorkflowQueryApi 使用待办/已办查询、流程历史、节点图和参与业务键查询。使用的 DTO 包括 StartProcessCmd、WorkflowLaunchResp、BizProcessMapDTO、TaskRespDTO、ApprovalLogDTO 和 ProcessDiagramDTO。

当前业务流程键：

| 流程键 | 业务用途 |
|---|---|
| lead_approve_v1 | 传统和当前营销线索提交 |
| lead_delete_process | 客户删除申请 |
| loan_approve_v1 | 资产立项主申请及加急申请（名称为现行实现约定） |

ProcessCompletedEvent 的 businessKey、processInstanceId、outcome 和 reason 是回调依据；监听器只做条件状态更新，不能把流程状态直接当作业务状态。

## 4. 治理中心契约

- DictApi.getDictLabel(type, code)：客户池、认领等展示场景的字典标签解析；字典类型和当前使用范围见 08-初始化数据清单.md。
- FileApi：upload、bindFile、unbindFile、listBizFiles、getFileContent，用于线索/标签导入、资产附件和导出文件。对象存储实现由治理中心负责。
- NotifyApi.sendNotification / batchSendNotifications：审批、认领和跨机构营销通知。
- @AuditLog 与公共审计切面：高危写操作、导入导出、审批和转交须按源码注解记录原因、操作者、目标和结果。

## 5. 本模块公开给调用方的契约

跨模块调用仅使用以下接口及 DTO，详见 04-对外API契约.md：

| 接口 | 主要消费者/用途 |
|---|---|
| CustomerQueryApi | 业务申请、绩效、报表读取客户及统计 |
| AssetProjectQueryApi | 业务申请读取资产立项统计 |
| LeadApi | 线索查询和版本链 |
| TagApi | 启用标签及客户标签查询 |
| ClaimApi | 有效认领查询 |
| TouchTaskQueryApi | 触达任务、客户触达历史和汇总 |

其中 AssetProjectQueryApi 的统计只读语义不等于允许直连 MARKETING_ASSET_PROJECT_APPLY；调用方不得依赖实体字段、SQL 列、缓存键或兼容表名。

## 6. 维护约束

- 修改 Controller、@BizAuth、公开 API、DTO、事件或错误码时，同步更新 03-接口设计与报文.md、04-对外API契约.md 和资源授权。
- 跨模块新增调用必须先在依赖方 api/ 中形成稳定 DTO/方法，再由本模块通过 facade/service 注入；禁止跨模块直接 Join 或复制实现。
- 流程、字典、资源和表结构的事实来源分别是 workflow、governance、auth 的当前实现及目标库 schema；本摘要不固化版本、数量或一次性发布记录。

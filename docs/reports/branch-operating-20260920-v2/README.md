## 修正支行取数

现有对公单值/趋势来源9020和9024的配置快照固定 `org_code=1`；与选中支行109同时筛选必然没有该支行数据。新页面保留发布身份与权限，借用同一对公屏已发布的机构明细槽 `corpRanking`，仅消费其中存款字段，不以该数据声称同层绩效排名。

- 最新值按选中机构请求。
- 历史请求每次为单日 `RANGE`，避免按机构聚合时跨日累加余额。
- 趋势取前五个月末＋当前截至日；同比和环比单独请求精确上年/上月同期，缺失不补零，最多并发2项历史请求。
- 初次无指定支行时，在授权候选中优先选择存款非空且有有效考核目标的支行。未能取回数据时不会宣称已找到覆盖最全机构。
- 历史只读审计指出 M_0282/M_0286/M_0347 等存在随机数测试定义。来源未经重新核验前，月均/贷款卡片及贷款趋势不进入展示。LIVE仅表示接口取数，不作真实性认证。
- 对公不良率保留“分类样本”、FTP收入保留“折人民币”口径说明；金额单位仍需业务确认。

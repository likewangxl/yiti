# 启动前 yit_test 只读快照

执行范围：仅 `yit_test`；无 DDL/DML/DELETE。

命令逻辑：从 `INFORMATION_SCHEMA.TABLES` 读取 `ACT_%` 表名，逐表执行 `SELECT COUNT(*)` 和 `CHECKSUM TABLE`。

```text
mysql -h127.0.0.1 -P3306 -uroot --password='[REDACTED]' -N -B -e "SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_SCHEMA='yit_test' AND TABLE_NAME LIKE 'ACT_%' ORDER BY TABLE_NAME"
逐表：SELECT COUNT(*) FROM yit_test.<ACT_TABLE>
逐表：CHECKSUM TABLE yit_test.<ACT_TABLE>
```

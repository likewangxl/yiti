## 支部审核状态流转

- POST `/api/re/reviews/tasks/branch/3/approve` -> `200 OK`（通过与提交分离）
- POST `/api/re/reviews/tasks/branch/3/submit-to-org` -> `200 OK`（单独提交组织审核）
- POST `/api/re/reviews/tasks/branch/4/reject` -> `200 OK`（填写驳回意见）
- GET `/api/re/tasks/assignments/4` -> `200 OK`（支部驳回后，报送员重新填报前后详情读取）
- POST `/api/re/tasks/submissions` -> `200 OK`（任务 4 重提，复用原 assignment）
- POST `/api/re/reviews/tasks/branch/4/approve` -> `200 OK`（重提后再次通过）
- POST `/api/re/reviews/tasks/branch/4/submit-to-org` -> `200 OK`（重提后再次提交组织审核）
- GET `/api/re/reviews/tasks/branch/queue?pageNo=1&pageSize=20&tab=REVIEWING` -> `200 OK`
- GET `/api/re/reviews/tasks/branch/queue?pageNo=1&pageSize=20&tab=APPROVED` -> `200 OK`
- GET `/api/re/reviews/tasks/branch/queue?pageNo=1&pageSize=20&tab=REJECTED` -> `200 OK`

页面证据显示：支部书记可执行通过、独立提交组织审核和驳回；任务 4 驳回后重新提交可以再次进入支部工作台并流转组织审核。

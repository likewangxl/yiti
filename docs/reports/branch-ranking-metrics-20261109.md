## 统计口径

| 指标 | 分子 | 分母 | 输出 |
|---|---|---|---|
| 对公存款目标完成率 | 本机构直营对公存款期末余额 | 数据日期所属考核周期内有效、同口径的存款余额目标 | 分子 / 分母 × 100 |
| 对公贷款目标完成率 | 本机构直营对公贷款期末本金余额 | 数据日期所属考核周期内有效、同口径的贷款余额目标 | 分子 / 分母 × 100 |
| 零售贷款不良率 | 本机构同产品范围内、经银行核准分类的不良贷款期末本金余额 | 同范围全部零售贷款期末本金余额 | 分子 / 分母 × 100 |
| 对公贷款不良率 | 本机构同产品范围内、经银行核准分类的不良贷款期末本金余额 | 同范围全部对公贷款期末本金余额 | 分子 / 分母 × 100 |

约束：

1. 金额统一为人民币元（`YUAN`），比例输出为百分点（`PERCENT`）；`2.5` 表示 `2.5%`，不能再乘 100。
2. 分子与分母必须来自同一机构、日期、数据版本及业务范围。生产目标必须在该数据日期有效；不能把净增目标、日均目标与期末余额混用。若目标是净增，应另建“同口径净增实际值 / 净增目标”的指标。
3. 不良本金与贷款本金必须使用一致的贷款范围、币种折算和去重规则；不猜测生产贷款分类码，不把利息、罚息或其他资产混入本金。
4. 缺值或分母为 0 不计算，返回 `NULL`；已知分子为 0 且分母大于 0，返回合法的 `0%`。负金额、不良本金超过贷款本金属于异常输入。
5. 完成率可以超过 100%，不截断。机构汇总使用分子合计除以分母合计，不能直接平均各机构百分比；输入缺失时不输出部分机构的伪全量汇总。
6. 本次结果按实际宽表 `DECIMAL(20,4)` 精度存储并逐值核对；界面保留两位小数仅是显示格式。

## 已准备的程序行为

对公中心入口使用`LIVE`模式读取已发布包和现有`/api/screen/data`接口，移除中心页面的对公固定演示模型引用。`LIVE`只表示接口取数，不能推断为生产环境或真实业务认证；页面显示“已接入数据 / 统计口径与环境见来源说明”。开发视觉预览继续明确使用演示模型。

服务端仅在已有对公CODE发布包满足新模板条件时开放对公LIVE目录入口，旧画布不直接进入新运行时。权限、screenCode、schemaVersion、发布状态和模板不符时拒绝；刷新重新请求接口，换屏与错误清空旧数据。

## 后续接入步骤

1. 确认正式对公指标来源及原始单位、日期/版本、可加总机构层级；如只做测试联调，明确标注数据性质，不作为经营结论。
2. 以受控API新建独立CORP来源，按现有授权组查询。汇总、日期趋势和机构明细分开配置，避免把多个机构同一天结果当单一时序。
3. 备存当前画布与发布快照，保存对公草稿并通过原草稿接口验收；缺失收入、有效客户、风险、目标和协调事项保持未接入。
4. 验收真实请求、日期、覆盖、空值、单位和权限后，再按实际授权范围启用发布版本。

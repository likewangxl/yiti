- 以独立 `CompositionBreakdown` 组件替换分行矩形树图：构成合计 → 100%横向构成带 → 两项组成明细。分段长度准确反映比例，明细突出55.5%与44.5%，并分别显示对公/零售名称及714.26/572.16亿元；金额不在图内外重复。
- 配色使用青色与低饱和蓝紫；父面板沿用原有深蓝主题。去掉重复外框与无效大色块，占比字体优先，机构组成名称不截断。
- 分行与市级摘要的整句文本由红色改为柔和蓝青色，业务数值、净减与目标差等文字含义不变。样式限定于经营摘要，不改变其他KPI或错误提示规则。
- 不新增依赖或数据请求，不修改数据源、已保存草稿、发布包或上游业务数据。
